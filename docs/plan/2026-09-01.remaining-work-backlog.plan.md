### A2. resize 입력 검증 부재

- **사실**: `server/src/utils/constants.ts:133` `MAX_COLS: 500`, `:137` `MAX_ROWS: 200` 이 정의만 되어 있고 **사용처가 0건**이다.

- **완료 조건**: 범위를 벗어난 resize 가 PTY 에 도달하지 않고, 정상 범위는 그대로 통과한다. 경계값(0, 1, MAX, MAX+1) 테스트 포함.

- **[2026-09-16] 해소.** 다만 **위치 표기가 낡았다**: 클램프는 `WsRouter.ts` 가 아니라 `SessionManager.ts` 의 `normalizeTerminalGeometry`(현재 `:1040-1046`)에 있고, `VALIDATION_LIMITS` 상수도 `constants.ts:97`·`:101` 로 옮겨졌다. 비정수·비양수는 거부하고 초과는 클램프한다. 최소값은 의도적으로 강제하지 않는다. `cwd=server/` `npx tsx --test src/services/SessionManagerResizeBounds.test.ts` → tests 6 / pass 6 / fail 0 (경계 0·1·MAX·MAX+1·NaN·Infinity 포함). 핀 파일을 건드리지 않았으므로 재게시도 불필요했다.
