## Decisions

| Topic | Decision |
| --- | --- |
| Reservation owner | Reuse SessionManager enqueue's existing reservedAuthorityOrdinal. Preserve both epoch and seq across queued reservations; never issue a second identity at flush. |
| Pending fields | reservedStreamEpoch and reservedSourceSeq, canonical strings copied from the existing reservation. |
| DataGap | No invented source identity. Continue deliverySeq ACK capability for source-less deliveries. |
| Source identity | Tuple (streamEpoch, sourceSeq), because seq wraps to 0 in a new epoch independently of fair connectionEpoch. |
| ACK discriminator | kind = deliverySeq or sourceSeq. Source variant requires streamEpoch and sourceSeq and excludes deliverySeq; delivery variant excludes both source fields. |
| Wire compatibility | Continue accepting legacy deliverySeq-only wire ACKs. JSON output clients retain legacy ACK emission. Normalize legacy input at the parsing/domain boundary; source ACK is explicit and used by the negotiated binary path. |
| Ledger | Keep internal deliverySeq counters and lastAcknowledgedSeq unchanged. Find exact source tuple in bounded sent/queue; reuse common cumulative delivery settlement. No unbounded source map. |
| Source state | lastAcknowledgedSource and highestEnqueuedSource tuples per lane, independent of delivery counters. |
| Lane floor | Initialize on first source enqueue to its immediate predecessor (same epoch, seq-1; or previous epoch/max64 for seq0); (0,0) has null predecessor. This is accounting scope only, not a claim that browser state is applied. |
| Source comparison | Canonical uint64 validation and BigInt epoch-then-seq comparison; no Number conversion or string lexical ordering. |
| Credit | Sum server-owned body encodedBytes only for entries removed once. Never infer bytes from source gaps or clientBytes. |

## Scope and sequence

1. Prove and fix pending reservation rollover first: current code stores nextTerminalAuthoritySourceSeq but reloads the epoch from committed retained state. Before a flush, (7,max) -> (8,0) -> (7,1) is a candidate defect. Reproduce through real SessionManager behavior before fixing; review all resets/restores of the reservation cursor.
2. Preserve reservation tuple in pending output and OutputAuthorityMetadata through router enqueue and FairTerminalDeliveryInput/Delivery. Only actual output frames carry an output identity; source-less control/dataGap delivery remains supported.
3. Add ACK union and parser behavior, source lookup and domain-specific error validation; preserve old delivery branches and common settlement.
4. Propagate tuple to wire and binary output adapter along with negotiated fair connectionEpoch; run actual browser write completion ACK path. Reject malformed source identities observably; do not silently switch ACK domains.
5. Reissue affected provenance/evidence; verify exact-source tests and runtime capability acceptance separately from build success.

## Error precedence and settlement

| Order | Check |
| --- | --- |
| 1 | Both domains present -> ACK_DOMAIN_CONFLICT; neither -> ACK_DOMAIN_MISSING; malformed discriminant/ordinal -> observable invalid-domain/value rejection. Preserve existing legacy invalid-delivery-seq parser behavior. |
| 2 | Unknown/retired lane and released lane -> existing ACK_UNKNOWN_LANE / ACK_STALE_EPOCH precedence. |
| 3 | Delivery seq <= delivery watermark, or source tuple <= source floor/settled watermark -> ACK_DUPLICATE, zero credit. |
| 4 | Delivery seq beyond issued ceiling, or source tuple beyond highest enqueued source (including no source history) -> ACK_OVER_ACK. |
| 5 | Issued-but-unsent delivery, queued source tuple, or source hole below ceiling without an exact sent entry -> ACK_OUT_OF_ORDER. |
| 6 | Resolve exact source tuple to deliverySeq, then run common cumulative settlement through that entry, updating both watermarks from entries actually removed. |

- Source epochs older than the newest enqueued epoch remain ACKable when their exact entry is still sent and unsettled. Connection rollback/release retains the stale-lane gate.
- Example: output(100,d1), dataGap(d2), output(103,d3). source100 -> credit d1; delivery2 -> credit d2; source103 -> credit d3. Repeated source100/delivery2 returns zero. If source103 arrives first it settles d1..d3 once; later delivery2 is duplicate.
- Reserved-but-not-enqueued identities are outside the lane ceiling. Queued-but-unsent identities are inside its ceiling but not ACKable.
