## Method, and why a zero here is a measurement

The standing brief's `#10` entry forbids checking only the requirements the issue body
names. So the corpus is **every acceptance criterion in every SRS document**, not a
per-requirement lookup.

`raw/ac-corpus.json` was built by parsing all five files under `docs/spec/*.srs.md` for
`- [ ]`/`- [x] AC-N:` lines under their owning requirement heading. It holds **913 AC rows
across 135 requirements**; `speckiwi list --root <worktree> --json --limit 1000` reports
**138** requirements, so three requirements carry no ACs.

Four controls were run before any conclusion was drawn from a zero:

| Control | Expectation | Result |
|---|---|---|
| A — corpus reproduces `REL-BGSTAB-011` | 9 rows, all checked | 9 rows, all checked — matches the CLI exactly |
| B — corpus reproduces `REL-BGSTAB-007` | 12 rows, none checked | 12 rows, none checked — matches the CLI exactly |
| C — term known to occur (`sourceSeq`, `driver lease`, `empty success`, `oldestRetainedSeq`) | non-zero, and spanning requirements the issue does not name | 7 / 4 / 4 / 5 hits, spanning `IR-BGSTAB-001`, `IR-BGSTAB-002`, `PERF-BGSTAB-011`, `REL-BGSTAB-008`, `REL-BGSTAB-012`, `FR-BGSTAB-024`, `MIG-BGSTAB-002` |
| D — term known not to occur (`ZZZ-does-not-exist`) | zero | zero |

Control C is the one that matters: the instrument reaches requirements outside the issue's
named pair, so a zero would be a measurement rather than a silence.

**Stated bias.** This map is **search-derived**, by substring over AC text. Per the standing
brief, search-derived coverage claims under-report, and this one carries that bias: an AC
that specifies the same property in different vocabulary is invisible to it. Every
"uncovered" verdict below must be discounted accordingly; a "covered" verdict is not
subject to that bias in the same direction.

## Divergences — recorded, not reconciled

**(a) Semantic divergence, issue AC-4.** The issue asks for two comparisons: the existing
viewport snapshot's *current screen* against the new checkpoint, **and** a shadow comparison
of the pre-refresh model's *full retained* logical-line/cell hash. `REL-BGSTAB-011` AC-4
specifies only the second — its comparer axes are "logical lines/cells, Unicode width,
cursor, modes, active buffer, parser tail, eviction metadata", with no separate
current-screen-vs-checkpoint arm. The two-arm structure the issue describes is not in the
criterion.

**(b) Divergence, issue AC-6.** The issue requires that *several facts of the same type
inside one chunk* be preserved. `REL-BGSTAB-011` AC-5 specifies identity
(`streamEpoch`, `sourceSeq`, record-local ordinal) and exactly-once settlement, which
*implies* multiplicity is representable but never states the preservation requirement. This
matters because, per the standing brief, that collection may legitimately be singular or
empty — a criterion that never states its size is the empty-enumeration hazard at
specification level.

**(c) Divergence, issue AC-8.** The issue's subject is the **input class** — replay, seed
and snapshot bytes specifically. `REL-BGSTAB-011` AC-5 is written about the **fact class**
and says nothing about which byte sources must be inert. `REL-BGSTAB-007` AC-9 speaks of
side effects under a driver lease, which is a different guard.

**(d) Divergence, issue AC-10.** The issue draws an explicit line between a **physical**
connection disconnect (revoke only that binding; keep the session-owned model, parser/write
chain and fact comparer alive) and a **logical** session end (release everything). The
criteria carry both halves but never draw the line: `REL-BGSTAB-011` AC-6 covers
disconnect/rebind, AC-9 covers termination, and neither states that the first must *not* do
what the second does. That is the property most at risk of being satisfied by an
over-broad implementation.

**SRS criteria with no issue AC:** `REL-BGSTAB-011` AC-7 (degradation/mismatch/lease
failure blocks canary promotion only) and AC-8 (the AI-TUI idle invariant) have no
counterpart in the issue's ten. They are in scope of the requirement this issue implements
and out of scope of the issue text; recorded, not reconciled.
