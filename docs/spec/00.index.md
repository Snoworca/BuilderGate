### Target: wave-5

**Goal:** binary data plane 무조건 도입(2026-08-16 오너 결정으로 adopt-or-skip 게이트 폐기), all-consumer convergence, reversible default, two-release soak와 안전한 legacy physical deletion을 수행한다. split data plane 채택 여부는 별도 판단으로 남는다.

### Target: wave-4

**Goal:** visible-only WebGL fallback, Unicode/alternate-buffer parity, stable selection, hidden residency와 input/IME/OSC52 exactly-once를 구현한다.

### Target: wave-3

**Goal:** TerminalResourcePolicy, browser sole writer, retained server model, single authority, fair delivery와 hidden authoritative recovery를 구축한다.

### Target: wave-2

**Goal:** Orca 원칙을 흡수하여 기존 UI와 authority를 바꾸지 않고 segmented UTF-8 output scheduling, explicit stale/resync repair, bounded snapshot-drain-ready restore, paste/copy exactly-once ownership을 TDD로 구현한다.

### Target: wave-1

**Goal:** split drift와 refresh 절단을 재현하고 retained-state authority 계약·benchmark evidence·G1 분기를 확정하며, bug-only이면 선택된 단일 국소 결함과 회귀 evidence까지 종결한다.

### Target: 0.5.3step1

**Goal:** Specify terminal context menu registered item paste workflow and the required nested context menu behavior for desktop and mobile.
