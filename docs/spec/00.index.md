### Target: terminal-fit-convergence

**Goal:** 그리드↔탭 전환·탭 이동 뒤 보이는 터미널의 cols/rows 가 컨테이너 크기로 반드시 수렴해 렌더링이 깨진 채 남지 않는다(새로고침 없이).

### Target: session-save-all

**Goal:** 세션 저장이 모든 터미널의 디렉터리·실행 명령·에이전트 세션 id 를 한 번에 저장하고, 재시작하면 셸이 저장된 디렉터리에서 열린 뒤 에이전트가 같은 명령(등록 별칭 포함)과 id 로 자동으로 이어진다. id 가 불확실하면 저장 창에서 사용자가 고친다.

### Target: login-persistence

**Goal:** 브라우저 로그인을 마지막 사용 후 7일까지 유지(슬라이딩)하고, 절전·탭 동결·다중 탭에서도 불필요하게 로그아웃되지 않게 한다.

### Target: mcp-management-tools

**Goal:** MCP 에 워크스페이스 생성·삭제·이름변경·목록, 터미널 생성·삭제·명령 실행·목록 도구를 추가하고(워크스페이스는 id 또는 이름으로 지정), 2026-07-28 무상태 MCP 프로토콜을 기존 2025-11-25 세션 방식과 함께 지원한다. 새 쓰기 도구는 고정 접근 키에만 허용한다.

### Target: file-explorer-navigation

**Goal:** docs/research/2026-09-28.file-explorer-navigation.md 의 승인된 6개 기능을 구현한다: 비동기·취소 가능한 검색(Ctrl+F), 보이는 항목 기준 타이핑 필터와 일치 강조, 단일 자식 디렉토리 자동 확장, 목록 모드 경로 빵부스러기, 세션 루트에서 .. 숨김, 정보 메뉴와 복사 가능한 정보 모달.

### Target: i18n

**Goal:** 프런트엔드 UI 문구를 언어별 JSON 사전(messages.{lang}.json)으로 옮기고, 브라우저 언어(navigator.language)가 한국어면 한국어, 아니면 영어 사전을 서버에서 받아 렌더한다. 연구: docs/research/2026-09-27.i18n.md

### Target: session-save-restore

**Goal:** BuilderGate 재시작 전에 사용자가 세션 저장 버튼으로 실행 중인 Claude·Codex·Hermes·OpenCode 세션의 ID를 에이전트를 멈추지 않고 저장하고, 재시작 뒤 확인을 거쳐 정확히 그 세션으로 이어한다.

### Target: ui-design-system

**Goal:** BuilderGate 전 화면을 하나의 디자인 시스템으로 통일한다: 글자·간격·컨트롤·아이콘 크기 토큰, 선 아이콘 세트, 공용 부품(버튼·칩·창 틀·목록 행·진행·배너·툴팁), 한국어 문구 규칙, 접근성 대비. 창 → 헤더·사이드바·세션 줄 → 편집기·파일 탐색기 순으로 옮긴다.

### Target: code-editor

**Goal:** 편집기를 마크다운 전용에서 넓혀, 텍스트로 편집 가능한 소스코드·설정·데이터 파일을 CodeMirror 6 코드 모드로 열고 이미지 파일은 보기 전용 뷰어로 연다. 저장 시 줄바꿈·BOM 을 보존하고 UTF-8 이 아닌 파일은 읽기 전용으로 연다. 연구: docs/research/2026-09-26.code-and-data-file-editor.md

### Target: file-explorer

**Goal:** 설계안 2026-09-12.file-explorer.design.md 의 확정 결정 21건을 구현한다. 트리·목록 모드와 가변 뿌리, `..` 상위 이동, 서버 파일 조작 작업 모델과 진행 보고, 창 범위 결정 모달, 편집기 좌측 패널과 폭 조절, 표면 적응형 디자인 토큰.

### Target: wave-5

**Goal:** binary data plane 무조건 도입(2026-08-16 오너 결정으로 adopt-or-skip 게이트 폐기), all-consumer convergence, reversible default, two-release soak와 안전한 legacy physical deletion을 수행한다. split data plane 채택 여부는 별도 판단으로 남는다.

### Target: wave-4

**Goal:** visible-only WebGL fallback, Unicode/alternate-buffer parity, stable selection, hidden residency와 input/IME/OSC52 exactly-once를 구현한다.

### Target: wave-3

**Goal:** TerminalResourcePolicy, browser sole writer, retained server model, single authority, fair delivery와 hidden authoritative recovery를 구축한다.

### Target: wave-2

**Goal:** Orca 원칙을 흡수하여 기존 UI와 authority를 바꾸지 않고 segmented UTF-8 output scheduling, explicit stale/resync repair, bounded snapshot-drain-ready restore, paste/copy exactly-once ownership을 TDD로 구현한다.

### Target: wave-1

**Goal:** split drift와 refresh 절단을 재현하고 retained-state authority 계약·benchmark evidence·G1 분기를 확정하며, bug-only이면 선택된 단일 국소 결함과 회귀 evidence까지 종결한다.

### Target: 0.5.3step1

**Goal:** Specify terminal context menu registered item paste workflow and the required nested context menu behavior for desktop and mobile.
