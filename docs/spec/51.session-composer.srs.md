### FR-CMP-001 — 세션 아래 입력창을 열고 닫는다

| Field | Value |
| --- | --- |
| Type | functional |
| Target | messenger |
| Status | implemented |
| Priority | high |
| Tags | - |
| Risk | medium |
| Stability | evolving |
| Verification Method | test |
| GitHub Issue | - |
| Related Docs | [session-input-box.html](../../design/html/2026-11-19.session-input-box.html) |

#### Requirement

Each terminal session shall have a composer below the terminal, above the session status row, that the user opens and closes from a toggle at the right end of that status row, with a rebindable shortcut (default Alt+N), and from the terminal context menu.

#### Rationale

-

#### Acceptance Criteria

- [x] AC-1: AC-1: 입력창은 터미널과 세션 하단 상태 줄 사이에 놓이고, 닫혀 있으면 공간을 차지하지 않는다. 처음에는 모든 세션에서 닫혀 있다.
- [x] AC-2: AC-2: 상태 줄 오른쪽 끝의 토글로 열고 닫는다. 열면 입력창에 포커스가 가고, 닫으면 그 세션의 터미널로 포커스가 간다. 보내지 않은 초안이 있으면 토글 옆에 점이 보인다.
- [x] AC-3: AC-3: 단축키(기본 Alt+N, 터미널 단축키 설정에서 바꿀 수 있음)는 닫혀 있으면 열고 포커스를, 열려 있고 터미널에 포커스가 있으면 입력창으로 포커스를, 입력창에 포커스가 있으면 닫는다. IME 조합 중에는 동작하지 않는다.
- [x] AC-4: AC-4: 터미널 컨텍스트 메뉴(모바일 포함)에 '입력창 표시' / '입력창 숨기기' 가 있다.
- [x] AC-5: AC-5: 열림 상태는 세션별로 브라우저에 저장되어 새로고침 뒤에도 유지된다.

### FR-CMP-002 — 입력창 높이를 위로 늘리고 줄인다

| Field | Value |
| --- | --- |
| Type | functional |
| Target | messenger |
| Status | implemented |
| Priority | high |
| Tags | - |
| Risk | medium |
| Stability | evolving |
| Verification Method | test |
| GitHub Issue | - |
| Related Docs | [session-input-box.html](../../design/html/2026-11-19.session-input-box.html) |

#### Requirement

The composer shall be resizable by dragging its top edge, within limits that keep the terminal usable, and the terminal shall be refitted once when the drag ends.

#### Rationale

-

#### Acceptance Criteria

- [x] AC-1: AC-1: 입력창 위쪽 손잡이를 위로 끌면 커지고 아래로 끌면 작아진다. 최소는 한 줄, 최대는 타일 높이의 50% 이며 터미널은 최소 6줄을 유지한다. 손잡이를 더블클릭하면 기본 높이로 돌아간다.
- [x] AC-2: AC-2: 내용이 짧으면 정한 높이보다 작게, 길면 정한 높이까지 자란 뒤 스크롤한다.
- [x] AC-3: AC-3: 드래그 중에는 PTY resize 를 보내지 않고, 드래그가 끝날 때 터미널을 한 번 다시 맞춘다.
- [x] AC-4: AC-4: 높이는 모든 세션이 함께 쓰는 값 하나로 브라우저에 저장된다.

### FR-CMP-003 — 입력창에서 쓴 글을 세션에 한 번에 보낸다

| Field | Value |
| --- | --- |
| Type | functional |
| Target | messenger |
| Status | implemented |
| Priority | high |
| Tags | - |
| Risk | medium |
| Stability | evolving |
| Verification Method | test |
| GitHub Issue | - |
| Related Docs | [session-input-box.html](../../design/html/2026-11-19.session-input-box.html) |

#### Requirement

The composer shall send its draft to the session in one bracketed paste followed by Enter, keep the draft while unsent, and support Claude Code style line breaks.

#### Rationale

-

#### Acceptance Criteria

- [x] AC-1: AC-1: 데스크톱에서 Enter 와 Ctrl/Cmd+Enter 는 보내고, Shift+Enter 는 줄을 바꾼다. 줄 끝에 \ 를 입력하고 Enter 를 누르면 \ 를 지우고 줄을 바꾼다(Claude Code 와 같다). 모바일에서 Enter 는 줄바꿈이고 전송 버튼으로 보낸다.
- [x] AC-2: AC-2: IME 조합 중의 Enter 는 보내지 않는다. 공백뿐인 초안은 보내지 않는다.
- [x] AC-3: AC-3: 보내기는 기존 터미널 붙여넣기 경로(정제·크기 상한·여러 줄 가드)로 본문을 한 번에 쓰고 이어 Enter 를 보낸다. 성공하면 입력창을 비우고 포커스는 입력창에 남는다.
- [x] AC-4: AC-4: 보내기에 실패하면 초안을 그대로 두고 입력창 위에 이유를 한 줄로 보인다.
- [x] AC-5: AC-5: 초안은 세션별로 브라우저에 저장되어 새로고침 뒤에도 남는다. 빈 입력창에서 첫 줄의 ↑ / ↓ 는 그 세션에서 보낸 최근 50개를 차례로 불러온다. Esc 는 PTY 에 아무것도 보내지 않고 포커스를 터미널로 옮긴다.
- [x] AC-6: 데스크톱에서 입력창이 열린 세션의 터미널을 그냥 클릭하면 포커스가 그 세션의 입력창으로 간다. 클릭은 지금처럼 터미널(마우스를 쓰는 프로그램 포함)에 전달된다. 끌어서 텍스트를 선택했거나, 왼쪽 버튼이 아니거나, 입력창이 닫혀 있으면 포커스를 옮기지 않는다. 입력창의 Esc 는 포커스를 터미널로 돌려준다.
