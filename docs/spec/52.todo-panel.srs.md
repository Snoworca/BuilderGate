### FR-TODO-001 — 할 일 목록을 서버에 저장하고 절대 id 를 매긴다

#### Requirement

The server shall keep one to-do list for the whole server, stored on disk, whose items form at most three levels (category, item, sub-item) and each carry an absolute numeric id that grows by one for every item created and is never reused.

#### Rationale

-

#### Acceptance Criteria

- [x] AC-1: 할 일 목록은 서버 전체에 하나이며 서버 데이터 폴더의 파일에 저장되어 서버를 다시 시작해도 남는다.
- [x] AC-2: 항목을 만들 때마다 id 가 1씩 커진다. id 는 계층 경로(1.2)가 아니라 절대 정수이며, 지운 항목의 id 는 다시 쓰지 않는다.
- [x] AC-3: 계층은 대분류(부모 없음), 항목(대분류의 자식), 세부항목(항목의 자식) 세 단계까지다. 세부항목 아래에 자식을 만들려고 하면 거부한다.
- [x] AC-4: 항목은 제목, 상세 설명, 완료 여부를 가진다. 제목은 비울 수 없다. 항목을 지우면 그 아래 항목도 함께 지워진다.
- [x] AC-5: 목록이 바뀌면 연결된 모든 브라우저에 알려 화면이 곧바로 갱신된다.
- [x] AC-6: 목록 전체는 메모리에 있고, 변경은 디스크 쓰기를 기다리지 않고 곧바로 응답·알림된다. 변경은 저장 큐에 쌓여 비동기로 파일에 쓰이며, 쓰는 중에 들어온 변경은 모아서 최신 상태 한 번으로 쓴다. 쓰기가 실패하면 다음 쓰기에서 다시 시도하고, 서버를 정상 종료할 때 남은 변경을 모두 쓴다.
- [x] AC-7: 항목은 누가 올렸는지를 기록한다. 패널에서 만든 항목은 사용자, MCP 로 만든 항목은 그 세션(이름과 sessionKey)이다. 세션에 묶이지 않은 MCP 호출은 MCP 로 기록한다.

### FR-TODO-003 — 대분류·항목·세부항목을 보여 주고 완료된 것을 보이거나 숨긴다

#### Requirement

The to-do panel shall show categories with their items and sub-items, each with its id, let the user add, complete and delete them, and let the user show or hide completed entries for the whole list from a toggle at the top and for one category from an icon at its right.

#### Rationale

-

#### Acceptance Criteria

- [x] AC-1: 대분류 아래에 항목, 항목 아래에 세부항목이 들여쓰기되어 보이고, 모든 줄에 절대 id(#n)가 보인다.
- [x] AC-2: 새 대분류를 추가할 수 있고, 대분류와 항목에서 하위 항목을 추가할 수 있다. 줄의 체크박스로 완료를 바꾸고, 지울 수 있다.
- [x] AC-3: 상단에 '완료된 것 보기 / 보지 않기' 토글이 있다. 보지 않기면 완료된 줄이 숨겨진다.
- [x] AC-4: 대분류마다 오른쪽에 '완료된 것 보기 / 보지 않기' 아이콘이 있어 그 대분류의 완료된 줄만 따로 보이거나 숨긴다. 상단 토글을 바꾸면 대분류별 설정은 상단 토글을 따른다.
- [x] AC-5: 보기 설정은 브라우저에 저장된다.
- [x] AC-6: 대분류(첫 단계) 줄의 제목은 항목·세부항목보다 큰 글꼴로 보여 목록의 구획이 한눈에 드러난다.
- [x] AC-7: 줄마다 제목 옆에 올린 쪽을 작은 라벨로 보여 준다. 사용자가 올렸으면 사용자 라벨, 세션이 올렸으면 그 세션 이름이다.
- [x] AC-8: 줄마다 하위 항목 추가 버튼과 별도로 같은 단계에 항목을 추가하는 버튼이 있다. 대분류 줄에서는 새 대분류를 추가한다.
- [x] AC-9: 패널을 열고 목록을 처음 받기 전까지는 목록 자리에 '불러오고 있습니다' 를 보여 준다. 받은 뒤 비어 있을 때만 빈 목록 안내를 보여 준다.
- [x] AC-10: 대분류 → 항목 → 세부항목이 왼쪽의 점선 트리로 이어진다. 선은 부모 표시(아이콘이나 체크박스) 아래에서 내려와 각 하위 줄의 표시 왼쪽으로 꺾이고, 마지막 하위 줄에서 끝난다. 상세 설명 상자가 끼어도 끊기지 않으며, 글자 크기·패널 너비가 바뀌면 다시 그린다.
- [x] AC-11: 대분류 줄의 체크박스 자리에는 상태 아이콘이 있다. 완료면 원 안의 V, 진행 중이면 하위 항목의 완료 비율만큼 차는 원(비율이 0 이어도 조금은 찬다)이다. 누르면 완료/진행 중이 바뀐다. 대분류 오른쪽에 하위 완료 수(완료/전체)를 작게 보인다.
- [x] AC-12: 항목·세부항목의 체크박스는 브라우저 기본 모양이 아니라 앱 색으로 그린다. 체크 안 됨은 어두운 바탕에 둥근 테두리, 체크됨은 어두운 남색 바탕에 연한 파랑 V 이며, 키보드 포커스에는 강조색 테두리가 생긴다.
- [x] AC-13: 제목이 줄 폭보다 길면 ... 으로 자르지 않고 다음 줄로 넘겨 전부 보여 준다. 체크박스·상태 아이콘·id·라벨과 마우스를 올렸을 때의 버튼은 제목의 첫 줄에 맞춘다.

The to-do panel shall show each entry's detail directly under the entry, let the user add or edit it in place from a button on the row, hide it per entry, edit the title in place, and offer the row actions from a right-click context menu; the panel shall have no fixed detail area at its bottom.

#### Acceptance Criteria

- [x] AC-1: 패널 하단의 고정 상세 영역은 없다. 상세 설명이 있는 항목은 줄 바로 아래, 제목 시작 위치에 맞춰 들여 쓴 상자에 설명 전체를 보여 주고 제목 옆에 메모 표시가 붙는다.
- [x] AC-2: 줄의 상세 설명 버튼(설명이 없으면 추가, 있으면 고치기)이나 설명 상자를 누르면 그 자리에 입력칸이 열린다. 입력칸은 설명 상자와 같은 위치와 폭이며, 글이 늘면 칸이 커지다가 정해진 높이를 넘으면 아주 얇은 스크롤 막대로 스크롤된다.
- [x] AC-3: Ctrl+Enter 나 저장으로 저장하고 Esc 나 취소로 닫는다. 설명 지우기로 설명을 없앤다. 저장이 거부되면 입력한 내용이 남고 오류가 보인다. 저장하면 다른 브라우저에도 반영된다.
- [x] AC-4: 설명 상자에 마우스를 올리면 숨기기가 나와 그 항목의 설명만 숨긴다. 제목 옆 메모 표시를 누르면 다시 보인다. 숨김 상태는 브라우저에 저장된다.
- [x] AC-5: 제목은 줄을 더블클릭해 그 자리에서 고친다. Enter 로 저장하고 Esc 로 취소한다.

- [x] AC-7: 패널 안 어디서 오른쪽 버튼을 눌러도 앱의 메뉴가 열린다. 상세 설명 상자에서는 그 항목의 메뉴, 목록의 빈 곳과 머리글에서는 대분류 추가·완료된 것 보기/숨기기·글자 크게/작게 메뉴다. 입력칸 안에서는 브라우저 기본 메뉴(복사·붙여넣기)를 그대로 둔다.

- [x] AC-9: 있던 상세 설명을 없애는 저장(설명 지우기, 또는 내용을 모두 지우고 저장)은 앱 안의 모달로 먼저 확인한다. 취소하면 입력칸과 내용이 그대로 남는다.

#### Requirement

시스템은 할 일 패널에서 하위 항목이 있는 대분류와 항목을 접고 펼칠 수 있게 해, 여러 프로젝트를 대분류로 나눠 두어도 지금 보는 것만 펼쳐 볼 수 있게 해야 한다.

#### Rationale

사용자가 여러 프로젝트를 진행하면서 프로젝트마다 대분류를 두려 하는데, 모든 대분류가 항상 펼쳐져 목록이 길어진다. 결정: 대분류를 프로젝트 단위로 쓰고 접기를 더한다(4단 확장은 하지 않음).

#### Acceptance Criteria

- [x] AC-1: 하위 항목이 있는 대분류와 항목 행의 상태 표시 왼쪽에 접기/펼치기 버튼이 있고, 누르면 그 아래의 모든 행(상세 설명 포함)을 숨기거나 다시 보인다. 버튼은 aria-expanded 로 상태를 알리고, 하위 항목이 없는 행은 같은 폭을 비워 정렬을 맞춘다
- [x] AC-2: 접힌 행은 숨겨진 하위 항목 수를 제목 옆에 보인다
- [x] AC-3: 접힘 여부는 항목 id 별로 할 일 패널 상태와 함께 localStorage 에 저장되어 새로고침 뒤에도 유지되고, 저장값이 잘못되었거나 저장소를 쓸 수 없으면 모두 펼친 상태로 시작한다
- [x] AC-4: 접힌 항목 아래에 자식을 추가하거나 드래그로 안에 넣으면 그 항목을 펼친다
- [x] AC-5: 점선 트리는 보이는 행만 잇고, 대분류의 진행 원은 접혀 숨은 항목까지 세어 그린다
- [x] AC-6: 버튼의 title 과 aria-label 문장은 i18n 카탈로그(en, ko)를 거친다
