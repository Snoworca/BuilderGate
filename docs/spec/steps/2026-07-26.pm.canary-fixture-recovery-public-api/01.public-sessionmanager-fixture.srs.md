#### Requirement

BuilderGate test infrastructure shall provide a public-API-only SessionManager fixture that deterministically observes session creation, fake-PTY registration, PowerShell resolution and cleanup without changing runtime behavior.

#### Rationale

The prior fixture proof depended on untracked private helpers. A public-only fixture makes lifecycle regression evidence reproducible without modifying production behavior.

#### Acceptance Criteria

- [ ] AC-1: The focused public-fixture test has a recorded module-absence RED before fixture implementation.
- [ ] AC-2: The fixture calls public createSession once and observes one fake-PTY spawn and one onData registration.
- [ ] AC-3: The createSession DTO id and getSession(created.id) DTO id match without private SessionManager state access.
- [ ] AC-4: Public deleteSession removes the session from getSession and releases every fixture-owned fake-PTY callback.
- [ ] AC-5: The fixture leaves the superseded fixture path, existing untracked Canary monolith, production imports, and PERF-BGSTAB-010 lifecycle unchanged.
- [ ] AC-6: The fake PTY observes powershell.exe and the public PowerShell argument prefix when the fixture requests powershell on win32.
