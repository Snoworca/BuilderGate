## 1. Scope Overview

세션의 작업 폴더가 git 저장소일 때, 세션 하단바에 브랜치 칩을 보여 주고, 칩에서 Git 그래프 창과 diff 를 연다. IDE 없이 코딩 에이전트로 작업할 때 무엇이 바뀌었는지 보기 위한 읽기 전용 기능이다.

- 설계 시안: [docs/design/git-viewer.html](../design/git-viewer.html)
- 구현 계획: [docs/plan/2026-10-23.git-viewer.plan.md](../plan/2026-10-23.git-viewer.plan.md) (설계에서 바꾼 것 D1~D6 포함)
- 에픽: #164

## 2. Scope Boundaries

### In Scope

- 세션 하단바의 브랜치 칩(브랜치, 변경 수, ahead/behind, 진행 중 작업)
- Git 창: 커밋 그래프(현재·전체·기준 비교), 커밋 상세, 파일 목록, diff
- 서버의 읽기 전용 git API(summary·status·log·commit·diff·compare)

### Out of Scope

- 쓰기 작업: stage, commit, discard, checkout, branch 생성, fetch
- 구문 강조, 이미지 전후 비교, 비 UTF-8 내용 표시(v1.1 이후)
- WS push 와 `.git` 감시(v1.1. v1 은 보이는 동안만 REST 폴링)
- 서브모듈 내부, 중첩 저장소

## 3. Assumptions and Constraints

- 서버 PC 에 git 2.30 이상이 있다. WSL 세션은 WSL 안의 git 을 쓴다.
- `server/src/ws/WsRouter.ts` 는 봉인된 소스라 v1 에서 고치지 않는다.

#### Requirement

The system shall show, in the bottom bar of each terminal session whose working directory is inside a git repository, a branch chip with the branch name, the number of changed paths and the ahead/behind counts.

#### Rationale

-

#### Acceptance Criteria

- [ ] AC-1: 저장소 세션은 첫 summary 응답 즉시 칩을 표시한다. 저장소가 아닌 세션은 하단바 DOM 이 지금과 같다(스냅샷 테스트).
- [ ] AC-2: 분리 HEAD 는 7자 sha 와 경고색, 진행 중 작업은 번역된 이름(병합 중, 리베이스 i/n 등)을 표시한다.
- [ ] AC-3: ●n 의 n 은 서로 다른 경로 수다(같은 파일의 스테이징·미스테이징을 한 번만 센다).
- [ ] AC-4: upstream 이 없으면 ↑ 를 기준 브랜치 대비로 ≈↑ 형식으로 표시하고 툴팁에 밝힌다.
- [ ] AC-5: 칩 aria-label 에 브랜치 전체 이름·변경 수·앞섬/뒤처짐이 폭 단계와 무관하게 들어간다.

### FR-GIT-009 — 갱신과 선택 유지

| Field | Value |
| --- | --- |
| Type | functional |
| Target | git-viewer |
| Status | planned |
| Priority | high |
| Tags | - |

#### Requirement

The system shall refresh the chip and the Git window by visibility-scoped polling and keep the selection by commit sha and file path.

#### Rationale

-

#### Acceptance Criteria

- [ ] AC-1: 세션 tab.status 가 running 이면 3초, idle 이면 10초, Git 창이 열려 있으면 3초마다 갱신한다. status 전이와 cwd 변경 때는 즉시 갱신한다(E2E: 출력을 계속 내는 프로세스가 파일을 쓰면 칩이 늘어난다).
- [ ] AC-2: summary 가 1초를 넘는 저장소는 간격을 (걸린 시간 × 5, 최대 30초)로 늘리고, 같은 결과가 10번 연속이면 10초로 늘린다.
- [ ] AC-3: 선택은 sha 와 (영역, 경로)로 유지하고 새 커밋이 들어와도 같은 행이다.
- [ ] AC-4: 보고 있는 diff 는 status 의 inputs 가 diff 응답의 inputs 와 다를 때만 배지를 띄우고(스테이징됨 보기 중 작업 트리만 바뀌면 배지 없음), role=status 로 한 번 알린다.
- [ ] AC-5: 선택한 sha 가 사라지면 "브랜치에 없음" 행과 배너를 띄우고 내용을 유지한다. .git 이벤트 1초 반영은 v1.1 이다.
