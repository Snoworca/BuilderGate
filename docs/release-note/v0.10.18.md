# BuilderGate v0.10.18

## English

### Added

- **Open file paths printed in the terminal.** When a coding agent prints a path such as
  `docs/design/main.html`, you can open it straight from the terminal. It opens the way a
  double click in the file explorer does: HTML in the HTML viewer, images and SVG in the image
  viewer, code and Markdown in the editor. (#146, FR-ARCH-012, FR-ARCH-013)
  - Desktop: Ctrl+click (Cmd+click on macOS) a path. The path is underlined only while the key
    is held; a plain click and drag selection work as before.
  - Long press or right click: the terminal menu starts with **Open {file}** for the nearest
    path, and a **Files on screen** submenu lists the paths currently visible. In tab and grid
    mode alike.
  - Relative paths resolve against the session's current folder, line suffixes such as
    `src/App.tsx:42` are dropped, and a path wrapped onto two lines is read as one. A file that
    does not exist or cannot be opened shows the reason instead of an empty editor.

- **New file in the file explorer.** **New file** sits directly above **New folder** in the
  context menu and in the phone's **More** sheet. It opens a window with the target folder and
  a name field. (#153, FR-FEX-029, FR-FOP-008)
  - The name is checked as you type. An empty name, `/` or `\`, `.` and `..`, and a name that
    is already in the folder (file or folder) are refused.
  - The server creates the file only if the name is free and never overwrites. If the name
    appeared since the folder was listed, the window stays open and says so.
  - The new file is selected and scrolled into view. It is not opened in the editor.

- **Drag to move or copy in the file explorer (desktop).** Drag entries onto a folder to move
  them; hold Ctrl (Option on macOS) when you drop to copy them. (#154, FR-FEX-030)
  - A selected row carries the whole selection, so several entries go at once.
  - Drop on a folder row, on a folder name in the path bar, or on empty space (the folder on
    screen). Hold over a folder for a moment to enter it, or over another tab to switch to it.
  - A chip at the bottom says **Move to …** or **Copy to …**, or why a drop cannot land: onto
    the entry itself, into a folder being dragged, or into the folder the entries are already
    in.
  - The job is the same as paste, so progress and the name-conflict questions are unchanged.
    The clipboard is not touched.
  - Phones and other touch screens have no drag; use select, cut or copy, and paste.
    Dragging files in from the operating system still uploads them.

### Changed

- **Mobile: the file explorer fills the screen.** On a phone it opened as a small floating
  window; it now fills the terminal area like the editor, without a maximize button. Desktop
  windows are unchanged. (#152, FR-FEX-028)

- **Settings button is a gear.** The old drawing (a hub with spokes) read as a sun.
  (FR-UIDS-001)

- **Mobile: header buttons are closer together.** The buttons are 36 px instead of 44 px on
  phones (32 px at 340 px wide and below), so the icons sit closer and more of the workspace
  name shows. (FR-UIDS-011)

## 한국어

### 추가

- **터미널에 출력된 파일 경로를 바로 엽니다.** 코딩 에이전트가 `docs/design/main.html` 같은
  경로를 출력하면 터미널에서 바로 열 수 있습니다. 파일 탐색기에서 더블클릭한 것과 같이 열립니다.
  HTML 은 HTML 뷰어, 이미지와 SVG 는 이미지 뷰어, 코드와 마크다운은 편집기로 엽니다. (#146,
  FR-ARCH-012, FR-ARCH-013)
  - PC: 경로를 Ctrl+클릭(macOS 는 Cmd+클릭)합니다. 키를 누르고 있는 동안만 경로에 밑줄이
    보이며, 그냥 클릭과 드래그 선택은 전과 같습니다.
  - 길게 누르기나 우클릭: 터미널 메뉴 맨 위에 가장 가까운 경로의 **{파일} 열기**가 나오고,
    **화면의 파일** 하위 메뉴에 지금 보이는 경로가 모입니다. 탭·그리드 모드 모두 됩니다.
  - 상대 경로는 그 세션의 현재 폴더를 기준으로 찾습니다. `src/App.tsx:42` 같은 줄 번호는 떼고,
    두 줄로 꺾인 경로는 하나로 읽습니다. 없거나 열 수 없는 파일이면 빈 편집기 대신 이유를
    알려 줍니다.

- **파일 탐색기에서 새 파일 만들기.** 컨텍스트 메뉴와 휴대폰 **더보기** 시트에서 **새 폴더**
  바로 위에 **새 파일**이 있습니다. 위치와 이름 칸이 있는 창이 뜹니다. (#153, FR-FEX-029,
  FR-FOP-008)
  - 이름은 입력할 때마다 확인합니다. 빈 이름, `/` 나 `\`, `.` 과 `..`, 그 폴더에 이미 있는
    이름(파일·폴더 모두)은 만들지 않습니다.
  - 서버는 이름이 비어 있을 때만 만들고 덮어쓰지 않습니다. 목록을 읽은 뒤에 같은 이름이
    생겼으면 창을 닫지 않고 알려 줍니다.
  - 만든 파일은 선택해서 화면에 보이게 합니다. 편집기에서 열지는 않습니다.

- **파일 탐색기에서 끌어서 이동·복사 (데스크톱).** 항목을 폴더에 끌어 놓으면 이동하고, 놓을 때
  Ctrl(macOS 는 Option)을 누르고 있으면 복사합니다. (#154, FR-FEX-030)
  - 선택된 행을 끌면 선택한 항목이 모두 함께 갑니다.
  - 폴더 행, 경로 막대의 폴더 이름, 목록의 빈 곳(보고 있는 폴더)에 놓을 수 있습니다. 폴더 위에
    잠시 머무르면 그 폴더로 들어가고, 다른 탭 위에 머무르면 그 탭으로 바뀝니다.
  - 아래쪽 칩에 **이동 → …** 또는 **복사 → …**, 또는 놓을 수 없는 이유가 나옵니다. 끄는 항목
    자신, 끄는 폴더의 안쪽, 항목이 이미 있는 폴더에는 놓을 수 없습니다.
  - 서버 작업은 붙여넣기와 같아서 진행 표시와 이름 충돌 질문이 그대로입니다. 클립보드는
    바꾸지 않습니다.
  - 휴대폰 같은 터치 화면에서는 끌기가 없습니다. 선택 → 잘라내기/복사 → 붙여넣기를 쓰세요.
    OS 에서 파일을 끌어 오는 업로드는 그대로입니다.

### 변경

- **모바일: 파일 탐색기가 화면을 채웁니다.** 휴대폰에서 작은 떠 있는 창으로 열리던 것을, 편집기처럼
  터미널 영역을 채우게 했습니다. 최대화 버튼은 없습니다. 데스크톱 창은 그대로입니다. (#152,
  FR-FEX-028)

- **설정 버튼을 톱니바퀴로 바꿨습니다.** 예전 그림(가운데 원과 살)은 해처럼 보였습니다.
  (FR-UIDS-001)

- **모바일: 헤더 버튼 간격을 좁혔습니다.** 휴대폰에서 버튼을 44px 대신 36px(340px 이하 폭에서는
  32px)로 줄여 아이콘이 가까워지고 워크스페이스 이름이 더 길게 보입니다. (FR-UIDS-011)
