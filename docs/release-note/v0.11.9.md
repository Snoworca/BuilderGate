# BuilderGate v0.11.9

## English

### Fixed

- **The ? badge stays on while a choice is still unanswered.** (FR-AITUI-024 AC-3, AC-6, #246)
  - Scrolling a waiting Claude Code menu no longer clears the ?. When the menu was scrolled so its
    footer or options left the screen ("Waiting for your answer (ctrl+End)" in their place), the next
    check saw no menu and dropped the mark.
  - In a form of several questions, answering one and stopping keeps the ?. Before, Enter on the first
    question cleared it although the form only moved on to the next one.
  - The ? now goes off only when the agent is shown moving on (working, back at its input box, or a
    shell prompt) or the session ends. Submitting the last answer clears it about a second later; Esc
    clears it too. There is no timeout, so a question left for hours keeps its ?.

## 한국어

### 수정

- **답하지 않은 선택지가 남아 있는 동안 ? 가 계속 표시됩니다.** (FR-AITUI-024 AC-3, AC-6, #246)
  - 답을 기다리는 Claude Code 메뉴를 스크롤해도 ? 가 꺼지지 않습니다. 메뉴의 안내 줄이나 선택지가
    화면 밖으로 밀리면(그 자리에 「Waiting for your answer (ctrl+End)」 가 표시됨) 다음 판정에서 메뉴가
    없는 것으로 보고 ? 를 지웠기 때문입니다.
  - 질문이 여러 개인 양식에서 하나만 답하고 멈춰도 ? 가 유지됩니다. 이전에는 첫 질문에서 Enter 를
    누르면, 양식이 다음 질문으로 넘어갈 뿐인데도 ? 가 꺼졌습니다.
  - 이제 ? 는 에이전트가 메뉴를 떠난 화면(작업 중, 입력 줄로 복귀, 셸 프롬프트)이 보이거나 세션이 끝날
    때만 꺼집니다. 마지막 답을 제출하면 1초 남짓 뒤에 꺼지고, Esc 로 취소해도 꺼집니다. 시간 제한은
    없으므로 몇 시간 기다리는 질문도 ? 가 유지됩니다.
