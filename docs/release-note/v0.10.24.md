# BuilderGate v0.10.24

## English

### Fixed

- **Terminal output is sent in the compact binary format again.** (MIG-BGSTAB-004)
  - v0.10.21 to v0.10.23 shipped a setting that made the server fall back to the larger JSON
    format for terminal output. It did so without an error.
  - The JSON format is heavier for a browser with many terminal sessions. This can make the
    terminals redraw one after another when you open a busy workspace.
  - The binary format is the default again. A release check now stops a build that loses it.

## 한국어

### 수정

- **터미널 출력을 다시 작은 binary 형식으로 보냅니다.** (MIG-BGSTAB-004)
  - 0.10.21~0.10.23 에는 서버가 터미널 출력을 더 큰 JSON 형식으로 보내게 하는 설정이 들어가
    있었습니다. 오류도 나지 않았습니다.
  - JSON 형식은 터미널 세션이 많은 브라우저에 부담이 큽니다. 그래서 세션이 많은
    워크스페이스를 열 때 터미널이 차례로 다시 그려질 수 있습니다.
  - binary 형식이 다시 기본값입니다. 이 설정을 잃은 빌드는 이제 릴리즈 전 검사에서 막힙니다.
