# BuilderGate v0.10.35

## English

### Fixed

- **Backspace during a Hangul composition on Windows no longer deletes the character before.**
  (FR-BGSTAB-038, #220)
  - In Chrome on Windows, typing 아니 and pressing Backspace twice left an empty line instead
    of 아. Chrome removes the last jamo of a composition with an edit that says it is not
    composing, and BuilderGate sent a delete for it to the terminal.
  - Edits between the start and the end of a composition are now left to the composition. The
    macOS Safari IME, the iPhone keyboard and dictation work as before.
- **A tab switch on the phone keeps the phone's terminal size while the desktop is idle.**
  (REL-BGSTAB-011, REL-BGSTAB-058, #214)
  - With the same workspace open on a desktop, switching BuilderGate tabs on an iPhone and back
    drew the terminal at the desktop's width until the keyboard was opened and closed.
  - The phone's size is now applied, and a desktop terminal shown only because another screen
    switched tabs no longer sends its own size back. When both screens are used, the size follows
    the one used last.

### Added

- **Copy terminal text on a touch screen.** (FR-ARCH-017, #219)
  - The terminal draws on a canvas, so a phone shows no selection handles over it and the menu's
    Copy was always disabled.
  - On a touch screen the terminal menu (long press or double tap) now has **Select text**. It
    opens the terminal text as plain text, where the system's own selection handles and copy
    work, and **Copy all** copies everything. The desktop menu is unchanged.
- **Open BuilderGate from the iPhone home screen without the browser bars.** (FR-ARCH-016, #221)
  - In Safari, Share › Add to Home Screen adds a BuilderGate icon. Opened from it, BuilderGate has
    no address bar or toolbar, so the terminal gets those rows back.
  - It is the same page from the same server, so workspaces and sessions continue from the
    desktop. The home-screen app signs in once on its own. Safari tabs and the desktop are
    unchanged.

## 한국어

### 수정

- **Windows에서 한글 조합 중 Backspace가 앞 글자까지 지우지 않습니다.** (FR-BGSTAB-038, #220)
  - Windows Chrome에서 **아니**를 입력하고 Backspace를 두 번 누르면 **아**가 남아야 하는데 줄이
    비었습니다. Chrome은 조합 중인 마지막 자모를 "조합 중이 아님"으로 표시된 삭제로 지우는데, BuilderGate가
    이것을 터미널에 지우기로 한 번 더 보냈기 때문입니다.
  - 이제 조합이 시작되고 끝날 때까지의 변화는 조합에 맡깁니다. 맥 Safari 한글 입력, 아이폰 키보드,
    음성 입력은 전과 같습니다.
- **PC가 가만히 있을 때 휴대폰에서 탭을 바꿔도 휴대폰의 터미널 크기가 유지됩니다.**
  (REL-BGSTAB-011, REL-BGSTAB-058, #214)
  - PC에 같은 워크스페이스를 열어 둔 채 아이폰에서 BuilderGate 탭을 바꿨다 돌아오면, 키보드를 올렸다
    내릴 때까지 터미널이 PC 폭으로 그려져 글자 배치가 깨졌습니다.
  - 이제 휴대폰의 크기가 반영되고, 다른 화면의 탭 전환 때문에 다시 보인 PC 터미널은 자기 크기를 다시
    보내지 않습니다. 두 화면을 함께 쓰면 크기는 마지막으로 조작한 쪽을 따릅니다.

### 추가

- **터치 화면에서 터미널 글자를 복사할 수 있습니다.** (FR-ARCH-017, #219)
  - 터미널은 글자를 캔버스에 그리기 때문에 휴대폰에서는 선택 손잡이가 나오지 않았고, 메뉴의 복사가 늘
    꺼져 있었습니다.
  - 이제 터치 화면의 터미널 메뉴(길게 누르기 또는 두 번 탭)에 **텍스트 선택**이 있습니다. 고르면 터미널
    내용을 일반 글자로 보여 주는 창이 열리고, 그 안에서 기기 기본 선택 손잡이로 복사하거나 **모두
    복사**로 전체를 복사할 수 있습니다. PC 메뉴는 그대로입니다.
- **아이폰 홈 화면에 추가해 주소 표시줄 없이 열 수 있습니다.** (FR-ARCH-016, #221)
  - Safari에서 공유 › 홈 화면에 추가를 고르면 BuilderGate 아이콘이 생깁니다. 이 아이콘으로 열면 주소
    표시줄과 툴바가 없어서 터미널이 그만큼 더 보입니다.
  - 같은 서버의 같은 페이지라서 워크스페이스와 세션은 PC에서 하던 그대로 이어집니다. 홈 화면 앱에서는
    한 번 따로 로그인합니다. Safari 탭과 PC 화면은 바뀌지 않습니다.
