# BuilderGate v0.11.3

## English

### Changed

- **Remote links work over plain HTTP too.** (FR-MCP-027)
  - Paste the remote's MCP address as shown in its MCP settings, `http://…` included; it is saved
    as `ws://host:port/mcp/peer` for any host. An address without `http://` or `https://` is still
    tried over TLS.
  - A BuilderGate whose MCP listener runs without TLS now accepts links from other PCs. Its IP
    allowlist and the MCP key are still checked.
  - Over plain HTTP the MCP key travels unencrypted. Use it on a network you trust.

## 한국어

### 변경

- **원격 연결이 평문 HTTP 로도 됩니다.** (FR-MCP-027)
  - 상대 MCP 설정 창에 보이는 주소를 `http://…` 그대로 붙여 넣으면 됩니다. 어느 호스트든
    `ws://호스트:포트/mcp/peer` 로 저장됩니다. `http://` 나 `https://` 없이 적은 주소는 지금처럼
    TLS 로 연결합니다.
  - TLS 없이 도는 MCP 리스너도 다른 PC 의 원격 연결을 받습니다. IP 허용 목록과 MCP 키 검증은
    그대로입니다.
  - 평문 HTTP 에서는 MCP 키가 암호화되지 않고 망을 지나갑니다. 신뢰할 수 있는 망에서만 쓰세요.
