# BuilderGate v0.10.27

## English

### Changed

- **The redraw after a switch comes sooner.** (REL-BGSTAB-053)
  - After you move to another workspace or tab, the terminals are redrawn after 0.1 s by
    default (it was 1.5 s).
  - In Settings, "Screen redraw" accepts 0 to 5 seconds in 0.1 s steps. 0 redraws right after
    the switch.
  - A browser that already saved a delay keeps it. Change it in Settings if you want the new
    value.

### Fixed

- Typing 0 in the redraw delay field no longer turns into 1.5 seconds.

## 한국어

### 변경

- **전환 뒤 다시 그리기가 더 빨라졌습니다.** (REL-BGSTAB-053)
  - 다른 Workspace 나 탭으로 옮기면 기본으로 0.1초 뒤에 터미널을 다시 그립니다(전에는 1.5초).
  - 설정의 "화면 다시 그리기" 에서 0~5초를 0.1초 단위로 정할 수 있습니다. 0 이면 옮긴 즉시
    다시 그립니다.
  - 이미 대기 시간을 저장한 브라우저는 그 값을 유지합니다. 새 값을 쓰려면 설정에서 바꿔 주세요.

### 수정

- 대기 시간 칸에 0 을 입력하면 1.5초로 바뀌던 문제를 고쳤습니다.
