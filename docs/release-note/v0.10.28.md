# BuilderGate v0.10.28

## English

### Added

- **Resize the commit details in the Git window.** (FR-GIT-012)
  - Drag the bar under the commit details to make them taller or shorter. When the bar has
    focus, the Up and Down arrow keys move it by 16 px.
  - Double-click the bar to go back to the automatic height.
  - The diff below always keeps at least 120 px. If the details do not fit, they scroll.

### Changed

- **The redraw after a switch is immediate by default.** (REL-BGSTAB-053)
  - The default delay is now 0 seconds (it was 0.1 s). A browser that already saved a delay
    keeps it.

### Fixed

- **No more "input was not delivered" toast for replies the terminal sent on its own.**
  (REL-BGSTAB-057)
  - When you switched screens, the server sometimes refused short automatic replies to a
    program's query, and the toast appeared although you typed nothing. Refused typing still
    shows the toast.
- **A Windows server finds the agent session of a WSL tab.** (FR-AITUI-020)
  - Claude and Codex sessions that run inside WSL are now found from a Windows server. A
    process ID that WSL reused for another program after a restart is not taken as the
    session.

## 한국어

### 추가

- **Git 창에서 커밋 정보의 높이를 바꿀 수 있습니다.** (FR-GIT-012)
  - 커밋 정보 아래의 막대를 끌어 높이를 늘리거나 줄입니다. 막대에 포커스가 있으면 위·아래
    화살표 키로 16px 씩 움직입니다.
  - 막대를 더블 클릭하면 자동 높이로 돌아갑니다.
  - 아래의 diff 영역은 늘 120px 이상 남습니다. 커밋 정보가 다 들어가지 않으면 스크롤됩니다.

### 변경

- **전환 뒤 다시 그리기가 기본으로 즉시 일어납니다.** (REL-BGSTAB-053)
  - 기본 대기 시간이 0초가 되었습니다(전에는 0.1초). 이미 대기 시간을 저장한 브라우저는 그
    값을 유지합니다.

### 수정

- **터미널이 스스로 보낸 응답 때문에 "입력이 전달되지 않음" 토스트가 뜨지 않습니다.**
  (REL-BGSTAB-057)
  - 화면을 전환할 때 프로그램의 질의에 대한 짧은 자동 응답을 서버가 거절하는 경우가 있었고,
    아무것도 입력하지 않았는데 토스트가 떴습니다. 사용자가 입력한 내용이 거절되면 지금도
    토스트가 뜹니다.
- **Windows 서버가 WSL 탭의 에이전트 세션을 찾습니다.** (FR-AITUI-020)
  - WSL 안에서 실행 중인 Claude·Codex 세션을 Windows 서버에서 찾을 수 있습니다. WSL 을 다시
    시작한 뒤 다른 프로그램이 같은 프로세스 번호를 받으면 그 프로세스를 세션으로 보지 않습니다.
