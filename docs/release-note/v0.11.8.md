# BuilderGate v0.11.8

## English

### Fixed

- **The ? badge now shows for long choice menus.** (FR-AITUI-024 AC-1, AC-2, #245)
  - In 0.11.7 a tab waiting on a question with several described options showed no ?. Such a menu,
    with Type something / Chat about this and the border a named session draws under it, put more
    rows under the selected option than the detector allowed.
  - A menu now counts whenever its footer (Enter to select · Esc to cancel) sits at the bottom of the
    screen, however long the menu is. The server reads up to 40 bottom rows instead of 16, so a menu
    whose descriptions wrap on a narrow screen is read whole.
  - Footer words typed into an agent's input box, or quoted in its answer, do not count as a menu.
- **Tabs attached to a background Claude session come back after a restart.** (FR-AITUI-014 AC-8,
  AC-9, FR-AITUI-016 AC-9, #242)
  - A tab whose shell exited while the server was shutting down is reopened when the save still holds
    an entry for it, instead of staying stopped.
  - A `claude attach <id>` tab is saved and restored as `claude attach <id>`, no longer with a guessed
    `--resume` of another session in the same folder. When the background session has ended, the tab
    runs `claude --resume <full id>` in that session's folder.

## 한국어

### 수정

- **긴 선택 메뉴에도 ? 가 표시됩니다.** (FR-AITUI-024 AC-1, AC-2, #245)
  - 0.11.7 에서는 설명이 달린 선택지가 여러 개인 질문을 기다리는 탭에 ? 가 표시되지 않았습니다.
    Type something · Chat about this 와 이름을 붙인 세션이 메뉴 아래에 그리는 테두리까지 더해지면
    선택된 항목 아래의 줄 수가 판정 상한을 넘었기 때문입니다.
  - 이제 메뉴 안내 줄(Enter to select · Esc to cancel)이 화면 맨 아래에 있으면 메뉴 길이와 상관없이
    선택 대기로 판정합니다. 서버가 읽는 아래쪽 줄을 16줄에서 40줄로 늘려, 좁은 화면에서 설명이 여러
    줄로 접힌 메뉴도 끝까지 읽습니다.
  - 에이전트 입력 줄에 쓴 안내 문구나 답변 본문에 인용된 안내 문구는 메뉴로 판정하지 않습니다.
- **백그라운드 Claude 세션에 붙은 탭이 재시작 뒤에 되살아납니다.** (FR-AITUI-014 AC-8, AC-9,
  FR-AITUI-016 AC-9, #242)
  - 서버가 끝나는 동안 셸이 종료된 탭도, 저장본에 그 탭의 항목이 남아 있으면 멈춘 채 두지 않고 다시
    엽니다.
  - `claude attach <id>` 탭은 같은 폴더의 다른 세션을 추정한 `--resume` 이 아니라 `claude attach <id>`
    그대로 저장하고 복구합니다. 백그라운드 세션이 끝났으면 그 세션의 폴더에서
    `claude --resume <전체 id>` 를 실행합니다.
