# BuilderGate v0.11.10

## English

### Added

- **A composer under each session.** (FR-CMP-001..003)
  - Messages from rooms and MCP no longer cut into what you are typing in the terminal. Write in the
    composer between the terminal and its status row; the draft goes in as one paste followed by Enter.
  - Toggle it from the right end of the status row, with Alt+N, or from the terminal context menu.
    Enter sends and Shift+Enter breaks the line; on phones Enter breaks the line and the button sends.
  - Drag its top edge to resize. The draft and the last 50 sent entries are kept per session.
- **`buildergate.session.rename_self`** lets an agent rename its own session with the default agent
  scope. (FR-MCP-029)
- **New file next to a file**: right-clicking a file in the file explorer offers 새 파일, created in the
  folder that holds the file. (FR-FEX-029)

### Changed

- **Agent messages in a room are never held.** The limit on consecutive agent messages is removed;
  every agent message is delivered, and a room an older version left held is freed by the next agent
  message. (FR-MSG-016)

### Fixed

- **The iPhone home-screen app fills the screen.** When iOS reported the height without the status
  bar, the app sat too high with an empty strip at the bottom. (FR-ARCH-016 AC-6, #247)
- **Windows and menus in the iPhone home-screen app clear the status bar.** The messenger window can
  be closed and the workspace menu can add a workspace again. (FR-ARCH-016 AC-7, #247)
- **The messenger conversation scrolls on a phone while the keyboard is up.** The messenger window now
  ends right above the keyboard instead of running under it. (FR-MSG-013 AC-6, #248)
- **The ? badge shows for a tall question menu on a narrow tab.** A task panel under the menu, or option
  descriptions long enough to push the cursor row off screen, no longer hide the ?.
  (FR-AITUI-024 AC-1, #249)
- **The HTML view no longer turns light pages dark.** (FR-MDE-034)

## 한국어

### 추가

- **세션마다 입력창이 생겼습니다.** (FR-CMP-001..003)
  - 방과 MCP로 들어온 메시지가 터미널에 입력하던 글을 끊지 않습니다. 터미널과 상태 줄 사이의 입력창에
    글을 쓰면, 한 번에 붙여 넣은 뒤 Enter를 보냅니다.
  - 상태 줄 오른쪽 끝의 버튼, Alt+N, 터미널 우클릭 메뉴로 켜고 끕니다. Enter는 보내기, Shift+Enter는
    줄바꿈입니다. 휴대폰에서는 Enter가 줄바꿈이고 버튼으로 보냅니다.
  - 위쪽 테두리를 끌어 높이를 바꿉니다. 쓰던 글과 최근 보낸 50건은 세션마다 남습니다.
- **`buildergate.session.rename_self`**: 에이전트가 기본 권한만으로 자기 세션의 이름을 바꿀 수
  있습니다. (FR-MCP-029)
- **파일 옆에 새 파일 만들기**: 파일 탐색기에서 파일을 우클릭해도 「새 파일」이 나오며, 그 파일이 있는
  폴더에 만들어집니다. (FR-FEX-029)

### 변경

- **방에서 에이전트 메시지를 보류하지 않습니다.** 에이전트 메시지 연속 제한을 없앴습니다. 모든 에이전트
  메시지가 전달되고, 이전 버전에서 보류된 방은 다음 에이전트 메시지로 풀립니다. (FR-MSG-016)

### 수정

- **아이폰 홈 화면 앱이 화면을 가득 채웁니다.** iOS가 상태 표시줄을 뺀 높이를 주면 앱이 위로 밀리고
  아래가 비던 문제를 고쳤습니다. (FR-ARCH-016 AC-6, #247)
- **아이폰 홈 화면 앱에서 창과 메뉴가 상태 표시줄 밑에 깔리지 않습니다.** 메신저 창을 닫을 수 있고,
  워크스페이스 메뉴에서 워크스페이스를 추가할 수 있습니다. (FR-ARCH-016 AC-7, #247)
- **휴대폰에서 키보드가 올라와 있어도 메신저 대화 목록이 스크롤됩니다.** 메신저 창이 키보드 밑까지
  이어지지 않고 키보드 바로 위에서 끝납니다. (FR-MSG-013 AC-6, #248)
- **좁은 탭의 긴 질문 선택지에도 ? 표시가 뜹니다.** 선택지 아래의 작업 목록 패널이나, 설명이 길어
  커서 줄이 화면 위로 밀린 경우에도 ? 가 사라지지 않습니다. (FR-AITUI-024 AC-1, #249)
- **HTML 보기가 밝은 페이지를 어둡게 바꾸지 않습니다.** (FR-MDE-034)
