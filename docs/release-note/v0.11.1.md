# BuilderGate v0.11.1

## English

### Changed

- **A remote is linked with its MCP address and MCP key only.** (FR-MCP-024)
  - Paste the address shown at the top of the remote's MCP settings
    (`https://10.0.1.13:3333/mcp`), or just `host:port` or `host`. It is saved as
    `wss://host:port/mcp/peer`; 3333 is used when no port is written. A port you write is kept,
    `:443` included, and links saved by earlier versions keep working.
  - The certificate fingerprint field is gone. The first connection remembers the remote's
    certificate, so a self-signed certificate no longer fails with `DEPTH_ZERO_SELF_SIGNED_CERT`.
    The certificate is checked before the key is sent. If the remote shows a different
    certificate later, the link stops before sending the key, and the Remote links tab offers
    「Trust new certificate」.
  - A remote whose MCP listens on plain HTTP is refused with a hint to turn on HTTPS there.
- **The MCP key can be shown again.** (FR-MCP-024)
  - The fixed access key is now called the MCP key. Its field is masked and has Show, Hide and
    Copy buttons.
  - The key is kept encrypted with this machine's key, like remote link keys.
  - **A key made by an earlier version was stored as a hash only and cannot be shown.**
    Regenerate it once to see it. Regenerating disconnects remotes that use the old key.

### Fixed

- Session-bound MCP tokens (`open_agent`, `session.claim`) no longer expire after five minutes.
  They end when the session closes or the server restarts. `whoami` over the MCP key now
  explains that the caller is not bound to a session. (SEC-MCP-002 AC-1, IR-MCP-001 AC-2)

## 한국어

### 변경

- **원격 연결은 MCP 주소와 MCP 키만 넣으면 됩니다.** (FR-MCP-024)
  - 주소 칸에는 상대 MCP 설정 창 위쪽에 보이는 주소(`https://10.0.1.13:3333/mcp`)를 그대로
    붙여 넣거나, `호스트:포트`나 호스트만 적습니다. 저장할 때 `wss://호스트:포트/mcp/peer` 로
    바뀌며, 포트를 적지 않으면 3333 을 씁니다. 적은 포트는 `:443` 이어도 그대로 쓰고, 이전
    버전에서 저장한 링크도 그대로 동작합니다.
  - 인증서 지문 칸을 없앴습니다. 처음 연결할 때 상대 인증서를 기억하므로, 자체 서명 인증서도
    `DEPTH_ZERO_SELF_SIGNED_CERT` 없이 연결됩니다. 인증서는 키를 보내기 전에 확인합니다.
    나중에 다른 인증서가 오면 키를 보내지 않고 연결을 멈추고, 원격 연결 탭에
    「새 인증서 신뢰」 버튼이 나옵니다.
  - 상대 MCP 가 HTTP(암호화 없음)면 연결하지 않고, 상대에서 HTTPS 를 켜라고 안내합니다.
- **MCP 키를 다시 볼 수 있습니다.** (FR-MCP-024)
  - 「고정 인증키」의 이름을 「MCP 키」로 바꿨습니다. 키 칸은 가려져 있고 「보기」「숨기기」
    「복사」 버튼이 있습니다.
  - 키는 원격 링크 키처럼 이 PC 키로 암호화해 저장합니다.
  - **이전 버전에서 만든 키는 해시만 저장되어 있어 볼 수 없습니다.** 한 번 재생성하면 볼 수
    있습니다. 재생성하면 이전 키로 연결된 원격은 끊깁니다.

### 수정

- 세션에 묶인 MCP 토큰(`open_agent`, `session.claim`)이 5분 뒤 만료되지 않습니다. 세션이
  닫히거나 서버가 다시 시작될 때 끝납니다. MCP 키로 `whoami` 를 부르면 세션에 묶이지 않은
  호출자라는 사실을 설명합니다. (SEC-MCP-002 AC-1, IR-MCP-001 AC-2)
