# BuilderGate v0.11.4

## English

### Fixed

- **Claude usage collection turns on on Linux and macOS.** (FR-USAGE-003)
  - It failed with "node was not found for this Claude (node)" when node was set up by the login
    profile (`~/.local/opt/node`, nvm) and BuilderGate itself had been started without that PATH.
    BuilderGate now looks node up through a login shell, the way Claude Code in a terminal finds it.

## 한국어

### 수정

- **Linux·macOS 에서 Claude 사용량 모으기가 켜집니다.** (FR-USAGE-003)
  - node 를 로그인 프로필이 PATH 에 넣는 곳(`~/.local/opt/node`, nvm)에 설치했고 BuilderGate 를
    그 PATH 없이 띄운 경우, "node was not found for this Claude (node)" 로 실패했습니다. 이제
    BuilderGate 는 터미널의 Claude Code 와 같은 방식(로그인 셸)으로 node 를 찾습니다.
