# BuilderGate v0.11.6

## English

### Added

- **`buildergate.system.stats`: every linked server's load in one call.** (FR-MCP-028)
  - Reports CPU model, cores, usage now and over the last minute, load average, memory, free space
    of each volume, read/write speed and busy share of each physical disk, and how many sessions and
    agents run.
  - Without `server`, the connected linked servers answer too, one item each, so a leading agent can
    start new work on the least loaded server.
  - Measuring starts with the first call and stops after 10 minutes without one.
  - Disk speed is reported on Windows and Linux; macOS reports the rest.

## 한국어

### 추가

- **`buildergate.system.stats`: 연결된 서버들의 자원 상황을 한 번에 봅니다.** (FR-MCP-028)
  - CPU 이름·코어 수·현재와 최근 1분 사용률·부하 평균, 메모리, 볼륨별 남은 공간, 물리 디스크별
    읽기·쓰기 속도와 바쁨 비율, 실행 중인 세션과 에이전트 수를 알려 줍니다.
  - `server` 를 지정하지 않으면 연결된 원격 서버도 함께 답합니다(서버마다 한 항목). 총괄 에이전트가
    가장 여유 있는 서버를 골라 작업을 맡길 수 있습니다.
  - 측정은 첫 호출 때 시작하고, 10분 동안 호출이 없으면 멈춥니다.
  - 디스크 속도는 Windows 와 Linux 에서 알려 주고, macOS 는 나머지 값만 알려 줍니다.
