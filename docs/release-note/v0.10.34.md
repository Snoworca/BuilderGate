# BuilderGate v0.10.34

## English

### Fixed

- **Usage limits follow the account you are logged in to now.** (FR-USAGE-002, FR-USAGE-006,
  FR-USAGE-007, #217)
  - After switching the Claude Code login, the old account stayed in the panel and could still
    send alerts. BuilderGate now reads which account each Claude folder is logged in to and treats
    the others as logged out.
  - Logged-out accounts never send alerts and are not shown in the panel. When there are any, a
    button in the panel head opens them in a dialog with their bars. Their usage stays as it was
    at logout.
  - An account logged in from another place (for example WSL) still counts as logged in.

### Changed

- **git time limits are doubled and can be changed in Settings.** (PERF-GIT-001, #218)
  - git commands already run in the background without blocking the server. A quick query
    (status and the like) now waits up to 10 seconds instead of 5, and other commands (log, diff)
    up to 20 seconds instead of 10.
  - Change both in Settings › Sessions and files (1 second to 5 minutes). A save applies to the
    next git command.
  - An older config file has no lines for these settings. They are added inside its file manager
    section the first time you save, so saving keeps working.

## 한국어

### 수정

- **사용량 한도가 지금 로그인한 계정을 따릅니다.** (FR-USAGE-002, FR-USAGE-006, FR-USAGE-007, #217)
  - Claude Code 로그인을 바꿔도 이전 계정이 패널에 남고 알림도 보낼 수 있었습니다. 이제는 Claude 설정
    폴더마다 지금 로그인한 계정을 읽고, 나머지 계정은 로그아웃된 계정으로 다룹니다.
  - 로그아웃된 계정은 알림을 보내지 않고 패널에도 보이지 않습니다. 그런 계정이 있으면 패널 머리에 버튼이
    나오고, 누르면 그 계정들을 막대와 함께 모달로 보여 줍니다. 사용량은 로그아웃할 때의 값에서 바뀌지
    않습니다.
  - 다른 곳(예: WSL)에서 로그인돼 있는 계정은 로그아웃으로 보지 않습니다.

### 변경

- **git 시간 제한을 두 배로 늘리고 설정에서 바꿀 수 있게 했습니다.** (PERF-GIT-001, #218)
  - git 명령은 원래 서버를 막지 않고 백그라운드에서 실행됩니다. 이제 빠른 조회(status 등)는 5초 대신
    최대 10초, 그 밖의 명령(log, diff)은 10초 대신 최대 20초를 기다립니다.
  - 두 값은 설정 › 세션·파일에서 1초~5분 사이로 바꿀 수 있고, 저장하면 다음 git 명령부터 적용됩니다.
  - 기존 설정 파일에는 이 항목이 없습니다. 처음 저장할 때 파일 관리자 묶음 안에 더하므로 설정 저장은
    그대로 됩니다.
