# BuilderGate v0.10.10

## English

### Fixed

- **After an app that tracked the mouse exited in a hidden workspace, moving the mouse typed
  garbage into the shell.** Strings such as `[555;50;76M` appeared at the PowerShell prompt once a
  waiting Claude session had finished.
  - Cause: while a workspace is hidden the terminal skips the output it receives, so the app's
    exit sequences (turn mouse tracking off, leave the alternate screen) were never applied. On
    reveal, the local snapshot saved while the app was still running was restored, which brought
    the alternate screen and mouse tracking back. The screen repair that followed was rejected by
    the server as a buffer mismatch, so the stale screen and the stale modes stayed.
  - Fix: a terminal that is revealed after skipping output no longer restores its local snapshot.
    It asks the server for the current screen through repair-replay, and that screen carries the
    current modes. When a visible-output resync is already running, the existing temporary local
    restore is kept.
  - Checked in a real browser on port 2222: with the workspace hidden, tracking is off and the
    exit line is shown after the fix, where before it stayed on. The force-kill control case still
    reports tracking on, which shows the measurement is alive.

- **Code blocks in the markdown editor were barely visible and Ctrl+B did nothing.**
  - Syntax highlighting outside a block always rendered as plain text: the highlighter's default
    regex engine is WebAssembly, and the server's `script-src 'self'` policy blocks compiling it,
    which failed silently. It now uses the JavaScript regex engine, and the policy is unchanged.
  - Highlighting inside a block was off because the editor window passed no language list.
  - A fence without a language was an almost invisible pale violet; it is now grey, and the
    highlighted widget is the same grey block.
  - Clicking a highlighted widget did not place the caret, so a block could not be edited by
    clicking. The caret is now placed on the first line of code.
  - Ctrl+B wraps the selection in `**…**` and unwraps it when pressed again.

### Added

- **The settings page now shows the running version.** The header reads `BuilderGate v<version>`,
  taken from the release version baked in at build time, so it is possible to tell which version
  an installation is actually running. The text goes through the message catalogues in both
  languages.

- **Many more languages are highlighted in the markdown editor.** Inside a block: 21 bundled
  languages plus about 140 loaded on demand, with the usual aliases (`golang`, `ps1`, `svg`,
  `patch`, and so on). Languages without a CodeMirror parser (elixir, graphql, zig, …) are
  coloured from the highlighter's tokens. Outside a block: about 330 languages with the same
  aliases.

### Internal

- The SRS workflow CLI (`speckiwi` 4.0.0) is pinned as a repository dependency instead of relying
  on a globally installed copy.

## 한국어

### 수정

- **숨겨진 워크스페이스에서 마우스를 쓰는 앱이 종료된 뒤, 마우스를 움직이면 셸에 이상한 문자가
  입력되던 문제를 고쳤습니다.** 대기 중이던 Claude 세션이 끝난 뒤 PowerShell 프롬프트에
  `[555;50;76M` 같은 문자열이 나타났습니다.
  - 원인: 워크스페이스가 숨겨진 동안 터미널은 받은 출력을 건너뜁니다. 그래서 앱의 종료 출력(마우스
    추적 끄기, 대체 화면 나가기)이 적용되지 않았습니다. 다시 드러날 때는 앱이 아직 돌던 시점에
    저장된 로컬 스냅샷이 복원되어 대체 화면과 마우스 추적이 되살아났고, 뒤따른 화면 수리는 서버가
    버퍼 불일치로 거절해 낡은 화면과 모드가 그대로 남았습니다.
  - 해결: 출력을 건너뛴 채 드러나는 터미널은 로컬 스냅샷을 복원하지 않고, repair-replay 로 서버의
    현재 화면을 받습니다. 서버 화면은 현재 모드를 담고 있습니다. 진행 중인 visible-output resync 가
    있으면 기존의 임시 로컬 복원을 그대로 씁니다.
  - 실제 브라우저(2222)에서 확인했습니다. 워크스페이스를 숨긴 경우 수정 전에는 추적이 켜진 채
    남았고, 수정 후에는 추적이 꺼지고 종료 줄이 보입니다. 강제 종료 대조군은 여전히 켜진 것으로
    보고되어 측정이 살아 있음을 보여 줍니다.

- **마크다운 편집기의 코드 블록이 거의 보이지 않고 Ctrl+B 가 동작하지 않던 문제를 고쳤습니다.**
  - 블록 밖 구문 강조가 늘 평문으로 보였습니다. 강조기의 기본 정규식 엔진이 WebAssembly 인데
    서버의 `script-src 'self'` 정책이 그 컴파일을 막아 조용히 실패했습니다. 이제 JavaScript 정규식
    엔진을 쓰며, 정책은 그대로입니다.
  - 블록 안 강조는 편집기 창이 언어 목록을 넘기지 않아 꺼져 있었습니다.
  - 언어를 적지 않은 펜스는 거의 보이지 않는 연보라였고, 이제 회색으로 바뀌었습니다. 강조 위젯도
    같은 회색 블록입니다.
  - 강조 위젯을 클릭해도 캐럿이 들어가지 않아 클릭으로 편집할 수 없었습니다. 이제 첫 코드 줄에
    캐럿을 둡니다.
  - Ctrl+B 는 선택한 글에 `**…**` 를 씌우고, 다시 누르면 벗깁니다.

### 추가

- **설정 화면이 실행 중인 버전을 보여 줍니다.** 머리글에 빌드 시점의 릴리즈 버전을 담아
  `BuilderGate v<버전>` 으로 표시하므로, 설치본이 실제로 어느 버전으로 돌고 있는지 확인할 수
  있습니다. 이 문구는 두 언어의 메시지 카탈로그를 거칩니다.

- **마크다운 편집기가 훨씬 많은 언어를 강조합니다.** 블록 안에서는 기본 포함 21개와 필요할 때
  불러오는 약 140개를 지원하며, `golang`·`ps1`·`svg`·`patch` 같은 약칭도 인식합니다. CodeMirror
  파서가 없는 언어(elixir·graphql·zig 등)는 강조기의 토큰으로 색을 칠합니다. 블록 밖에서는 같은
  약칭 표와 함께 약 330개 언어를 강조합니다.

### 내부

- SRS 워크플로 CLI(`speckiwi` 4.0.0)를 전역 설치본에 의존하지 않고 저장소 의존성으로 고정했습니다.
