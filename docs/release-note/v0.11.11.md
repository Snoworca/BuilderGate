# BuilderGate v0.11.11

## English

### Added

- **A to-do panel on the right.** (FR-TODO-001..003, FR-TODO-006, FR-TODO-007)
  - One list for the whole server, kept in `data/todos.json`. Every browser sees a change at once.
  - Open it from the header button, with Alt+T, or from the terminal context menu. Drag its left
    edge to resize it. On a phone it fills the screen.
  - Entries nest three levels: category, item, sub-item. Each entry has an absolute id (#n) that grows
    by one and is never reused.
  - A dotted tree joins each entry to its parent. A category shows a pie that fills as its entries
    get done, then a check mark when the category is done, with the done/total count beside it.
  - Hide or show completed entries for the whole list, or per category.
  - Each entry's detail shows right under it. Add or edit it in place; Ctrl+Enter saves, Esc cancels.
    Hide one entry's detail with Hide, and show it again from the note mark.
  - Double-click a row to rename it. Move entries with the up/down buttons or by drag and drop,
    also under another parent.
  - Right-click anywhere in the panel for the row's or the panel's actions. Deleting an entry or
    removing a detail asks first in an in-app dialog.
  - Each entry shows who added it: you, or the session that added it over MCP.
  - The header has buttons to make the text larger or smaller.
- **To-do tools for agents.** (FR-TODO-005)
  - `buildergate.todo.list`, `add`, `update`, `move` and `delete` follow the same rules as the panel.
    Session agents hold the needed scopes by default.

### Changed

- Saving the to-do list no longer holds up the request. Changes made during a write are saved
  together, a failed write is retried, and the list is saved on shutdown. (FR-TODO-001 AC-6)

## 한국어

### 추가

- **오른쪽 할 일 패널** (FR-TODO-001..003, FR-TODO-006, FR-TODO-007)
  - 서버 전체에 목록이 하나 있고 `data/todos.json`에 저장됩니다. 바뀐 내용은 모든 브라우저에 바로
    반영됩니다.
  - 헤더 버튼, Alt+T, 터미널 오른쪽 버튼 메뉴로 엽니다. 왼쪽 가장자리를 끌어 너비를 바꿉니다.
    휴대폰에서는 화면을 가득 채웁니다.
  - 대분류, 항목, 세부항목의 세 단계입니다. 항목마다 절대 id(#n)가 있습니다. id는 1씩 커지고,
    지운 번호는 다시 쓰지 않습니다.
  - 점선 트리가 항목과 부모를 잇습니다. 대분류에는 하위 항목이 완료되는 만큼 차는 원이 보이고,
    대분류를 완료하면 V로 바뀝니다. 옆에는 완료 수(완료/전체)가 함께 보입니다.
  - 완료된 항목은 목록 전체에서, 또는 대분류별로 보이거나 숨길 수 있습니다.
  - 상세 설명은 항목 바로 아래에 보입니다. 그 자리에서 쓰고 고치며, Ctrl+Enter로 저장하고 Esc로
    취소합니다. 「숨기기」로 그 항목의 설명만 숨기고, 메모 표시를 누르면 다시 보입니다.
  - 줄을 더블클릭하면 제목을 고칩니다. 올리기·내리기 버튼이나 드래그 앤 드롭으로 순서를 바꾸고,
    다른 부모 아래로도 옮길 수 있습니다.
  - 패널 어디서나 오른쪽 버튼을 누르면 항목이나 패널의 메뉴가 열립니다. 항목을 지우거나 상세
    설명을 지울 때는 앱 안의 확인 창이 먼저 묻습니다.
  - 항목마다 올린 쪽이 작은 라벨로 보입니다. 직접 올렸으면 사용자, MCP로 올렸으면 그 세션의
    이름입니다.
  - 헤더의 버튼으로 글자를 키우거나 줄입니다.
- **에이전트용 할 일 도구** (FR-TODO-005)
  - `buildergate.todo.list`, `add`, `update`, `move`, `delete`는 패널과 같은 규칙을 따릅니다.
    세션 에이전트는 필요한 권한을 기본으로 가집니다.

### 변경

- 할 일 목록을 저장하는 동안 요청이 기다리지 않습니다. 쓰는 도중에 들어온 변경은 한 번에 모아
  쓰고, 쓰기에 실패하면 다시 시도하며, 서버를 끌 때 남은 변경을 저장합니다. (FR-TODO-001 AC-6)
