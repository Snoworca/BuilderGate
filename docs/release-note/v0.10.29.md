# BuilderGate v0.10.29

## English

### Added

- **Hold a row in the file explorer to pick it up.** (FR-FEX-032)
  - Hold a row for 0.45 s, with a mouse or a finger. The rows you carry leave the list, a card
    with the name follows the pointer, and a release over a folder, over a folder in the path
    bar or over the empty list moves them. Hold Ctrl (Option on macOS) to copy.
  - Stay over a folder for 0.7 s to open it, or over another explorer tab for 0.5 s to switch
    to it. The list scrolls near its edges.
  - Escape, or a release somewhere else, puts the rows back.
  - On touch this replaces the old press and hold. Release in place to open the row's menu,
    and double tap to open the row.
- **Drop entries on a file to move them into its folder.** (FR-FEX-033)
  - A file row now takes a drop for the folder that holds it, so you can move an entry into a
    folder that shows only files.
  - From the drop until the move ends the dropped rows stay dimmed, and the window shows how
    many entries are moving.
- **Wrap long commit subjects in the Git window.** (FR-GIT-013)
  - The tools row gains a '제목 줄바꿈' checkbox. It is off by default, this browser keeps it,
    and every Git window shares it.
  - When it is on, a long subject wraps and the row grows. The graph follows the taller row,
    so the lines still meet.
- **The editor follows the file on disk.** (FR-MDE-030)
  - The editor window checks the file of the tab you see every 2 seconds, while its new
    '자동 새로고침' toggle is on. The toggle is on by default and this browser keeps it for
    every editor window. A slow answer makes the wait longer, up to 30 s.
  - A tab without edits is read again. Markdown and code keep their scroll and view, the HTML
    viewer renders the new page, and an image shows the new image.
  - A tab with unsaved edits is not read. A bar offers 다시 불러오기 or 내 편집 유지.
  - A file that stays deleted closes its tab with a notice. A tab with unsaved edits keeps a
    bar that offers 다시 저장 or 편집 버리고 닫기.
  - The saves you make in this editor are not counted as changes.
- **Open files from other worktrees of the same repository, read-only.** (SEC-FOP-002)
  - Ctrl+click, the editor and the MCP editor tools now open a file in a sibling worktree of
    the session folder's repository (for example `d-1` next to `d`). Before, they refused any
    path outside the session folder.
  - Such a file opens read-only, with a notice that names the worktree. Blocked paths,
    blocked extensions and link checks still apply, and MCP saves stay inside the session
    folder.
- **Set the scroll speed for full-screen programs on a phone.** (FR-ARCH-015)
  - Settings offers 0.25× to 2× for a one-finger drag over a full-screen program such as
    Claude Code. The default is 1×, so nothing changes until you pick a value. This browser
    keeps it.

### Fixed

- **A phone in landscape keeps the mobile layout.** (FR-UIDS-015)
  - The layout was chosen by width alone, so a phone turned to landscape (800–930 px wide)
    got the desktop layout. One query now decides it: narrower than 768 px, or a touch screen
    at most 500 px high and 950 px wide. A tablet in landscape keeps the desktop layout, even
    when an on-screen keyboard makes it shorter.
- **The Git graph lines meet in short rows.** (FR-GIT-005)
  - The graph was drawn 28 px high in the 44 px rows of a phone, so its lines broke between
    rows. It is now drawn at the measured row height.
- **The screen no longer jumps when you switch tabs.** (REL-BGSTAB-058)
  - Every tab switch resized the terminal twice, so the program redrew twice. Now the switch
    redraws only when the terminal was resized somewhere else, for example on a phone. The
    menu, the shortcut and workspace switches still always redraw.
- **The desktop types again after a phone took over.** (REL-BGSTAB-011)
  - After a phone typed in a session, the desktop's input and resizes were refused until you
    switched tabs. The desktop's own screen now takes the session back.
- **Paths open from the iPhone terminal.** (FR-ARCH-013)
  - With the mobile Ctrl key latched, a tap on a path opens it. The mobile context menu no
    longer stays on its checking label, and path checks give up after 5 s and show the
    unchecked paths.
- **The HTML viewer works on phones.** (FR-MDE-028)
  - The toolbar scrolls from its start, so reload and the view toggle are reachable. Below
    1280 px the page is laid out 1280 px wide and scaled to fit, with a toggle for the real
    width. On a touch screen, pinch and drag zoom and pan the page instead of the whole app.

## 한국어

### 추가

- **파일 탐색기에서 행을 길게 눌러 집습니다.** (FR-FEX-032)
  - 마우스나 손가락으로 행을 0.45초 누르면 집힙니다. 집은 행은 목록에서 빠지고 이름이 적힌
    카드가 포인터를 따라오며, 폴더·경로 막대의 폴더·빈 목록 위에서 놓으면 그곳으로
    옮겨집니다. Ctrl(macOS 는 Option)을 누른 채 놓으면 복사합니다.
  - 폴더 위에 0.7초 머무르면 그 폴더가 열리고, 다른 탐색기 탭 위에 0.5초 머무르면 그 탭으로
    바뀝니다. 목록은 가장자리 근처에서 스크롤됩니다.
  - Esc 를 누르거나 다른 곳에서 놓으면 행이 제자리로 돌아갑니다.
  - 터치에서는 이 동작이 기존의 길게 누르기를 대신합니다. 제자리에서 떼면 그 행의 메뉴가
    열리고, 두 번 탭하면 행이 열립니다.
- **파일 위에 놓으면 그 파일이 든 폴더로 옮겨집니다.** (FR-FEX-033)
  - 이제 파일 행도 끌어 놓기를 받으며, 그 파일이 든 폴더가 대상이 됩니다. 파일만 보이는
    폴더로도 항목을 옮길 수 있습니다.
  - 놓은 순간부터 작업이 끝날 때까지 놓인 행은 흐리게 보이고, 창에 옮기는 항목 수가
    표시됩니다.
- **Git 창에서 긴 커밋 제목을 줄바꿈합니다.** (FR-GIT-013)
  - 도구 줄에 '제목 줄바꿈' 체크박스가 생겼습니다. 기본은 꺼짐이고, 이 브라우저에 저장되며,
    모든 Git 창이 같은 값을 씁니다.
  - 켜면 긴 제목이 줄바꿈되고 행이 길어집니다. 그래프도 길어진 행에 맞춰 그려져 선이
    이어집니다.
- **편집기가 디스크의 파일을 따라갑니다.** (FR-MDE-030)
  - 편집기 창은 '자동 새로고침' 이 켜져 있는 동안 보고 있는 탭의 파일을 2초마다 확인합니다.
    이 설정은 기본으로 켜져 있고, 이 브라우저에 저장되어 모든 편집기 창에 적용됩니다. 응답이
    늦으면 확인 간격이 최대 30초까지 늘어납니다.
  - 편집하지 않은 탭은 다시 읽습니다. 마크다운과 코드는 스크롤 위치와 보기를 그대로 두고,
    HTML 뷰어는 새 화면을 그리며, 이미지는 새 이미지를 보여 줍니다.
  - 저장하지 않은 편집이 있는 탭은 읽지 않습니다. 대신 띠가 떠서 다시 불러오기와 내 편집
    유지 중에서 고르게 합니다.
  - 지워진 채로 남아 있는 파일은 알림과 함께 탭을 닫습니다. 저장하지 않은 편집이 있으면 다시
    저장과 편집 버리고 닫기를 묻는 띠가 남습니다.
  - 이 편집기에서 한 저장은 변경으로 세지 않습니다.
- **같은 저장소의 다른 worktree 에 있는 파일을 읽기 전용으로 엽니다.** (SEC-FOP-002)
  - Ctrl+클릭, 편집기, MCP 편집기 도구가 세션 폴더와 같은 저장소의 다른 worktree(예: `d`
    옆의 `d-1`)에 있는 파일을 엽니다. 전에는 세션 폴더 밖의 경로를 모두 거부했습니다.
  - 이런 파일은 읽기 전용으로 열리며, 어느 worktree 의 파일인지 알려 줍니다. 차단 경로·차단
    확장자·링크 검사는 그대로 적용되고, MCP 의 저장은 세션 폴더 안에서만 합니다.
- **휴대폰에서 전체 화면 프로그램의 스크롤 속도를 정합니다.** (FR-ARCH-015)
  - Claude Code 같은 전체 화면 프로그램 위에서 한 손가락으로 끌 때의 속도를 설정에서
    0.25배~2배로 고릅니다. 기본은 1배라서 값을 고르기 전에는 바뀌는 것이 없습니다. 이
    브라우저에 저장됩니다.

### 수정

- **가로로 돌린 휴대폰이 모바일 화면을 유지합니다.** (FR-UIDS-015)
  - 화면 배치를 너비만으로 골랐기 때문에, 가로로 돌린 휴대폰(너비 800~930px)에 데스크톱
    배치가 나왔습니다. 이제 하나의 기준이 이것을 정합니다. 너비가 768px 보다 좁거나, 터치
    화면이면서 높이 500px·너비 950px 이하일 때 모바일 배치입니다. 가로로 둔 태블릿은 화면
    키보드가 올라와 높이가 줄어도 데스크톱 배치를 유지합니다.
- **짧은 행에서도 Git 그래프의 선이 이어집니다.** (FR-GIT-005)
  - 휴대폰의 44px 행에 그래프를 28px 높이로 그려서 행 사이에서 선이 끊겼습니다. 이제 측정한
    행 높이로 그립니다.
- **탭을 바꿀 때 화면이 위아래로 흔들리지 않습니다.** (REL-BGSTAB-058)
  - 탭을 바꿀 때마다 터미널 크기를 두 번 바꿨기 때문에 프로그램이 화면을 두 번 다시
    그렸습니다. 이제는 휴대폰처럼 다른 곳에서 터미널 크기가 바뀐 경우에만 다시 그립니다.
    메뉴·단축키·워크스페이스 전환은 지금처럼 항상 다시 그립니다.
- **휴대폰에서 입력한 뒤에도 데스크톱에서 바로 입력할 수 있습니다.** (REL-BGSTAB-011)
  - 휴대폰에서 세션에 입력하고 나면, 탭을 바꾸기 전까지 데스크톱의 입력과 크기 변경이
    거부되었습니다. 이제 데스크톱 화면이 세션을 다시 가져옵니다.
- **아이폰 터미널에서 경로를 열 수 있습니다.** (FR-ARCH-013)
  - 모바일 Ctrl 키를 고정한 상태에서 경로를 탭하면 그 경로가 열립니다. 모바일 메뉴가 확인
    중 표시에 멈춰 있지 않으며, 경로 확인은 5초가 지나면 그만두고 확인하지 못한 경로를
    보여 줍니다.
- **휴대폰에서 HTML 뷰어가 제대로 동작합니다.** (FR-MDE-028)
  - 도구 줄이 처음부터 스크롤되어 새로 고침과 보기 전환에 닿을 수 있습니다. 너비가 1280px
    보다 좁으면 페이지를 1280px 너비로 배치한 뒤 화면에 맞게 줄이며, 실제 너비로 보는 전환이
    있습니다. 터치 화면에서는 두 손가락 확대와 끌기가 앱 전체가 아니라 페이지를 확대하고
    옮깁니다.
