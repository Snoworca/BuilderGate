# BuilderGate v0.10.37

## English

### Changed

- **MCP can be opened to other machines over plain HTTP, and `*` allows every address.**
  (SEC-MCP-001, #231)
  - External access (Tools › MCP settings › Bind mode › External access) no longer requires
    TLS. HTTPS (direct TLS or a trusted proxy) is still available.
  - Write `*` in the external IP list to allow every address. `0.0.0.0/0` is still refused;
    `*` is the one way to open to everyone. The trusted proxy list never takes `*`.
  - While MCP is on, choosing HTTP for external access or adding `*` shows a warning under that
    field, and Save asks once before saving. Over HTTP the access key travels unencrypted.
  - The options now say what they do: HTTP (unencrypted), HTTPS (direct TLS), HTTPS (trusted
    proxy), External access (IP list). Choosing external access changes a `127.0.0.1` host to
    `0.0.0.0`, and choosing localhost only changes it back.

### Fixed

- **Turning MCP off and back to localhost only in one save works.** (SEC-MCP-001, #231)
  - The save failed with `MCP_LOOPBACK_ONLY`: the stopped listener's previous `0.0.0.0` host
    replaced the host you had just saved.

## 한국어

### 변경

- **MCP 를 HTTP 로도 외부에 열 수 있고, `*` 로 모든 주소를 허용할 수 있습니다.** (SEC-MCP-001, #231)
  - 외부 접근(도구 › MCP 설정 › 바인드 모드 › 외부 접근 허용)에 이제 TLS 가 필요하지 않습니다. HTTPS(직접 TLS,
    신뢰 프록시)도 그대로 쓸 수 있습니다.
  - 외부 IP 허용 목록에 `*` 를 적으면 모든 주소를 허용합니다. `0.0.0.0/0` 은 지금처럼 받지 않으며, 모두 여는 방법은
    `*` 하나입니다. 신뢰 프록시 목록에는 `*` 를 쓸 수 없습니다.
  - MCP 가 켜져 있을 때 외부 접근에 HTTP 를 고르거나 `*` 를 넣으면, 그 칸 아래에 경고가 나오고 저장할 때 한 번 더
    확인합니다. HTTP 에서는 인증키가 암호화되지 않은 채 전송됩니다.
  - 선택지 이름을 동작에 맞게 바꿨습니다: HTTP (암호화 없음), HTTPS (직접 TLS), HTTPS (신뢰 프록시),
    외부 접근 허용(IP 목록). 외부 접근을 고르면 호스트 `127.0.0.1` 이 `0.0.0.0` 으로 바뀌고, 로컬 호스트 전용으로
    돌리면 다시 `127.0.0.1` 이 됩니다.

### 수정

- **MCP 끄기와 로컬 호스트 전용 전환을 한 번에 저장할 수 있습니다.** (SEC-MCP-001, #231)
  - 그동안은 멈춘 리스너에 남아 있던 이전 호스트 `0.0.0.0` 이 방금 저장한 호스트를 덮어써서
    `MCP_LOOPBACK_ONLY` 로 저장이 거부됐습니다.
