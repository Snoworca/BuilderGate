# BuilderGate v0.11.5

## English

### Fixed

- **The Linux x64 release starts on Ubuntu 24.04 again.** (OPS-BGSTAB-024)
  - v0.11.4 stopped with "Failed to load native module: pty.node" on distributions with glibc older
    than 2.42, such as Ubuntu 24.04. The terminal module had been built against a newer glibc.
  - Linux builds now target glibc 2.39, and a release whose native modules need a newer glibc fails
    before it is published.

### 수정

- **Linux x64 릴리즈가 Ubuntu 24.04 에서 다시 실행됩니다.** (OPS-BGSTAB-024)
  - v0.11.4 는 Ubuntu 24.04 처럼 glibc 가 2.42 보다 낮은 배포판에서

    배포 전에 빌드를 실패시킵니다.
