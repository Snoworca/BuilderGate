# BuilderGate v0.10.17

## English

### Added

- **Build label in the workspace sidebar.** The foot of the workspace list shows the running
  version and the commit it was built from, for example `v0.10.17 · 1a2b3c4d`. A server that is
  still serving an old build is visible at a glance. (FR-UIDS-012)

### Changed

- **Running from a source checkout rebuilds a stale build.** `start.sh` and `start.bat` used to
  skip the build whenever a built `dist` existed, so after `git pull` or `git reset` the old
  screens kept being served. The build now records the commit it came from; when the checkout is
  at a different commit, or the record is missing, the start script rebuilds and says why.
  Packaged installs are unchanged. (#149, OPS-BGSTAB-022)

### Fixed

- **"Not Found" instead of the app.** When the server cannot find its web files it now shows a
  page saying so (HTTP 503) instead of a bare "Not Found". Opened on the same machine, the page
  shows the path that was checked; from elsewhere it points to the server log, which records the
  path. If you see it, check that no older BuilderGate process still holds the port, then
  reinstall or rebuild. (#149, OPS-BGSTAB-023)

- **Mobile: the key bar did not appear on some phones.** Browsers that shrink the page together
  with the on-screen keyboard (Samsung Internet, for example) were not recognised as having the
  keyboard up, so the key bar stayed hidden. The keyboard is now measured against the tallest
  screen height seen at the current width. (FR-MKB-013)

- **Mobile: header buttons ran off the right edge** and cut off Log out. On phones the header
  now hides the title text (the logo stays), drops the gaps between buttons and tightens its
  padding. Buttons keep their 44 px size on phones 375 px and wider, and shrink to 40 px and
  36 px on narrower screens. (#148, FR-UIDS-011)

## 한국어

### 추가

- **워크스페이스 사이드바에 빌드 표시.** 워크스페이스 목록 맨 아래에 실행 중인 버전과 빌드한
  커밋이 보입니다(예: `v0.10.17 · 1a2b3c4d`). 서버가 예전 빌드를 서빙하고 있으면 바로 알 수
  있습니다. (FR-UIDS-012)

### 변경

- **소스 체크아웃 실행 시 예전 빌드를 다시 빌드합니다.** 전에는 `start.sh`·`start.bat` 가 빌드된
  `dist` 가 있으면 빌드를 건너뛰어, `git pull`·`git reset` 뒤에도 예전 화면이 서빙되었습니다.
  이제 빌드할 때 소스 커밋을 기록하고, 체크아웃의 커밋이 다르거나 기록이 없으면 다시 빌드하며
  그 이유를 로그에 남깁니다. 설치판(패키지) 동작은 바뀌지 않습니다. (#149, OPS-BGSTAB-022)

### 수정

- **앱 대신 "Not Found" 만 나오던 문제.** 서버가 웹 파일을 찾지 못하면 빈 "Not Found" 대신 웹
  파일이 없다는 안내 페이지(HTTP 503)를 보여 줍니다. 같은 컴퓨터에서 열면 서버가 확인한 경로가
  보이고, 다른 곳에서 열면 서버 로그를 보라고 안내합니다(로그에 경로가 남습니다). 이 페이지가
  보이면 예전 BuilderGate 프로세스가 그 포트를 잡고 있지 않은지 확인한 뒤 다시 설치하거나 다시
  빌드하세요. (#149, OPS-BGSTAB-023)

- **모바일: 일부 휴대폰에서 키 줄이 나오지 않던 문제를 고쳤습니다.** 화면 키보드와 함께 페이지
  높이까지 줄이는 브라우저(예: 삼성 인터넷)에서 키보드가 올라온 것을 알아채지 못해 키 줄이 계속
  숨어 있었습니다. 이제 현재 화면 너비에서 본 가장 큰 높이를 기준으로 키보드를 판정합니다.
  (FR-MKB-013)

- **모바일: 헤더 버튼이 화면 오른쪽 밖으로 나가 로그아웃 버튼이 잘리던 문제를 고쳤습니다.** 휴대폰에서는
  헤더 제목 글자를 숨기고(로고는 남김) 버튼 간격과 여백을 줄였습니다. 375px 이상 휴대폰에서는
  버튼을 44px 로 유지하고, 그보다 좁은 화면에서는 40px·36px 로 줄입니다. (#148, FR-UIDS-011)
