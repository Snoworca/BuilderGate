# BuilderGate v0.10.25

## English

### Added

- **Screen redraw reaches every terminal of a grid.** "Redraw screen" in the grid view now
  redraws every terminal of the workspace. The chosen terminal goes first, and the others
  follow 100 ms apart. In the tab view it still redraws only the shown terminal.
  (REL-BGSTAB-053)
- **The screen is redrawn again after a switch.** About 1.5 s after you move to another
  workspace, or to another tab in the tab view, the terminals are redrawn once more. If you
  switch again before that, only the last switch is redrawn. Creating or closing a tab does
  not start a redraw.
- **Settings for the automatic redraw.** Settings has a new "Screen redraw" card. You can turn
  the redraw after a workspace switch and after a tab switch on or off, and set the delay
  (0.5 to 5 s). These settings are kept in this browser only.
- **Ctrl+Alt+R redraws the screen.** It redraws the same terminals as the menu item. It also
  works in Hangul input mode and before the shortcut settings have loaded. A keyboard where
  AltGr+R types a character still types it. "Redraw screen" is also a new action in the
  shortcut manager, so you can put it on another key. Your own binding on Ctrl+Alt+R wins.

## 한국어

### 추가

- **그리드의 모든 터미널을 다시 그립니다.** 그리드 보기에서 "화면 다시 그리기" 를 누르면
  Workspace 의 모든 터미널을 다시 그립니다. 고른 터미널이 먼저이고, 나머지는 100ms 간격으로
  이어집니다. 탭 보기에서는 지금처럼 보이는 터미널 하나만 다시 그립니다. (REL-BGSTAB-053)
- **전환한 뒤에 화면을 한 번 더 다시 그립니다.** 다른 Workspace 로 옮기거나 탭 보기에서 다른
  탭으로 옮기면, 약 1.5초 뒤에 터미널을 한 번 더 다시 그립니다. 그 전에 다시 옮기면 마지막
  전환만 다시 그립니다. 탭을 새로 만들거나 닫을 때는 다시 그리지 않습니다.
- **자동 다시 그리기 설정.** 설정에 "화면 다시 그리기" 카드가 생겼습니다. Workspace 전환 뒤와
  탭 전환 뒤의 다시 그리기를 각각 켜고 끌 수 있고, 지연 시간(0.5~5초)을 정할 수 있습니다.
  이 설정은 이 브라우저에만 저장됩니다.
- **Ctrl+Alt+R 로 화면을 다시 그립니다.** 메뉴 항목과 같은 터미널을 다시 그립니다. 한글 입력
  모드에서도, 단축키 설정을 불러오기 전에도 동작합니다. AltGr+R 로 문자를 입력하는 자판에서는
  문자가 그대로 입력됩니다. 단축키 관리자에도 "화면 다시 그리기" 동작이 생겨 다른 키에 둘 수
  있습니다. Ctrl+Alt+R 에 직접 등록한 단축키가 있으면 그것이 우선합니다.
