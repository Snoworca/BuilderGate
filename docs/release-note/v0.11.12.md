# BuilderGate v0.11.12

## English

### Fixed

- **A restored Claude session keeps its permission mode.** Sessions launched with
  `--dangerously-skip-permissions` came back in default mode after a restart when BuilderGate had not
  seen the launch command (for example, a command recalled from shell history), and every later
  restore stayed that way. A running Claude tab is now saved with the mode it actually runs in: a
  message sent since it started (Shift+Tab changes included), else the launch command, else the
  Claude process command line, else the last mode in its transcript. An ended attach session resumed
  by id gets the last mode in its transcript. (FR-AITUI-025, #253)

## 한국어

### 수정

- **복구한 Claude 세션이 권한 모드를 유지합니다.** `--dangerously-skip-permissions` 로 띄운 세션이,
  BuilderGate 가 실행 명령을 보지 못한 경우(셸 기록으로 불러온 명령 등) 재시작 뒤 기본 모드로
  돌아왔고, 그 뒤 복구도 계속 기본 모드로 이어지던 문제를 고쳤습니다. 이제 실행 중인 Claude 탭은
  실제로 쓰는 모드로 저장됩니다. 시작 뒤 보낸 메시지(Shift+Tab 변경 포함), 실행 명령, Claude 프로세스
  명령줄, 대화 기록의 마지막 모드 순서로 판단합니다. 끝난 attach 세션을 id 로 이어 열 때는 대화 기록의
  마지막 모드를 붙입니다. (FR-AITUI-025, #253)
