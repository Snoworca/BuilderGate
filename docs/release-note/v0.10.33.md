# BuilderGate v0.10.33

## English

### Fixed

- **Links in a markdown document open.** (FR-MDE-033, #216)
  - In edit mode a click on a link's text did nothing; only the small icon at its end
    worked. A click on the rendered link now opens it.
  - Web addresses (`http`, `https`, `mailto`, `tel`) open in a new browser tab. Other schemes,
    such as `javascript:`, open nothing.
  - A link to a file, such as `./PRD.md` or `../docs/a.md`, opened the BuilderGate address
    with that path in a new browser window. It now opens the file in an editor tab, resolved
    from the folder of the document you are reading.
  - To edit a link, put the cursor in it with the keyboard or double-click it. A link the
    cursor is in shows its source, and a click there edits it. A click with Ctrl, Shift, Alt
    or Cmd held also edits.

### Added

- **The editor opens more kinds of files.** (FR-MDE-013, #215)
  - Server templates (`jsp`, `asp`, `aspx`, `cshtml`, `erb`, `ejs`, `hbs`, `twig`, `njk`,
    `liquid` and others) open with HTML highlighting.
  - Ruby, Swift, Lua, Perl, Groovy/Gradle, R, Haskell, Erlang, Clojure, Julia, OCaml, F#, VB,
    Tcl, CoffeeScript, Pascal, Fortran, Protobuf, TeX, Verilog, VHDL, Elm, Crystal, Haxe, Pug,
    Gherkin, HTTP, Jinja2, NSIS, SPARQL, Turtle and SAS files open with their highlighting.
  - Text formats without a grammar (`tf`, `hcl`, `graphql`, `prisma`, `rst`, `adoc`, `org`,
    `srt`, `vtt`, `sln`, `nix`, `zig` and others) open as plain text. So do `go.mod`,
    `go.sum`, `CODEOWNERS`, `.gitkeep` and `.tool-versions`. `Pipfile`, `Podfile`,
    `Brewfile`, `BUILD.bazel` and `.clang-format` open with their highlighting.
  - Extensions with two common meanings (`v`, `pl`, `pp`, `fs`, `ftl`, `asm`) open without
    highlighting.

## 한국어

### 수정

- **마크다운 문서의 링크가 열립니다.** (FR-MDE-033, #216)
  - 편집 모드에서 링크 글자를 누르면 아무 일도 없었고, 링크 끝의 작은 아이콘만 동작했습니다. 이제 렌더된
    링크를 누르면 열립니다.
  - 웹 주소(`http`, `https`, `mailto`, `tel`)는 브라우저 새 탭으로 엽니다. `javascript:` 같은 그 밖의
    주소는 열지 않습니다.
  - `./PRD.md`, `../docs/a.md` 같은 파일 링크는 그동안 BuilderGate 주소에 그 경로를 붙여 브라우저 새
    창으로 열었습니다. 이제는 보고 있는 문서의 폴더를 기준으로 경로를 풀어 편집기 탭으로 엽니다.
  - 링크를 고치려면 키보드로 커서를 링크 안에 넣거나 링크를 더블클릭합니다. 커서가 들어간 링크는 원문이
    보이고, 그때 누르면 편집이 됩니다. Ctrl·Shift·Alt·Cmd 를 누른 채 클릭해도 편집이 됩니다.

### 추가

- **편집기로 여는 파일 종류가 늘었습니다.** (FR-MDE-013, #215)
  - 서버 템플릿(`jsp`, `asp`, `aspx`, `cshtml`, `erb`, `ejs`, `hbs`, `twig`, `njk`, `liquid` 등)은 HTML
    문법 강조로 엽니다.
  - Ruby, Swift, Lua, Perl, Groovy/Gradle, R, Haskell, Erlang, Clojure, Julia, OCaml, F#, VB, Tcl,
    CoffeeScript, Pascal, Fortran, Protobuf, TeX, Verilog, VHDL, Elm, Crystal, Haxe, Pug, Gherkin, HTTP,
    Jinja2, NSIS, SPARQL, Turtle, SAS 파일은 각 문법 강조로 엽니다.
  - 문법 강조가 없는 텍스트 형식(`tf`, `hcl`, `graphql`, `prisma`, `rst`, `adoc`, `org`, `srt`, `vtt`,
    `sln`, `nix`, `zig` 등)은 일반 텍스트로 엽니다. `go.mod`, `go.sum`, `CODEOWNERS`, `.gitkeep`,
    `.tool-versions` 도 일반 텍스트로 엽니다. `Pipfile`, `Podfile`, `Brewfile`, `BUILD.bazel`,
    `.clang-format` 은 각 문법 강조로 엽니다.
  - 뜻이 둘로 갈리는 확장자(`v`, `pl`, `pp`, `fs`, `ftl`, `asm`)는 문법 강조 없이 엽니다.
