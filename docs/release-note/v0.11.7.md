# BuilderGate v0.11.7

## English

### Fixed

- **iPad: touch scrolling and the mobile key bar work again.** (FR-ARCH-008 AC-4, FR-MKB-013 AC-5, #236)
  - Touch behaviour now follows the input device (a phone layout or a coarse pointer), not the layout,
    so an iPad that keeps the desktop layout scrolls with one finger, pinches, and shows the key bar.
- **Phone: tapping a Claude Code choice no longer raises the keyboard.** (FR-ARCH-010 AC-8, #237)
  - While the keyboard is down and the program tracks the mouse, a tap away from the input row only
    clicks. Tapping the input row still opens the keyboard.
- **iPhone home-screen app: the bottom rows (the git status line) are no longer cut off.**
  (FR-ARCH-016 AC-6, #238)
  - Only the home-screen app draws under the status bar and keeps the safe-area margins; a browser
    tab is unchanged.

### Added

- **Arrow keys without the keyboard on choice screens.** (FR-MKB-013 AC-6, #239)
  - When a program shows choices and the keyboard is down, the key bar stays docked at the bottom.
    Its keys are sent without focusing the terminal, so the keyboard stays down.
- **A ? on tabs whose agent waits on a choice.** (FR-AITUI-024, #240)
  - When a session's output stops on a choice menu (a permission request, a question), its tab shows
    an orange ? and the workspace list shows ?N. Picking or cancelling clears it at once.
  - The server reads only the last rows of the live screen when output pauses; there is no polling
    and the scrollback is never read.

## 한국어

### 수정

- **iPad 에서 터치 스크롤과 모바일 키 줄이 다시 동작합니다.** (FR-ARCH-008 AC-4, FR-MKB-013 AC-5, #236)
  - 터치 동작을 화면 배치가 아니라 입력 장치(휴대폰 배치이거나 손가락 포인터)로 판정합니다. 데스크톱
    배치를 유지하는 iPad 에서도 한 손가락 스크롤, 핀치, 키 줄을 쓸 수 있습니다.
- **휴대폰에서 Claude Code 선택지를 탭해도 키보드가 올라오지 않습니다.** (FR-ARCH-010 AC-8, #237)
  - 키보드가 내려가 있고 프로그램이 마우스를 추적하는 동안, 입력 줄에서 떨어진 곳을 탭하면 클릭만
    보냅니다. 입력 줄을 탭하면 지금처럼 키보드가 올라옵니다.
- **아이폰 홈 화면 앱에서 맨 아래(git 상태 줄)가 잘리지 않습니다.** (FR-ARCH-016 AC-6, #238)
  - 홈 화면 앱에서만 상태 표시줄 아래까지 그리고 안전 영역 여백을 둡니다. 브라우저 탭은 그대로입니다.

### 추가

- **선택지 화면에서 키보드 없이 방향키를 쓸 수 있습니다.** (FR-MKB-013 AC-6, #239)
  - 프로그램이 선택지를 보여 주고 키보드가 내려가 있으면 키 줄이 화면 아래에 고정됩니다. 키는 터미널에
    포커스를 주지 않고 보내므로 키보드가 올라오지 않습니다.
- **에이전트가 선택을 기다리는 탭에 ? 를 표시합니다.** (FR-AITUI-024, #240)
  - 세션 출력이 선택 메뉴(권한 요청, 질문)에서 멈추면 탭 이름 앞에 주황 ?, 워크스페이스 목록에 ?N 이
    표시됩니다. 선택하거나 취소하면 바로 사라집니다.
  - 서버는 출력이 멈출 때 화면의 아래쪽 줄만 읽습니다. 주기적으로 확인하지 않고 scrollback 도 읽지
    않습니다.
