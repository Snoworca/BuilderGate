# BuilderGate v0.10.32

## English

### Added

- **Usage limits under the workspace list.** (FR-USAGE-001..007, #213)
  - Thin bars show the 5-hour and weekly limits of Claude Code and Codex, one block per
    account. Each account shows its full email and plan. The bar colour follows what is left:
    green, then yellow below 40 %, then red below 15 %.
  - A window that has no record is not shown. An account whose record is older than an hour is
    greyed out.
  - The refresh button reads the records again. The gear opens the settings, which are also on
    the settings page.
  - The server reads the records on an interval you set (15–3600 seconds, 60 by default).
  - Claude Code gives its limits only to the statusline. Turning on Claude collection puts a
    small relay in front of your statusline. The relay records the limits and runs your
    statusline unchanged. Turning it off restores the original.
  - Codex limits are read from its session logs; nothing has to be installed.
  - Alerts go to a Google Chat webhook and a Telegram bot when the remaining part is below
    the percentage you set. Every refresh sends an alert, unless the value is the same as the
    previous refresh. Each channel has a test button whose result stays below it.
  - The webhook URL and the bot token are stored encrypted, and only their last 4 characters
    are shown. Alert texts name the account by its nickname, or by its full email when it has
    none.

## 한국어

### 추가

- **워크스페이스 목록 아래에 사용량 한도를 보여 줍니다.** (FR-USAGE-001..007, #213)
  - Claude Code 와 Codex 의 5시간 한도와 주간 한도를 계정마다 얇은 막대로 보여 줍니다. 계정 이름에는
    이메일 전체와 요금제가 나옵니다. 막대 색은 남은 양을 따릅니다. 넉넉하면 초록, 40 % 미만이면 노랑,
    15 % 미만이면 빨강입니다.
  - 기록이 없는 한도는 보여 주지 않습니다. 기록이 한 시간보다 오래된 계정은 흐리게 표시합니다.
  - 새로고침 버튼은 기록을 다시 읽습니다. 톱니 버튼을 누르면 설정 창이 뜹니다. 같은 설정은 설정 화면에도
    있습니다.
  - 서버는 사용자가 정한 간격으로 기록을 읽습니다(15–3600초, 기본 60초).
  - Claude Code 는 한도를 상태 표시줄(statusline)에만 넘겨 줍니다. 그래서 Claude 수집을 켜면 사용 중인
    상태 표시줄 앞에 작은 중계 스크립트를 둡니다. 이 스크립트는 한도를 기록한 뒤 원래 상태 표시줄을 그대로
    실행합니다. 수집을 끄면 원래 설정으로 되돌립니다.
  - Codex 한도는 Codex 세션 기록에서 읽으므로 따로 설치할 것이 없습니다.
  - 남은 양이 사용자가 정한 비율 미만이면 Google Chat 웹훅과 Telegram 봇으로 알림을 보냅니다. 갱신할 때마다
    보내되, 직전 갱신과 값이 같으면 보내지 않습니다. 채널마다 테스트 버튼이 있고, 결과는 버튼 아래에
    남습니다.
  - 웹훅 URL 과 봇 토큰은 암호화해 저장하고 끝 4자리만 보여 줍니다. 알림 문구에는 계정 별명이 나오고,
    별명이 없으면 이메일 전체가 나옵니다.
