# BuilderGate v0.11.13

## English

### Changed

- **A click on the terminal goes to its open composer.** When the bottom composer is open (Alt+N), a
  plain click on that session's terminal puts the caret in the composer, so you can type right away.
  The click still reaches the terminal, so programs that read the mouse get it. Focus stays on the
  terminal when you drag to select text, right-click, the composer is closed, or you are on a phone.
  Esc in the composer still returns to the terminal. (FR-CMP-003 AC-6)
- **Long to-do titles wrap.** A title that does not fit the panel now wraps onto more lines instead of
  ending in "…". (FR-TODO-003 AC-13)

### Fixed

- **The save dialog keeps a Claude tab's permission mode.** A tab switched to bypass with Shift+Tab was
  saved without the flag from the save dialog, so a restore opened it in default mode. The dialog now
  shows and saves the mode the tab runs in. (FR-AITUI-025 AC-6, #255)
- **Terminals no longer inherit the server's `NODE_ENV` and `PORT`.** A Vite dev server started in a
  tab ran as production, `npm install` skipped devDependencies, and apps that read `PORT` tried to bind
  the BuilderGate port. A session that sets these values itself still gets them. (FR-MCP-030, #257)

## 한국어

### 변경

- **터미널을 클릭하면 열린 입력창으로 포커스가 갑니다.** 하단 입력창(Alt+N)이 열려 있으면 그
  세션의 터미널을 클릭하는 것만으로 커서가 입력창에 놓여 바로 입력할 수 있습니다. 클릭은 터미널에도
  그대로 전달되므로 마우스를 읽는 프로그램도 클릭을 받습니다. 끌어서 텍스트를 선택할 때, 오른쪽
  버튼을 누를 때, 입력창이 닫혀 있을 때, 휴대폰에서는 포커스가 터미널에 남습니다. 입력창에서 Esc를
  누르면 지금처럼 터미널로 돌아갑니다. (FR-CMP-003 AC-6)
- **긴 할 일 제목이 줄바꿈됩니다.** 패널 너비를 넘는 제목은 "…"로 잘리지 않고 다음 줄로
  이어집니다. (FR-TODO-003 AC-13)

### 수정

- **저장 대화상자가 Claude 탭의 권한 모드를 유지합니다.** Shift+Tab으로 bypass 모드로 바꾼 탭을
  저장 대화상자로 저장하면 플래그가 빠져, 복구할 때 기본 모드로 열렸습니다. 이제 대화상자가 탭이
  실제로 쓰는 모드를 보여 주고 그대로 저장합니다. (FR-AITUI-025 AC-6, #255)
- **터미널이 서버의 `NODE_ENV`와 `PORT`를 물려받지 않습니다.** 탭에서 띄운 Vite 개발 서버가
  프로덕션으로 돌고, `npm install`이 devDependencies를 건너뛰고, `PORT`를 읽는 앱이 BuilderGate
  포트에 바인딩하려던 문제를 고쳤습니다. 세션에서 이 값을 직접 지정하면 그 값을 받습니다.
  (FR-MCP-030, #257)
