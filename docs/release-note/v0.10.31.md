# BuilderGate v0.10.31

## English

### Fixed

- **The server no longer runs out of memory after a day or two.** (REL-BGSTAB-061, #208)
  - Every terminal output chunk left about 320 bytes waiting on its session until the
    session closed. With about 48 sessions the heap grew from 1.2 GB to 3.56 GB in 30 hours
    and the process died. Before it died, input stalled and `git/summary` timed out.
  - Each write now lets go of its wait when it finishes.
- **One terminal's failed screen recovery no longer reconnects every terminal again and
  again.** (REL-BGSTAB-060, #208)
  - The last recovery attempt of each terminal closed the WebSocket that every terminal
    shares, and each reconnect made all sessions fetch their screens again.
  - Now one such reconnect is allowed per minute across all terminals. A terminal refused
    within that minute resubscribes only itself and keeps its attempt for later.
- **The service comes back after a crash.** (REL-BGSTAB-059, #208)
  - After the app exited, the sentinel gave the restarted app 30 seconds. Restoring about 48
    tabs took longer, so the sentinel killed it and the service stayed down. A start and a
    sentinel restart now wait 180 seconds, and the sentinel keeps its heartbeat fresh while it
    waits so that `stop` still works.
- **Two Codex tabs in one folder save different session ids.** (FR-AITUI-021, #203)
  - A Codex that had written nothing has no thread lock, so the one locked thread in the
    folder was saved for both tabs. A thread locked before a tab's Codex started is no longer
    taken for that tab, and two tabs that read the same id are told apart before saving.
- **Markdown viewer: code blocks follow the dark theme, and wide tables fit.** (FR-MDE-031,
  FR-MDE-032, #204, #205)
  - Code blocks in the dark theme had a light background.
  - On a desktop a table fits the document width and wraps its cells. On a phone it keeps its
    width and shows a scrollbar that stays visible.

### Added

- **Tools › Loop: run shell sessions on a schedule.** (FR-LOOP-001..006, #206)
  - Days of the week, dates of the month (or the last day), one date, or an interval. Choose
    the shell and the folder.
  - Steps run top to bottom: a command, a prompt, a wait in milliseconds, and an optional
    session end. `codex delay 2000 "…"` on one line becomes three steps.
  - Each run opens a tab in a `@schedule-{n}` workspace, starting with `@schedule-0`. When
    every one is full, the next number is made. Tabs of runs without a session end are kept up
    to the loop's count, and at 32 `@schedule` tabs a run is skipped.
  - A run that comes due while the previous one is still sending is skipped. Each loop keeps
    its last 50 runs. `@schedule` tabs are left out of the session save.
- **Register and run loops over MCP.** (FR-LOOP-007, #207)
  - `buildergate.loop.list`, `history`, `create`, `update`, `delete` and `run`.
  - New scopes `mcp:loops.read` and `mcp:loops.write` are held by the fixed access key and by
    agents in BuilderGate tabs. Agents started before this version get them after a restart.

## 한국어

### 수정

- **서버가 하루이틀 지나면 메모리가 바닥나던 문제를 고쳤습니다.** (REL-BGSTAB-061, #208)
  - 터미널 출력이 한 조각씩 들어올 때마다 약 320바이트가 그 세션이 닫힐 때까지 남아 있었습니다.
    세션이 48개쯤이면 30시간 동안 힙이 1.2 GB 에서 3.56 GB 로 늘었고, 결국 프로세스가 종료됐습니다.
    종료 전에는 입력이 멈추고 `git/summary` 가 시간을 넘겼습니다.
  - 이제는 출력 조각 하나를 다 쓰면 그 대기를 바로 해제합니다.
- **터미널 하나의 화면 복구가 실패해도 모든 터미널이 계속 다시 연결되지 않습니다.** (REL-BGSTAB-060, #208)
  - 그동안은 터미널마다 마지막 복구 시도가 모든 터미널이 함께 쓰는 WebSocket 을 끊었습니다.
    그래서 다시 연결될 때마다 모든 세션이 화면을 새로 받았습니다.
  - 이제는 이런 재연결을 모든 터미널을 통틀어 1분에 한 번만 허용합니다. 그 1분 안에 막힌 터미널은
    자기만 다시 구독하고, 남은 시도는 나중을 위해 남겨 둡니다.
- **서버가 죽어도 다시 살아납니다.** (REL-BGSTAB-059, #208)
  - 앱이 종료되면 센티널이 다시 띄우는데, 준비될 때까지 30초만 기다렸습니다. 탭 48개를 복구하려면
    그보다 오래 걸려서 센티널이 새 앱을 종료했고, 서비스가 멈춘 채로 남았습니다.
  - 이제 시작과 재시작 모두 180초를 기다립니다. 기다리는 동안에도 heartbeat 를 갱신하므로
    `stop` 이 거부되지 않습니다.
- **같은 폴더의 Codex 탭 두 개가 서로 다른 세션 id 로 저장됩니다.** (FR-AITUI-021, #203)
  - 아직 아무것도 쓰지 않은 Codex 는 스레드 잠금이 없습니다. 그래서 폴더에 하나뿐인 잠긴 스레드가
    두 탭 모두에 저장됐습니다.
  - 이제는 탭의 Codex 가 시작되기 전에 잠긴 스레드를 그 탭의 것으로 보지 않습니다. 두 탭이 같은 id 를
    읽으면 저장하기 전에 둘을 가려냅니다.
- **마크다운 뷰어의 코드 블록이 다크 테마를 따르고, 넓은 표가 화면에 맞습니다.** (FR-MDE-031, FR-MDE-032, #204, #205)
  - 다크 테마인데도 코드 블록 배경이 밝게 나오던 문제를 고쳤습니다.
  - 데스크톱에서는 표가 문서 폭에 맞춰지고 셀 내용이 줄바꿈됩니다. 휴대폰에서는 표가 원래 폭을
    유지하고, 늘 보이는 가로 스크롤바가 생깁니다.

### 추가

- **도구 › 루프: 셸 세션을 일정에 따라 실행합니다.** (FR-LOOP-001..006, #206)
  - 일정은 요일마다, 매월 날짜(말일 포함), 특정 날짜 하루, 간격 중에서 고릅니다. 셸과 디렉터리도
    정합니다.
  - 단계는 위에서 아래로 차례로 실행됩니다. 명령, 프롬프트, 대기(밀리초), 세션 종료를 넣을 수 있고
    세션 종료는 넣지 않아도 됩니다. `codex delay 2000 "…"` 처럼 한 줄로 쓰면 단계 셋으로 나뉩니다.
  - 실행할 때마다 `@schedule-{n}` Workspace 에 새 탭을 엽니다. `@schedule-0` 부터 채우고, 모두 가득 차면
    다음 번호를 만듭니다.
  - 세션 종료가 없는 실행의 탭은 루프에 정한 수만큼 남겨 둡니다. `@schedule` 탭이 모두 32개면 그 실행을
    건너뜁니다.
  - 앞 실행이 아직 단계를 보내는 중이면 이번 실행을 건너뜁니다. 루프마다 최근 50건의 실행 기록을 남기고,
    `@schedule` 탭은 세션 저장에서 뺍니다.
- **MCP 로 루프를 등록하고 실행합니다.** (FR-LOOP-007, #207)
  - 도구는 `buildergate.loop.list`, `history`, `create`, `update`, `delete`, `run` 입니다.
  - 새 권한 `mcp:loops.read`, `mcp:loops.write` 는 고정 접근 키와 BuilderGate 탭 안의 에이전트가 모두
    가집니다. 이 버전보다 먼저 시작한 에이전트는 다시 시작해야 이 권한을 받습니다.
