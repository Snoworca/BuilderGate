# BuilderGate v0.10.30

## English

### Fixed

- **Hangul typed on an iPhone is composed.** (FR-MKB-015, #201)
  - The iOS Korean keyboard joins a jamo to the syllable before by deleting that syllable
    from the input and inserting the joined one, without composition events. The terminal
    sent only the jamo, so 안녕하세요 arrived as ㅇㅏㄴㄴㅕㅇㅎㅏㅅㅔㅇㅛ. It now sends the
    keyboard's change: a backspace and the joined syllable.
  - While a syllable is being typed, Backspace is left to the keyboard, so it removes the
    last jamo (각 becomes 가) and the next jamo no longer joins a syllable you deleted.
- **Hangul typed in Safari on a Mac no longer drops keys.** (FR-BGSTAB-036, #209)
  - The macOS Korean input method replaces the syllable as each jamo is typed, and the
    terminal ignored those replacements, so 안녕하세요 arrived as ㅇㄴㅎ세요. When you typed
    fast, a syllable that began while the previous key was still down was lost. Both now
    reach the terminal, and nothing is sent twice.
- **Dictation on an iPhone no longer repeats phrases.** (FR-BGSTAB-037, #210)
  - Dictation rewrites everything it has inserted each time it refines its result, and the
    terminal appended every rewrite. It now sends only what changed.

## 한국어

### 수정

- **아이폰에서 친 한글이 조합됩니다.** (FR-MKB-015, #201)
  - iOS 한글 키보드는 조합 이벤트 없이, 입력칸에서 앞 글자를 지우고 합친 글자를 다시 넣는
    방식으로 자모를 합칩니다. 터미널은 자모만 보냈기 때문에 `안녕하세요`가
    `ㅇㅏㄴㄴㅕㅇㅎㅏㅅㅔㅇㅛ`로 들어갔습니다. 이제 키보드가 바꾼 내용(지우기와 합친 글자)을
    그대로 보냅니다.
  - 글자를 조합하는 동안 지우기는 키보드가 처리합니다. 그래서 마지막 자모만 지워지고(`각`이
    `가`가 됨), 지운 글자에 다음 자모가 합쳐지지 않습니다.
- **맥 Safari에서 한글을 칠 때 키가 씹히지 않습니다.** (FR-BGSTAB-036, #209)
  - 맥 한글 입력기는 자모를 칠 때마다 앞 글자를 바꿔 넣는데, 터미널이 이 바꿔 넣기를 무시해서
    `안녕하세요`가 `ㅇㄴㅎ세요`로 들어갔습니다. 빠르게 쳐서 앞 키를 떼기 전에 다음 글자가
    시작되면 그 글자가 사라지기도 했습니다. 이제 둘 다 터미널에 들어가고, 같은 글자를 두 번
    보내지 않습니다.
- **아이폰 음성 입력에서 어절이 반복되지 않습니다.** (FR-BGSTAB-037, #210)
  - 음성 입력은 인식 결과를 다듬을 때마다 지금까지 넣은 문장 전체를 다시 넣는데, 터미널은
    그때마다 문장을 덧붙였습니다. 이제 바뀐 부분만 보냅니다.
