# BuilderGate v0.10.16

## English

### Added

- **Upload files.** The file explorer can now upload files into the session folder. (#139,
  FR-FEX-022…026, FR-FOP-006)
  - Use the path bar's upload button, the context menu, or drop files from the OS onto the list
    or onto a target chip.
  - Files stream to a hidden temporary file and are placed only once they are complete. Two
    uploads with the same name never silently overwrite each other; a name conflict asks you to
    skip, keep both, or apply the same choice to the rest.
  - Progress shows in the existing file-job popover. Failures are listed per file and can be
    retried. Leaving the page during an upload asks for confirmation.

- **Download several items or a folder as ZIP.** Multiple selected entries and folders download
  as one ZIP file. Above 1 GiB or 10,000 entries, a confirmation bar shows the totals first.
  `.git` and `node_modules` are left out, and blocked paths are skipped. (#139, FR-FEX-025)

- **Mobile file explorer bar.** The bottom bar now has four fixed slots: Upload, Download, Paste
  and More. Selection actions and the rest of the commands are in the More sheet. The list looks
  the same as on desktop. (#139, FR-FEX-026)

- **Extract archives.** `.zip`, `.tar`, `.tar.gz` and `.tgz` files can be extracted from the
  context menu. (#140, FR-FEX-027, FR-FOP-007)
  - **Extract** creates a folder named after the archive unless the archive already holds a
    single top-level folder. **Extract here** extracts into the current folder.
  - Unsafe entries are skipped and listed: path traversal, absolute paths, links and devices, and
    blocked paths. Archives over 10 GiB or 100,000 entries, suspicious compression ratios,
    encrypted ZIPs and split ZIPs are refused.
  - ZIP names without the UTF-8 flag are read as CP949, so Korean names from Windows archives
    come out correctly.

- **HTML viewer.** HTML files open in an editor tab with a **Rendered | Source** toggle. (#141,
  FR-MDE-028, SEC-MDE-002)
  - The rendered page loads its relative images, styles and scripts from the same folder, runs
    its JavaScript, and loads external CDN resources.
  - The page runs in a sandbox without access to BuilderGate's login token. Hidden files and
    folders are not served to it.
  - Unsaved edits can be previewed before saving. On a phone, the toolbar stays on one compact
    line and scrolls sideways when it does not fit.
  - Paths that start with `/` are not resolved; that is a property of the page.

- **MCP: open an HTML page.** New tool `buildergate.editor.open_html` opens an HTML file in the
  viewer. (#141, FR-MCP-013)

### Changed

- **Mobile: the key bar shows only while the system keyboard is up.** Closing the keyboard with
  Android's back button used to leave the bar alone at the bottom of the screen. The bar now
  appears once the keyboard has risen and hides shortly after it goes down. It stays while the
  special keyboard panel is open. A tablet used only with a hardware keyboard shows no bar.
  (#147, FR-MKB-013)

### Fixed

- **iPhone: the keyboard opened on any touch, and the screen was cut off.** (#144, FR-ARCH-010,
  FR-ARCH-011)
  - The terminal now takes focus only on a short tap. Scrolling, pinching and long presses no
    longer open the keyboard.
  - While the keyboard is open the app follows the visible area, so the header and tab bar stay
    on screen. The bottom of the app is no longer hidden behind Safari's toolbar.

- **Mobile: the keyboard's place stayed blank after the keyboard went down** until the page was
  reloaded. The browser had scrolled the page to show the input; that scroll is now reset when
  the keyboard closes. (#143, FR-MKB-012)

- **Grid: after switching from tab to grid, programs such as Codex or Claude Code drew only part
  of each pane**, sometimes with overlapping lines, and a reload showed the same. (#145)
  - The server ignores a resize to the size it already has, so the program was never told to
    redraw. A pane that becomes visible, and a manual repair (middle click), now shrink the
    terminal by one row and restore it, which makes the program redraw at its real size.
    (REL-BGSTAB-047)
  - A resize back to the original size could be dropped while another resize was still queued,
    leaving the terminal one row short. (REL-BGSTAB-047)
  - Output could stop partway down with older text showing through, until the area was selected.
    The terminal now repaints every row after each size fit. (REL-BGSTAB-048)

## 한국어

### 추가

- **파일 업로드.** 파일 탐색기에서 세션 폴더로 파일을 올릴 수 있습니다. (#139,
  FR-FEX-022~026, FR-FOP-006)
  - 경로 막대의 업로드 버튼, 오른쪽 버튼 메뉴, 또는 OS 에서 목록이나 대상 칩으로 끌어 놓기로
    올립니다.
  - 파일은 숨김 임시 파일로 받은 뒤 다 받았을 때만 제자리에 둡니다. 같은 이름의 업로드가
    서로를 조용히 덮어쓰지 않으며, 이름이 겹치면 건너뛰기·둘 다 유지·남은 항목에도 같은 선택
    적용 중에서 고릅니다.
  - 진행 상황은 기존 파일 작업 팝오버에 보입니다. 실패는 파일마다 보이고 다시 시도할 수
    있습니다. 업로드 중에 페이지를 떠나려 하면 확인을 받습니다.

- **여러 항목·폴더를 ZIP 으로 내려받기.** 여러 항목과 폴더를 ZIP 파일 하나로 받습니다.
  1 GiB 나 1만 개를 넘으면 먼저 확인 막대에 크기와 개수를 보여 줍니다. `.git` 과
  `node_modules` 는 빼고, 차단 경로는 건너뜁니다. (#139, FR-FEX-025)

- **모바일 파일 탐색기 하단 막대.** 업로드·다운로드·붙여넣기·더보기 네 칸으로 고정했습니다.
  선택 작업과 나머지 명령은 더보기 시트에 있습니다. 목록은 데스크톱과 같은 모습입니다.
  (#139, FR-FEX-026)

- **압축 풀기.** `.zip`, `.tar`, `.tar.gz`, `.tgz` 파일을 오른쪽 버튼 메뉴에서 풉니다.
  (#140, FR-FEX-027, FR-FOP-007)
  - **압축 풀기**는 압축 파일 이름의 폴더를 만들어 그 안에 풉니다. 압축 파일 안에 최상위
    폴더가 하나뿐이면 그 폴더를 그대로 풉니다. **여기에 풀기**는 현재 폴더에 풉니다.
  - 위험한 항목은 건너뛰고 목록으로 보여 줍니다: 경로 탈출, 절대 경로, 링크·장치, 차단 경로.
    10 GiB 나 10만 개를 넘는 압축 파일, 압축률이 비정상인 파일, 암호 ZIP, 분할 ZIP 은
    거부합니다.
  - UTF-8 표시가 없는 ZIP 이름은 CP949 로 읽으므로, Windows 에서 만든 압축 파일의 한글
    이름이 바르게 나옵니다.

- **HTML 뷰어.** HTML 파일이 편집기 탭에서 **렌더링 | 소스** 토글과 함께 열립니다. (#141,
  FR-MDE-028, SEC-MDE-002)
  - 렌더링된 페이지는 같은 폴더의 상대 경로 이미지·스타일·스크립트를 불러오고, JavaScript 를
    실행하며, 외부 CDN 자원도 불러옵니다.
  - 페이지는 BuilderGate 로그인 토큰에 접근할 수 없는 샌드박스에서 돕니다. 숨김 파일과 폴더는
    페이지에 내주지 않습니다.
  - 저장하지 않은 편집 내용도 미리 볼 수 있습니다. 휴대폰에서는 도구 막대가 한 줄로 작게
    붙고, 넘치면 옆으로 밀어서 봅니다.
  - `/` 로 시작하는 경로는 풀지 않습니다. 이는 페이지 쪽의 문제입니다.

- **MCP: HTML 페이지 열기.** 새 도구 `buildergate.editor.open_html` 이 HTML 파일을 뷰어로
  엽니다. (#141, FR-MCP-013)

### 변경

- **모바일: 키 줄은 시스템 키보드가 올라와 있을 때만 보입니다.** 전에는 Android 뒤로 버튼으로
  키보드를 닫으면 키 줄만 화면 아래에 남았습니다. 이제 키보드가 다 올라온 뒤 나타나고,
  키보드가 내려가면 잠시 뒤 숨습니다. 특수 키보드 패널이 열려 있는 동안에는 그대로
  보입니다. 하드웨어 키보드만 쓰는 태블릿에서는 나오지 않습니다. (#147, FR-MKB-013)

### 수정

- **iPhone: 어떤 터치든 키보드가 열리고 화면이 잘리던 문제를 고쳤습니다.** (#144,
  FR-ARCH-010, FR-ARCH-011)
  - 이제 짧게 탭할 때만 터미널에 포커스가 갑니다. 스크롤, 두 손가락 확대, 길게 누르기로는
    키보드가 열리지 않습니다.
  - 키보드가 열린 동안 앱이 보이는 영역을 따라가므로 헤더와 탭 막대가 화면에 남습니다. 앱
    아래쪽이 Safari 주소창 뒤로 숨지 않습니다.

- **모바일: 키보드를 내린 뒤 키보드 자리가 빈 공간으로 남던 문제를 고쳤습니다.** 새로고침해야
  돌아왔습니다. 브라우저가 입력칸을 보여 주려고 페이지를 스크롤해 두었기 때문이며, 이제
  키보드가 내려가면 그 스크롤을 되돌립니다. (#143, FR-MKB-012)

- **그리드: 탭에서 그리드로 바꾸면 Codex·Claude Code 같은 프로그램이 칸 중간까지만 그리던
  문제를 고쳤습니다.** 줄이 겹치기도 했고, 새로고침해도 같았습니다. (#145)
  - 서버는 이미 같은 크기로의 크기 변경을 무시하므로, 프로그램이 다시 그리라는 신호를 받지
    못했습니다. 이제 칸이 보이게 될 때와 수동 복구(가운데 클릭) 때 터미널을 한 줄 줄였다가
    되돌려, 프로그램이 실제 크기로 다시 그리게 합니다. (REL-BGSTAB-047)
  - 다른 크기 변경이 아직 대기 중일 때 원래 크기로 되돌리는 요청이 버려져 터미널이 한 줄
    짧게 남을 수 있었습니다. (REL-BGSTAB-047)
  - 출력이 중간에서 끊기고 이전 글자가 비쳐 보이다가, 그 영역을 선택하면 제대로 보이던
    문제가 있었습니다. 이제 크기를 맞출 때마다 모든 줄을 다시 그립니다. (REL-BGSTAB-048)
