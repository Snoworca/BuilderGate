# BuilderGate v0.11.0

## English

### Added

- **Messenger: rooms where people and agent sessions on linked servers talk.** (FR-MSG-001..015)
  - Open it from the header button. Create a room, put your own sessions in, and invite contacts
    on other PCs; they pick their own sessions. A message typed in the window or sent by an agent
    with `buildergate.room.send` is pasted into the member sessions with a
    `[BG-ROOM:<room> | <sender>]` prefix. `@session` and `@person::session` send to one or more.
  - Messages are pasted only into sessions whose screen is a ready agent (bracketed paste on).
    Plain shells and programs such as vim are skipped, so a remote person's text never runs as a
    shell command.
  - The PC that created the room keeps the log and orders the messages; the others keep a copy
    and catch up after reconnecting. 20 consecutive agent messages hold the room until a person
    writes.
  - Contacts by address or a connection code, a per-session 「paste and press Enter」 switch,
    unread badge, delivery states, Google Chat notices for invites and mentions.
  - 「Accept LAN connections」 opens a separate TLS listener (MCP port + 1) for other PCs on the
    private network; the MCP listener local agents use is unchanged.
- **Loops can run in an existing session.** (FR-LOOP-008)
  - The loop window has two tabs for where it runs: 「New session」 (as before) and
    「Existing session」. Pick 「workspace : session」 from a list; the loop is saved by tab id
    and sends its messages to that session on schedule.
  - 「Skip while the agent is working」 is on by default. A loop whose session was closed skips
    the run and turns itself off; a session whose shell exited is skipped and the loop stays on.
    Several loops on one session run one after another.
- **Linked BuilderGate servers.** (FR-MCP-016..020, FR-MCP-022)
  - One server dials another's MCP listener and both control each other over one WebSocket
    (Tools › MCP settings › Remote links). Messages to `<server>/<session>` are queued and resent
    after a reconnect.
  - Session, workspace and terminal lists merge every linked server; other tools take a
    `server` argument. Session search matches the words of a name in any order.
- **`buildergate.file.upload_url`** returns a one-use URL that puts a file into a session's
  folder. (FR-MCP-021)
- **Keys for agents.** Arrows, Esc, Tab, function keys and Ctrl/Alt/Shift combinations.
  (FR-MCP-015)

### Changed

- **MCP: messages and terminal control are two tools.** (FR-MCP-011, FR-MCP-023)
  - `buildergate.message.send` sends text to an agent and always carries the sender tag
    `[from: …]`. The `includeSender` argument is gone; passing `includeSender: false` or `keys`
    is refused with `USE_TERMINAL_INPUT`.
  - New `buildergate.terminal.input` types one command line plus Enter, or keys, and adds
    nothing. A command that starts with `[from:` or contains control characters is refused.
  - Agents whose MCP connection is bound to their session can now run commands and press Enter
    with `buildergate.terminal.input` (new session scope `mcp:terminal.input`). Submitting with
    `message.send` still needs `mcp:message.submit`.
  - Both servers of a link must run this version: older servers do not know the new tool.

### Fixed

- A new-session loop saved with a WSL folder such as `/mnt/c/Users/me` failed with
  「directory missing」 on Windows; the folder is now checked as `C:\Users\me`.
- The MCP audit log shows the target session instead of 「Object」 and names the linked-server
  tools.

## 한국어

### 추가

- **메신저: 사람과, 연결된 서버의 에이전트 세션이 함께 대화하는 방.** (FR-MSG-001..015)
  - 헤더의 버튼으로 엽니다. 방을 만들고 내 세션을 넣은 뒤 다른 PC 의 연락처를 초대하면, 초대받은 사람이
    자기 세션을 고릅니다. 창에 쓴 글이나 에이전트가 `buildergate.room.send` 로 보낸 글은
    `[BG-ROOM:<방> | <보낸 사람>]` 을 붙여 멤버 세션에 붙여 넣습니다. `@세션` 과 `@사람::세션` 으로 한 명
    또는 여럿에게 보낼 수 있습니다.
  - 화면이 준비된 에이전트(bracketed paste 켜짐)인 세션에만 붙여 넣습니다. 일반 셸이나 vim 같은 프로그램은
    건너뛰므로, 원격 사람이 쓴 글이 셸 명령으로 실행되지 않습니다.
  - 방을 만든 PC 가 기록을 보관하고 순서를 정합니다. 다른 PC 는 사본을 두고 다시 연결되면 따라잡습니다.
    에이전트끼리 20번 연속으로 주고받으면 사람이 쓸 때까지 방을 멈춥니다.
  - 주소나 연결 코드로 연락처 추가, 세션별 「받은 메시지를 바로 입력」 스위치, 읽지 않은 수, 전달 상태,
    초대와 멘션의 Google Chat 알림을 지원합니다.
  - 「사내망 연결 받기」를 켜면 같은 사내망의 다른 PC 를 위한 TLS 리스너(MCP 포트 + 1)를 따로 엽니다.
    로컬 에이전트가 쓰는 MCP 리스너는 그대로입니다.
- **루프를 기존 세션에서 실행할 수 있습니다.** (FR-LOOP-008)
  - 루프 창의 「어디서」에 「새 세션」(기존 방식)과 「기존 세션」 두 탭이 있습니다. 「워크스페이스 : 세션」을
    목록에서 고르면 탭 id 로 저장되고, 정해진 시각마다 그 세션에 메시지를 보냅니다.
  - 「에이전트가 작업 중이면 건너뜀」이 기본으로 켜져 있습니다. 대상 세션이 닫히면 그 실행을 건너뛰고 루프를
    끕니다. 셸이 끝난 세션은 건너뛰되 루프는 켜진 채로 둡니다. 한 세션에 루프가 여럿이면 차례로 실행합니다.
- **BuilderGate 서버끼리 연결.** (FR-MCP-016..020, FR-MCP-022)
  - 한 서버가 다른 서버의 MCP 리스너에 연결하면, WebSocket 하나로 서로를 제어합니다(도구 › MCP 설정 ›
    원격 연결). `<서버>/<세션>` 으로 보낸 메시지는 대기열에 들어가고, 다시 연결되면 다시 보냅니다.
  - 세션·워크스페이스·터미널 목록은 연결된 모든 서버를 합쳐 보여 주고, 다른 도구는 `server` 인자를 받습니다.
    세션 검색은 이름의 단어를 순서와 상관없이 찾습니다.
- **`buildergate.file.upload_url`** 은 세션 폴더에 파일을 한 번 올릴 수 있는 URL 을 돌려줍니다. (FR-MCP-021)
- **에이전트용 키 입력.** 방향키, Esc, Tab, 기능 키, Ctrl/Alt/Shift 조합을 보낼 수 있습니다. (FR-MCP-015)

### 변경

- **MCP: 메시지와 터미널 제어를 두 도구로 나눴습니다.** (FR-MCP-011, FR-MCP-023)
  - `buildergate.message.send` 는 에이전트에게 글을 보내며, 보낸 세션 표시 `[from: …]` 가 항상 붙습니다.
    `includeSender` 인자는 없어졌고, `includeSender: false` 나 `keys` 를 넘기면 `USE_TERMINAL_INPUT` 으로
    거부합니다.
  - 새 도구 `buildergate.terminal.input` 은 명령 한 줄과 Enter, 또는 키를 보내며 아무것도 덧붙이지 않습니다.
    `[from:` 으로 시작하거나 제어 문자가 든 명령은 거부합니다.
  - 세션에 묶인 에이전트도 이제 `buildergate.terminal.input` 으로 명령을 실행하고 Enter 를 보낼 수 있습니다
    (새 세션 권한 `mcp:terminal.input`). `message.send` 로 제출하려면 여전히 `mcp:message.submit` 이
    필요합니다.
  - 연결된 두 서버는 모두 이 버전이어야 합니다. 이전 버전 서버는 새 도구를 모릅니다.

### 수정

- 새 세션 루프의 디렉터리를 `/mnt/c/Users/me` 같은 WSL 경로로 저장하면 Windows 에서 「디렉터리 없음」으로
  실패하던 문제를 고쳤습니다. 이제 `C:\Users\me` 로 바꿔 확인합니다.
- MCP 감사 로그가 대상을 「객체」 대신 세션 이름으로 보여 주고, 연결된 서버 도구에도 이름을 붙입니다.
