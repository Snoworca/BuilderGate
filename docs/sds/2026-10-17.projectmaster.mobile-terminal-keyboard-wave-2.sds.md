## Acceptance Contracts

- SDS-AC-1 (FR-MKB-005 AC-1): WHEN a LatchKey renders for each latch state THE SYSTEM SHALL expose data-latch-state off|once|locked and a corner dot element on Ctrl, Alt and Shift only → `LatchKey`
- SDS-AC-2 (FR-MKB-005 AC-3): WHEN a LatchKey gets pointerdown then pointerup before 1500 ms THE SYSTEM SHALL leave the modifier once, and WHEN pointercancel arrives THE SYSTEM SHALL leave it unchanged → `LatchKey`
- SDS-AC-3 (FR-MKB-005 AC-5): WHEN contextmenu fires on a LatchKey THE SYSTEM SHALL call preventDefault and stopPropagation → `LatchKey`
- SDS-AC-4 (FR-MKB-006 AC-1): WHEN MobileKeyBar renders THE SYSTEM SHALL list the keys in MOBILE_BAR_KEYS order plus the switch button and no Win, AltGr, mouse or screenshot key → `MobileKeyBar`, `MOBILE_BAR_KEYS`
- SDS-AC-5 (FR-MKB-006 AC-3): WHEN the Up key is released with Ctrl once and application cursor mode on THE SYSTEM SHALL send ESC [1;5A to the active tab and leave Ctrl off → `sendMobileKey`
- SDS-AC-6 (FR-MKB-006 AC-4): WHEN a bar key gets pointerdown and mousedown while the helper textarea is focused THE SYSTEM SHALL prevent default, keep the textarea as document.activeElement, and skip the key when the pointer moved more than 8 px before pointerup → `MobileKeyBar`
- SDS-AC-7 (FR-MKB-006 AC-7): WHEN reset runs during a held press THE SYSTEM SHALL commit all off and the 1500 ms timer SHALL not lock → `mobileModifierLatch.reset`
- SDS-AC-8 (FR-MKB-006 AC-2): WHEN focusin targets the active tab's helper textarea THE SYSTEM SHALL report true, and false after focusout or for another tab → `useTerminalInputFocus`
- SDS-AC-9 (FR-MKB-007 AC-1): WHEN visualViewport has height 500, offsetTop 120 and innerHeight 900 THE SYSTEM SHALL return top 120, height 500, inset 280 → `computeViewportBox`
- SDS-AC-10 (FR-MKB-007 AC-3): WHEN window.visualViewport is undefined THE SYSTEM SHALL return inset 0 without throwing → `computeViewportBox`
- SDS-AC-11 (FR-MKB-007 AC-5): WHEN an inset of 280 was measured and a later measure is 0 THE SYSTEM SHALL keep getLastKeyboardInset at 280 → `getLastKeyboardInset`
- SDS-AC-12 (FR-MKB-006 AC-6): WHEN the bar renders THE SYSTEM SHALL take every aria label from t() with keys present in both catalogs and no Korean literal in src → `MOBILE_BAR_KEYS`
