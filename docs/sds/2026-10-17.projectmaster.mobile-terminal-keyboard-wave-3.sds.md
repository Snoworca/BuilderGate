## Acceptance Contracts

- SDS-AC-1 (FR-MKB-008 AC-1): WHEN the switch is tapped with the system keyboard up THE SYSTEM SHALL call blurInput then setFocusSuppressed(true) and render the panel → `toggleSpecialKeyboard`, `TerminalHandle.blurInput`
- SDS-AC-2 (FR-MKB-008 AC-2): WHEN no inset was ever measured THE SYSTEM SHALL size the panel 280 px, else the last inset → `specialPanelHeight`
- SDS-AC-3 (FR-MKB-008 AC-3): WHEN the switch is tapped with the panel open THE SYSTEM SHALL clear suppression and call focus() inside the same handler call → `toggleSpecialKeyboard`
- SDS-AC-4 (FR-MKB-008 AC-4): WHEN focus is suppressed THE SYSTEM SHALL ignore handleClick and pending restore, and WHEN released SHALL behave as before → `TerminalHandle.setFocusSuppressed`
- SDS-AC-5 (FR-MKB-008 AC-5): WHEN the panel is open and the textarea is blurred THE SYSTEM SHALL keep the bar visible with label ABC → `shouldShowMobileKeyBar`, `MobileKeyBar`
- SDS-AC-6 (FR-MKB-009 AC-2): WHEN the panel renders THE SYSTEM SHALL show the top row and three blocks in the FR-MKB-009 order → `MobileSpecialKeyboard`, `SPECIAL_LEFT_BLOCK`
- SDS-AC-7 (FR-MKB-009 AC-5): WHEN F5 is tapped with Alt once THE SYSTEM SHALL send ESC ESC [15~ and Alt SHALL be off → `MobileSpecialKeyboard`
- SDS-AC-8 (FR-MKB-010 AC-1): WHEN Numpad is tapped THE SYSTEM SHALL swap only the right block and the left and middle keys SHALL keep their DOM order → `MobileSpecialKeyboard`
- SDS-AC-9 (FR-MKB-010 AC-4): WHEN storage throws on read and write THE SYSTEM SHALL open with arrows and not throw → `readRightBlock`, `writeRightBlock`
- SDS-AC-10 (FR-MKB-011 AC-3): WHEN a LatchKey press moves 20 px before release THE SYSTEM SHALL leave the modifier unchanged → `LatchKey`, `isDragBeyond`
- SDS-AC-11 (FR-MKB-011 AC-4): WHEN enabled is false THE SYSTEM SHALL attach no focusin listener → `useTerminalInputFocus`
- SDS-AC-12 (FR-MKB-011 AC-1): WHEN a LatchKey is locked THE SYSTEM SHALL style it from the orange token family and tokens.css SHALL define it for both themes → `LatchKey`
