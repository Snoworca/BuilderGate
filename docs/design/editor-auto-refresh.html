편집기 자동 새로고침

디스크의 파일이 바뀌면 편집기 창의 HTML 뷰어, 마크다운·코드 편집기, 이미지 뷰어가 스스로 다시 읽습니다. 창 위쪽의 자동 새로고침 토글로 끄고 켭니다. 화면에 보이는 탭만 2초마다 수정 시각과 크기를 확인합니다. 아래 버튼으로 상황을 재현해 보세요.

외부에서
토글을 끈 상태에서 "파일 변경"을 누르면 아무 일도 일어나지 않습니다. HTML 탭의 수동 "다시 불러오기"(F5)는 토글과 관계없이 남습니다.

동작

상황저장 안 한 편집 없음저장 안 한 편집 있음
파일 변경바로 다시 읽음. 커서·스크롤 유지, 바뀐 줄을 잠깐 강조덮어쓰지 않고 노란 띠: [다시 불러오기] [내 편집 유지]
파일 삭제탭을 닫고 알림을 띄움. 마지막 탭이면 창도 닫음편집을 잃지 않도록 닫지 않고 빨간 띠: [다시 저장] [편집 버리고 닫기]
HTML 뷰어페이지를 다시 엶(스크롤은 맨 위로)
이미지·SVG새 이미지로 바꿔 끼움. 확대 상태 유지

규칙

  1. 확인 방법: 화면에 보이는 탭만 2초마다 /files/stat 의 수정 시각과 크기를 비교합니다. 숨긴 탭, 최소화한 창, 백그라운드 브라우저 탭은 묻지 않습니다. 응답이 느리면(WSL) 간격을 늘립니다.
  2. 토글: 기본 켜짐. 브라우저에 저장하고 모든 편집기 창에 함께 적용합니다.
  3. 내 저장: 내가 저장해서 바뀐 수정 시각은 외부 변경으로 보지 않습니다.
  4. 저장 시점: 외부에서 바뀐 파일에 저장하면 지금처럼 덮어씁니다(1차 범위).
  5. 삭제: 이름 변경·이동도 원래 경로에서는 삭제로 봅니다.
