동작

  1. 끌어오기 — 운영체제 파일이 세션 위에 오면 그 세션 영역 전체에 노란 오버레이(불투명도 15%)와 “이곳으로 파일 업로드”가 뜹니다. 다른 세션은 그대로입니다.
  2. 취소 — 세션 밖으로 나가거나 Esc 를 누르면 사라지고 아무것도 올라가지 않습니다.
  3. 놓기 — 파일과 폴더(하위 폴더 포함)가 그 세션의 현재 폴더로 업로드되고, 진행은 하단 파일 작업 막대에 표시됩니다.
  4. 같은 이름 — 덮어쓰지 않고 이름 (2).확장자 로 둘 다 보관합니다.
  5. 데스크톱 전용 — 터치 포인터이거나 폭 768px 미만이면 반응하지 않습니다. 파일 탐색기에서 끌어 온 항목은 업로드로 취급하지 않습니다.
