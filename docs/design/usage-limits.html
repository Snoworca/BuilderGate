④ 정해 둔 것

막대높이 3px, 길이 = 사용한 비율. 창 이름(5시간·주간)은 왼쪽, 사용률과 남은 시간은 막대 아래 한 줄.
색 (남은 양 기준)40% 이상 초록 · 15~40% 노랑 · 15% 미만 빨강.
기록 없는 창막대를 숨긴다. 기록되면 나타난다. 두 창 모두 없으면 그 에이전트 블록을 숨기고, 둘 다 없으면 영역 전체를 숨긴다.
오래된 값마지막 기록이 1시간보다 오래되면 막대를 흐리게, 「n시간 전 기준」을 노랗게. 초기화 시각이 지났으면 0% 와 「초기화됨」.
계정 구분Claude: 중계가 실행될 때 자기 설정 폴더(CLAUDE_CONFIG_DIR 또는 홈)의 .claude.json 계정 블록(accountUuid + organizationUuid)으로 계정을 붙인다. Codex: 각 세션 기록 첫 줄의 creator_account_id. 둘 다 토큰은 읽지 않으며, 저장·표시에는 원래 식별자 대신 해시를 쓴다.
계정 표시한 에이전트에 계정이 하나면 이름을 생략한다. 둘 이상이면 계정마다 줄을 나누고 「별명 → 가린 이메일 · 요금제 → 짧은 해시」 순으로 이름을 붙인다. 계정을 알 수 없는 기록은 「계정 미상」으로 따로 둔다. API 키로 쓰는 경우는 한도가 없어 그리지 않는다.
알림 메시지계정 이름을 함께 넣는다: 「[BuilderGate] Claude(회사 팀) 5시간 한도 남은 양 12% …」.
어디서 읽나Codex: ~/.codex/sessions 의 가장 최근 기록. Claude: 상태줄 중계가 쓴 파일. Windows 와 WSL 의 홈을 모두 보고, 더 최근 값을 쓴다.
갱신서버가 주기(기본 60초, 15초~1시간)마다 기록 파일을 다시 읽고, 화면은 같은 주기로 서버 값을 받아 온다. ↻ 는 서버에 즉시 다시 읽기를 요청한다.
알림 기준고른 창(5시간·주간)의 남은 양이 기준(기본 20%) 미만이면 갱신될 때마다 보낸다. 단, 같은 계정·같은 창의 직전 갱신 값과 이번 값(사용률)이 같으면 보내지 않는다. 남은 양이 기준 이상이면 보내지 않는다.
알림 채널Google Chat 웹훅 URL, 텔레그램 봇 토큰 + chat id. 채널마다 켜기/끄기와 테스트 버튼. 테스트는 입력칸의 값(저장 전 값 포함)으로 실제 메시지를 보내고 성공·실패와 오류를 보여 준다.
비밀값웹훅 URL·봇 토큰은 서버 설정에 암호화해 저장하고, 화면에는 끝 4자리만 보인다(●●●●abcd). 바꿀 때만 새로 입력한다. 로그와 응답에 원문을 남기지 않는다.
쓰지 않는 방법OAuth 토큰으로 Anthropic 사용량 API 를 부르는 것 — 공개 문서에 없고 사내 규정(구독 인증 정보를 도구에 연결 금지)에 걸린다.
