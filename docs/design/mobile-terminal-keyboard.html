모바일 터미널 키보드 — 디자인 시안

BuilderGate 모바일 모드에서 시스템 키보드 위에 띄우는 키 줄과, 시스템 키보드 대신 쓰는 특수 키보드입니다. 키를 누르면 터미널로 보낼 바이트가 아래 기록에 찍힙니다.

잠글 수 있는 키 (Ctrl·Alt·Shift) 짧게 누름 — 다음 한 키에만 적용 (파란 글자·밑줄, 키를 하나 치면 꺼짐) 1.5초 누름 — 잠금 (약한 진동)

보낸 바이트

    위치visualViewport 높이 변화로 시스템 키보드 높이를 구해 키 줄을 바로 위에 붙입니다. 특수 키보드는 마지막으로 잰 키보드 높이를 그대로 써서 화면이 출렁이지 않게 합니다.
    전송 경로키는 xterm 의 현재 모드(앱 커서 모드 등)를 보고 시퀀스를 고른 뒤 기존 WebSocket 입력 경로로 보냅니다. 키 줄 버튼은 포커스를 빼앗지 않아(mousedown 기본 동작 차단) 시스템 키보드가 내려가지 않습니다.
    잠금(토글) 키Ctrl·Alt·Shift 만 잠글 수 있고, 오른쪽 위의 점으로 표시합니다(꺼짐 회색 · 한 번 파랑 · 잠금 주황 불). 1.5초 누르는 동안 키가 아래에서부터 차오르고, 다 차면 navigator.vibrate(25) 로 약하게 진동합니다. 잠긴 키는 짧게 한 번 누르면 풀립니다. 진동은 안드로이드 Chrome 에서만 됩니다 — iOS Safari 는 진동 API 가 없어 불빛만 바뀝니다.
    뺀 키RD Client 의 Win·AltGr·마우스·스크린샷 키는 터미널에서 의미가 없어 넣지 않았습니다. 키 높이는 디자인 토큰 --ctl-touch(44px) 이상입니다.
