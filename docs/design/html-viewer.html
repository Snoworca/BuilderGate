    1창과 토글
    
      
      
        
    • 이미지·SVG와 같은 편집기 창의 탭으로 엽니다. .html·.htm 은 탐색기에서 열면 렌더링이 기본입니다.
      • 
        
    • 상단 도구 막대의 렌더링 / 소스 토글은 아이콘만이 아니라 글자가 있는 세그먼트 버튼으로 둡니다. 두 화면 모두 마운트를 유지해 전환해도 편집 중인 내용이 사라지지 않습니다(SVG 탭과 같은 방식).
      • 
        
    • 소스는 기존 코드 편집기(HTML 문법 강조, 줄바꿈 토글, Ctrl+S 저장)입니다.
      • 
      
    
    
    
    
    
      
    2렌더링과 JS
    
      
      
        
    • iframe sandbox="allow-scripts allow-forms allow-modals allow-popups" 이고, allow-same-origin 은 주지 않습니다. JS는 실행되지만 앱과 다른 출처라 로그인 토큰(localStorage)·쿠키·앱 API에 닿지 않습니다.
      • 
        
    • 서빙 응답에도 Content-Security-Policy: sandbox … 를 붙여, URL을 새 탭에서 직접 열어도 같은 격리가 적용됩니다.
      • 
        
    • 렌더링은 편집 중인 내용을 보여 줍니다. 저장하지 않은 수정이 있으면 위에 안내와 [저장]이 뜹니다. 상대 자원은 <base> 를 넣어 저장된 파일과 같은 폴더에서 불러옵니다.
      • 
        
    • 다시 불러오기(F5)는 페이지를 새로 띄워 JS를 처음부터 다시 실행합니다.
      • 
      
    
    
    
    
    
      
    3정적 자원
    
      
      
        
    • 서버 라우트 /api/html-view/<토큰>/<경로> 가 HTML과 그 상대 경로 자원을 서빙합니다. 세션 폴더 밖·차단 경로·차단 확장자는 거부합니다.
      • 
        
    • 토큰은 창이 열린 동안 여러 번 쓸 수 있고, 탭을 닫으면 폐기합니다.
      • 
        
    • 외부 URL(CDN)은 페이지가 쓰는 그대로 불러옵니다. / 로 시작하는 절대 경로는 페이지의 문제로 보고 지원하지 않습니다.
      • 
        
    • 도구 막대의 자원 n 버튼은 이 페이지가 요청한 자원과 결과(200·404·차단·외부)를 보여 줍니다. 실패가 있으면 노란색이 됩니다.
      • 
      
    
    
    
    
    
      
    4MCP
    
      
      
        
    • buildergate.editor.open_html 을 추가합니다. 인자는 path, 선택 view(rendered·source), terminal, html(텍스트를 저장 후 열기) 입니다.
      • 
        
    • 기존 open_code·open_image·open_markdown 과 같은 경로·권한 규칙을 따릅니다.
