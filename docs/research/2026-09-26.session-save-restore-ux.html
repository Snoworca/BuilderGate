세션 저장 · 복구 UX

BuilderGate를 재시작하기 전에 AI 에이전트 세션을 저장하고, 재시작한 뒤 확인을 거쳐 정확히 그 세션으로 이어하는 흐름입니다. 저장할 때 각 에이전트를 정상 종료하고, 종료할 때 에이전트가 찍는 공식 재개 명령에서 세션 ID를 읽습니다. 색과 글꼴은 BuilderGate의 실제 토큰을 따랐고, 세션 이름·경로·ID는 예시입니다.

① 헤더 버튼 버튼 상태 4가지 ② 저장 창 ③ 재시작 직후 배너 ④ 이어하기 창 모바일 저장본 기록
재시작 전

① 헤더의 세션 저장 버튼

헤더 오른쪽, 보기 전환 버튼과 도구·설정 사이에 아이콘 버튼 하나를 둡니다. 배지는 실행 중인 AI 세션 수입니다.

  • 도구 메뉴에 넣지 않는다. 자주 누르지는 않지만 재시작 직전에 바로 찾아야 하는 버튼이다.
  • 누르기 전에 설명한다. 마우스를 올리거나 키보드 초점이 가면 툴팁으로 "정상 종료 + 이어하기 ID 기록"을 알린다.
  • 한 자리에서 저장과 복구를 모두 한다. 저장 뒤와 재시작 뒤에는 같은 버튼이 상태를 바꿔 보여 준다(아래 상태표).

버튼 상태 4가지

저장과 이어하기를 같은 자리에서 찾게 합니다.

재시작 전

② 저장 창 — 고르기 → 종료 → 완료

AI 세션을 워크스페이스별로 묶어 보여 주고, 체크한 세션만 정상 종료하며 ID를 받습니다.

  • 끊기는 것을 미리 말한다. 응답을 쓰고 있는 세션에는 "응답 작성 중" 표시를 붙이고, 아래쪽에 "쓰던 응답이 끊기지만 대화 기록은 남는다"고 알린다.
  • 세션마다 결과를 보여 준다. 대기 → 종료하는 중 → "ID 확인 · 7c1e0b52…". ID를 받지 못하면 "복구 때 최근 세션으로"라고 미리 알린다.
  • 탭에 증거가 남는다. 완료 뒤 각 탭에는 에이전트가 찍은 재개 명령이 그대로 보인다. 버튼이 없어도 사용자가 직접 확인할 수 있다.
체크박스를 바꾸고 "저장하고 에이전트 종료"를 눌러 보세요. "확인"을 누르면 처음으로 돌아갑니다.
재시작 후

③ 재시작 직후 — 이어하기 배너

에이전트를 자동으로 띄우지 않습니다. 탭은 셸로 먼저 열어 두고, 저장본이 있다는 사실을 배너로 알립니다.

  • 막지 않는다. 모달이 아니라 배너라서 바로 셸을 쓸 수 있다.
  • "나중에"는 배너만 닫는다. 헤더의 파란 "이어하기" 버튼은 저장본을 처리할 때까지 남는다.
  • 탭마다 표시한다. 세션 줄에 "↻ 이어하기 대기" 칩이 붙는다.
재시작 후

④ 이어하기 창 — 고르기 → 이어하기 → 결과

세션마다 실제로 보낼 명령과 신뢰도를 보여 주고, 사용자가 고른 것만 이어합니다.

  • 기본 체크는 정확한 ID를 받은 세션만. ID가 없는 세션은 체크를 해제해 두고, 체크하면 최근 세션으로 이어간다고 미리 보여 준다.
  • 명령을 그대로 보여 준다. claude --resume …처럼 셸에 보낼 명령이 보이니 무엇이 일어날지 예측할 수 있다.
  • 한 번만 묻는다. 처리 결과(restored · skipped · failed)를 저장본에 기록해 다음 시작 때 다시 묻지 않는다.
체크를 바꾸고 "선택한 N개 이어하기"를 눌러 보세요. 뒤의 탭 화면도 결과에 맞게 바뀝니다.

모바일 — 이어하기 시트

원격에서 휴대폰으로 재시작을 확인하는 경우를 위해, 같은 결정을 하단 시트로 합니다.

  • 누를 수 있는 영역을 44px 이상으로 한다. 체크박스는 44px 칸 안에 있고, 행 전체를 눌러도 바뀐다.
  • 헤더의 파란 버튼은 아이콘과 숫자만 둔다. 좁은 화면에서도 같은 자리에 있다.
  • 저장 버튼은 워크스페이스 메뉴(드로어)에 둔다. 모바일 헤더에는 공간이 없다.

저장본 기록

  • 한 줄에 탭 하나: tabId · agent · sessionId · 얻은 방법(종료 문구 | 대체) · savedAt · restore(pending → restored | skipped | failed) · 처리 시각
  • 저장본이 남아 있는 동안 헤더 버튼은 파란 "이어하기"로 남고, 모든 항목이 처리되면 기본 버튼으로 돌아간다.
  • 버튼 없이 재시작하면(크래시 등) 저장본이 없으므로 지금처럼 --continue / resume --last로 복구한다.
  • 명령에 들어가는 ID는 형식을 검사한다. Claude·Codex는 UUID, Hermes는 YYYYMMDD_HHMMSS_hex6, OpenCode는 ses_…이다.
