# BuilderGate Wave 3 authority·fairness 구현 계획

## §1 개요

### 1.1 목표

Orca의 single retained model, shallow fair delivery, gap/recovery와 central writer 원칙을 BuilderGate의 WebSocket/WAN·다중 client 구조에 맞게 흡수한다. REL-BGSTAB-007과 Wave 3 신규 7개 Requirement의 65개 AC를 strict TDD로 구현한다.

### 1.2 범위

- observe-only TerminalResourcePolicy와 non-loss canary infrastructure
- Browser TerminalWriteCoordinator sole writer
- retained server model, checkpoint/Ordinal64/fact/driver lease
- single-authority limited promotion과 rollback epoch
- per-client/per-session fair scheduler와 server-owned ACK credit
- hidden dataGap과 full authoritative reveal recovery

### 1.3 제외사항

UI visual·label·layout·interaction, binary/split 기본화, WebGL/Unicode/selection/input/residency Wave 4 범위, legacy 물리 삭제와 buffer product default 숫자 변경은 제외한다. Orca는 읽기 전용이다.

### 1.4 강제 gate

각 Phase는 RED→GREEN→integration evidence 뒤 까칠한 reviewer의 정확한 `No findings`를 받아야 완료한다. `https://localhost:2222`만 E2E에 사용하고 node.exe 및 TCP 2001/2002를 중단하지 않는다.
