# 로그인이 계속 풀리는 문제 — 7일 슬라이딩 로그인 (REL-BGSTAB-037)

## 증상

로그인 상태가 자주 풀린다.

## 원인

- JWT 수명이 30분(`auth.durationMs: 1800000`)이고, 브라우저가 **고정 15분 타이머**로만 갱신했다. 절전·덮개 닫기, 백그라운드 탭 동결, 브라우저 종료처럼 갱신이 30분 이상 끊기면 토큰이 만료되고 서버는 만료 토큰을 갱신하지 않는다.
- 여러 탭이 localStorage 의 토큰 하나를 공유한다. 한 탭이 갱신하면 옛 토큰이 즉시 폐기되는데, 다른 탭이 그 직전에 보낸 요청이 401 을 받으면 **모든 탭이 로그아웃**됐다.
- 갱신 주기가 설정과 무관한 15분이라, 유지 시간을 15분보다 짧게 두면 매번 만료됐다.
- 갱신으로 폐기한 토큰은 폐기 목록에 24시간만 남았다. 30분 토큰에는 문제가 없었지만 7일 토큰이면 폐기된 토큰이 다시 유효해진다(이번에 함께 수정).

## 해결

| 항목 | 내용 |
|---|---|
| 기본 유지 시간 | 7일(`604800000`), 설정 범위 1분~30일. 설정 파일에 옛 기본값 `1800000` 이 그대로 있으면 7일로 읽는다(파일은 고치지 않음, `normalizeRawConfigForPlatform`) |
| 슬라이딩 | 브라우저가 토큰이 10분(짧은 세션은 수명의 절반) 지나면 갱신. 1분마다 확인하고, 화면 복귀(`visibilitychange`)·포커스·네트워크 복구 때 즉시 확인 |
| 다중 탭 | 401 을 받았는데 저장된 토큰이 보낸 토큰과 다르면(다른 탭이 갱신) 저장된 토큰으로 한 번 재시도 |
| 폐기 | 갱신으로 폐기한 토큰은 그 토큰의 만료 시각까지 폐기 목록에 남김 |
| 실패 처리 | 갱신 실패는 토큰이 실제로 만료됐을 때만 로그아웃(일시적 네트워크 오류로 로그아웃하지 않음) |

## 한계

- 브라우저 쪽 갱신 동작(절전 복귀·다중 탭)은 단위 테스트로만 확인했고 실제 브라우저로 보지 않았다.
- 폐기 목록은 메모리에 있어 서버를 재시작하면 비워진다. 갱신으로 교체된 옛 토큰이 재시작 뒤 만료 시각까지 다시 유효해질 수 있다.
- 운영 설치본(2001/2002)은 새 버전으로 교체해야 적용된다.
