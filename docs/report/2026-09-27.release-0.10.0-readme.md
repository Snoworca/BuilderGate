# 0.10.0 릴리즈와 README

## 요청
0.10.0 으로 버전을 올리고 태그를 붙여 푸시하고, 빌드해 릴리즈에 올린다. README 를 영어(위)·한국어(아래)로 쓰고 맨 위에 바로가기를 둔다. 실행 방법·옵션, 스크린샷과 설명 없이는 알기 어려운 사용법(컨텍스트 메뉴, MCP) 설명서, 빌드 방법과 개발 환경을 담는다.

- README.md 전면 재작성: 영어/한국어 바로가기, 기능, 내려받기, 실행, 실행 옵션 표, 최초 비밀번호, 설정, 사용 설명서(Workspace·그리드, 터미널 컨텍스트 메뉴, 세션 경로 메뉴와 편집기, 도구 메뉴, MCP 보안·에이전트 프로필·웹훅·세션 탭과 MCP 도구 표, 세션 저장, 설정과 언어), 2단계 인증, 빌드, 개발 환경, macOS
