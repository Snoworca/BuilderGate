# Exclusive runtime port guard

- Requirement: REL-BGSTAB-001, B1 operational validation preparation. No AC/status promotion.
- Design: [exclusive runtime validation](../plan/2026-09-08.exclusive-runtime-validation.design.md).
- Files: `server/tools/require-exclusive-runtime-port.cjs` and `server/tools/test-exclusive-runtime-port.cjs`.

The test-only preload restricts Node TCP listen calls to the profile selected at preload time: fixture permits 2222; app permits 2222 plus the existing 2221 redirect. Missing/invalid profiles fail at preload. Unsupported ports and ambiguous IPC/descriptor/handle forms fail before the captured original listen. An optional UTF-8 JSONL log records forwarded and rejected attempts. Production startup does not load this tool automatically.

Self-tests replace the captured original listen before loading the guard, so even a defective guard cannot open a real socket. They cover numeric/string/options overloads, receiver/argument/callback/return identity, invalid profiles, profile changes after preload, malformed endpoints and optional logging.
