# Owned HTTP pipe/socket test helper

- Scope: B0 HTTP-only migration under REL-BGSTAB-001 and the user's TCP/process safety rules. Real-peer auth tests, TLS/boot2222, whole-server regression and E2E cleanup remain open.
- withLocalHttpServer runs the supplied real HTTP/Express app on a unique local pipe/Unix socket, forwards request method/path/headers/body, returns raw status/headers/UTF-8 body, and closes its own accepted sockets/server in finally. Bind errors are propagated without a port retry. Only its successfully bound Unix path is eligible for removal.
- The endpoint/listen/cleanup pattern reuses the existing WsRouterRestoreMetadata fixture approach without loading its WS/PTY test environment. No production service, new runtime flag or TCP listener is introduced.
