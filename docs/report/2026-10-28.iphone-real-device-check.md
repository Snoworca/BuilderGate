# 아이폰 실기기 확인 기록 (#193, #194, #196)

## 개요

이 보고서는 2026-10-28에 사용자가 실제 아이폰에서 확인한 결과를 SRS 증거로 남긴 작업을 기록한다. 대상은 PR #195(이슈 #193, #194)와 PR #197(이슈 #196)로 2222에 반영한 빌드다. 앞선 작업에서는 ego 브라우저의 터치 에뮬레이션으로만 확인했고, 실기기 확인은 남은 일로 적어 두었다.

## 사용자가 확인한 내용

모두 아이폰 Safari로 `https://localhost:2222`에 접속해 확인했다.

| 요구사항 | 확인한 동작 | 해당 AC |
|---|---|---|
| FR-ARCH-013 | 모바일 Ctrl 래치를 켠 채 터미널의 경로를 탭하면 파일이 열린다. 길게 누르기 경로 메뉴가 '확인 중…'에서 멈추지 않고 항목을 보여 준다. | AC-10, AC-11 |
| FR-MDE-028 | 맞춤 보기에서 두 손가락으로 확대하면 앱 화면이 아니라 시안만 확대된다. 한 손가락으로 시안 내부가 스크롤되고, 탭하면 시안 안이 클릭된다. | AC-11 |
| FR-ARCH-015 | 설정에서 전체 화면 프로그램 스크롤 속도를 낮추면, Claude Code 위에서 한 손가락으로 끌 때 실제로 느리게 스크롤된다. | AC-2, AC-3 |

FR-ARCH-015의 확인은 앞선 작업이 남긴 한계를 닫는다. ego 실측(VE-4)은 앱이 보내는 휠 신호 수가 배율대로 줄어드는 것까지만 확인했고, 그 신호가 실제 프로그램에 도착하는지는 관측하지 못했다.

## SRS 반영

- 세 요구사항에 실기기 확인 증거를 추가했다(FR-ARCH-013 VE-13, FR-MDE-028 VE-9, FR-ARCH-015 VE-5). 증거의 참조는 이 보고서다.
- FR-ARCH-015의 ego 실측 증거(VE-2, VE-4)는 참조가 설명 문장이라 speckiwi의 승급 검사를 통과하지 못했다. 그 측정을 기록한 `docs/report/2026-10-28.mobile-fullscreen-scroll-speed.md`로 참조를 바꿨다.
- FR-MDE-028과 FR-ARCH-015는 모든 AC가 체크되어 있고 각 AC에 자동 테스트나 실측 증거가 있으므로, 상태를 `implemented`에서 `verified`로 올렸다.
- FR-ARCH-013은 `implemented`로 두었다. 다른 작업이 남긴 증거 세 건의 참조가 파일이나 올바른 URL이 아니어서 승급 검사를 통과하지 못한다(2026-10-19 아이폰 확인, 2026-10-22 Playwright 확인 두 건). 남의 기록을 고쳐 쓰지 않기 위해 이번에는 손대지 않았다.
