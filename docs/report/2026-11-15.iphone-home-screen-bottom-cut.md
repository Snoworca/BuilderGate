# 아이폰 홈 화면 앱에서 화면 아래쪽이 잘림 (FR-ARCH-016 AC-6)

## 이슈

- 2026-11-15 사용자 보고: 아이폰 홈 화면에 추가한 BuilderGate 를 열면, 키보드가 내려가 있을 때 화면 아래쪽이 잘려 맨 아래 깃 상태 줄이 보이지 않는다.
- 사용자에게 확인한 내용은 다음과 같다.
  - 기기는 아이폰이고, iOS 26 이다.
  - 키보드를 올렸다 내린 뒤가 아니라, 앱을 처음 열 때부터 잘린다.
  - 깃 상태 줄과 함께 터미널 줄도 몇 줄 가려진다.

## 원인

- `index.html` 의 `apple-mobile-web-app-status-bar-style` 이 `black`(불투명)이었다.
- 이 설정에서 iOS 26 은 웹 화면을 상태 표시줄 아래에서 시작하면서, 높이는 화면 전체로 잡는 것으로 판단했다. 그 결과 상태 표시줄 높이(약 50~60px)만큼 앱 아래쪽이 화면 밖으로 밀린다. 잘린 양이 「깃 상태 줄 + 터미널 두세 줄」이라는 보고와 맞는다.
- iOS 26 의 홈 화면 앱과 Safari 에서는 화면 높이 계산이 어긋나는 문제가 여러 건 보고되어 있다(WebKit 300523, 301857 등).
- 어제 iPad 수정(`262f8241`)은 원인이 아니다. 폰에서는 `isMobile` 과 `isTouchInput` 이 같아서 그 수정이 폰의 동작을 바꾸지 않는다.
- 실기기에서 `innerHeight` 같은 수치를 직접 재지는 못했다. 따라서 위 원인은 가설이며, 실기기 확인으로 판정한다.

## 해결

홈 화면 앱에서만 페이지가 화면 전체(상태 표시줄 영역 포함)를 덮게 하고, 상태 표시줄과 홈 인디케이터 영역은 앱이 직접 비운다.

- `index.html`: `apple-mobile-web-app-status-bar-style` 을 `black-translucent` 로 바꿨다. 이 값은 홈 화면 앱에만 적용된다.
- `utils/standaloneViewport.ts`(신규): `navigator.standalone` 이 true 이거나 `(display-mode: standalone)` 이면 다음 두 가지를 한다.
  - viewport 메타에 `viewport-fit=cover` 를 한 번만 덧붙인다.
  - `html` 에 `standalone-app` 클래스를 단다.
- `main.tsx`: 첫 렌더 전에 위 함수를 부른다.
- `globals.css`:
  - `html.standalone-app` 을 `env(safe-area-inset-*)` 네 방향만큼 띄운다. 띄운 띠는 이전 불투명 상태 표시줄처럼 `#1e1e1e` 로 칠한다.
  - 키보드가 올라와 있는 동안 `--app-height` 는 화면 전체 기준의 보이는 높이다. 그래서 `.app` 높이에서 상단 inset 을 뺀다.
  - 키보드가 올라와 visual viewport 에 고정된 `.app` 은 루트의 여백 밖에 있다. 그래서 상단 inset 만 스스로 비운다. 하단은 키보드가 홈 인디케이터를 덮으므로 비우지 않는다.
- Safari 탭과 PC 에서는 viewport 와 레이아웃이 그대로다(FR-ARCH-016 AC-4).

## 요구사항

- FR-ARCH-016 에 AC-6 을 추가했다. 실기기 확인 전이라 체크하지 않았다. 검증 증거 VE-4 와 변경 노트를 남겼다.

## 검증

- `tests/unit/standaloneViewport.test.ts` 6/6. 처음에는 모듈이 없어 실패했고, 모듈만 만든 상태에서는 4/6 이었다(상태 표시줄 스타일과 CSS · `main.tsx` 배선 두 건 실패). 검사한 내용은 다음과 같다.
  - 홈 화면 앱 판정(`navigator.standalone`, display mode)
  - `viewport-fit=cover` 를 한 번만 덧붙이는지
  - 브라우저 탭에서는 viewport 와 루트를 건드리지 않는지
  - `black-translucent`
  - `html.standalone-app` 의 네 방향 safe-area 여백과, 키보드 고정 상태의 상단 여백
  - `main.tsx` 가 첫 렌더 전에 설치하는지
- `tests/unit/homeScreenApp.test.ts` 3/3: viewport 메타 원문이 그대로인지(AC-4) 포함.
- `test:unit:mobile-keyboard` 103/103.
- `tsc -p` app · test · node 오류 0. `speckiwi validate` 오류 0, `check:kiwi-status` · `check:srs-change-notes` 통과.
- 바꾼 파일 중 소비자 매니페스트가 봉인한 파일은 없어 재봉인하지 않았다.

## 남은 일

- 실제 아이폰 확인: 홈 화면 앱을 완전히 닫았다가 다시 열어야 바뀐 상태 표시줄 설정이 적용된다. 다음 세 가지를 확인해야 한다.
  - 깃 상태 줄까지 보이는지
  - 헤더가 상태 표시줄에 가리지 않는지
  - 키보드를 올렸을 때 키 줄이 키보드 바로 위에 붙는지
- 가설이 틀렸다면 기기에서 `innerHeight`, `visualViewport` 수치를 재는 방법을 따로 마련해야 한다.
- 라이트 테마에서도 상태 표시줄 띠는 어두운 색이다. 이전 불투명 상태 표시줄과 같은 모습이다.
