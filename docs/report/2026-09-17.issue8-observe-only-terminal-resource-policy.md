# Issue #8 — TerminalResourcePolicy observe-only compiler and settings inventory telemetry

Requirement: `OBS-BGSTAB-005`. Baseline: `bc94bea`.
Evidence bundle: `docs/analysis/2026-09-17.issue8-observe-only-policy/` with `SHA256SUMS.txt`.

## Issue

`OBS-BGSTAB-005` carried `Status=implemented` with AC-1 through AC-7 all checked, every
implementation file present, and a sealed "No findings" closure recorded on the issue. At the same
time the VE-11 row on `REL-BGSTAB-001` listed three of this Requirement's own tests among six
pre-existing unresolved failures — including the static inventory contract test that AC-6 names.

A checked acceptance criterion whose named test is red in the committed record is not a stale
premise; it is a false record. So the first deliverable was a measurement, not a fix.

## Root cause

Measured at `bc94bea`, `cwd=server/`:
`npx tsx --test src/services/TerminalResourcePolicy.test.ts` → exit 1, tests 20 / pass 17 / fail 3.
The VE-5 guard `node tools/wave3/terminal-resource-consumer-manifest.test.mjs` → exit 1.

All three failures threw from one place, so only one cause was ever visible. Fixing each exposed the
next. There were four:

1. **Not pre-existing.** Commit `1ae3787` (REL-BGSTAB-009) moved the grace lane out of
   `WebSocketProvider#bufferGraceMessage` into `terminalGraceBuffer#applyGraceBufferedMessage` —
   an identical body, by its own commit message — and updated its own regex gates but not this
   Requirement's consumer catalog. Measured ancestry: `1ae3787` is **not** an ancestor of `a6c7edc`
   (VE-11's HEAD) or `8f8f934` (the 2026-09-16 Change Note's baseline), and **is** an ancestor of
   `bc94bea`.
2. `ConfigFileRepository.ts`'s classification `accessEvidenceSha256` pin went stale when
   `resourceLimits.telemetry.sampleIntervalMs` was retired, so the file lost its exemption and its
   `@resource-limits-root.[dynamic]` render access surfaced as an unregistered call site.
3. The `reserved-copy-option-decoy` mutation fixture pinned a CRLF marker against `SessionManager.ts`,
   which is LF in this checkout, so the fixture failed on its own setup instead of posing its question.
4. `TerminalResourcePolicyObservations.ts`'s compact decision list never gained
   `resourceLimits.terminal.checkpointMaxBytes` when REL-BGSTAB-023 registered it.

Causes 2–4 are genuinely pre-existing and reproduce at the earlier baselines. Cause 1 is not, and it
had inherited their label because a failure-name match across commits was read as a cause match.
Nothing in the failing output distinguished them.

## Resolution

- Re-pointed four catalog tuples and six mutation fixtures at the relocated owner.
- Made fixture insertion newline- and indentation-agnostic, matching a run of trimmed lines and
  asserting that exactly one occurrence was found before editing. The decoys are still rejected,
  which is the evasion set re-run after the relaxation.
- Re-pinned the `ConfigFileRepository.ts` access hash after reviewing its only delta since the
  previous pin: `sampleIntervalMs` retired and `checkpointMaxBytes` added, across the apply and
  render paths, all persistence-boundary, no new dynamic access.
- Added the missing compact decision; re-sealed manifest and lineage.
- **AC-1 was also substantively false while its own test passed.** `assertRepositoryPath` asserts
  `existsSync` only, which is true of the correct state and of the defect. AC-1 now also requires
  each entry's `evidenceSignature` to occur in the file the manifest names, and asserts its own
  check count first so it cannot pass vacuously over an empty set. Restoring the pre-fix
  `consumerPath` reddens AC-1 through that new assertion, by its own message.
- **Two guard contracts were unsatisfiable rather than strict**, and were split by what each is
  evidence of: classification pins were held equal to an immutable seal although they must move
  when a classified file's accesses change, and now require enumeration in the sealed lineage
  exactly as resource decisions already did; and one regex asserted the focused pass count over both
  the live run and the sealed PH-001 artifact, satisfiable only by forging that artifact or freezing
  two suites.
