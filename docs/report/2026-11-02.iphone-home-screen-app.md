# 아이폰 홈 화면 앱 지원 추가

## 개요

이 보고서는 아이폰 Safari에서 BuilderGate를 홈 화면에 추가해 주소 표시줄 없이 열 수 있게 한 작업을 기록한다.

- 요구사항: FR-ARCH-016, `docs/spec/10.product-architecture.srs.md`
- 브랜치: `feat/home-screen-app`(`fix/tab-switch-size-lease` 위, main 0.10.34 기준)
- 작업일: 2026-10-31 ~ 2026-11-02

## 배경

- 아이폰 Safari는 주소 표시줄을 화면 아래에 둔다. 스크롤하면 작아지지만, 웹 페이지가 이 막대를 계속 작게 유지할 방법은 없다.
- 이 막대가 휴대폰 화면에서 터미널 줄 몇 개를 차지한다.
- 홈 화면에 추가한 웹 앱을 `display: standalone`으로 열면 주소 표시줄과 툴바가 없다.

## 해결 방법

- `frontend/public/manifest.webmanifest`를 추가했다. 내용은 다음과 같다.
  - 이름 `BuilderGate`, `start_url`과 `scope`는 `/`
  - `display: standalone`, 배경색과 테마색 `#1e1e1e`
  - 192×192, 512×512 PNG 아이콘
- `logo.svg`를 `#1e1e1e` 정사각형 위에 84% 크기로 그려 PNG 아이콘 세 개(180, 192, 512)를 만들었다.
- `frontend/index.html`에 다음을 추가했다.
  - manifest 링크
  - `apple-touch-icon`(180×180)
  - `apple-mobile-web-app-capable`, `apple-mobile-web-app-title`, `apple-mobile-web-app-status-bar-style`
- 다음 두 가지는 일부러 바꾸지 않았다. 그래서 Safari 탭과 PC 화면은 전과 같다.
  - viewport 태그(`viewport-fit=cover`를 넣지 않음)
  - `theme-color` 태그(Safari 탭 막대 색을 바꿀 수 있어 넣지 않음)

홈 화면 앱은 같은 서버의 같은 페이지다. 그래서 워크스페이스, 탭, 세션은 PC에서 하던 그대로 이어진다. 다만 iOS에서는 저장소가 Safari와 분리되므로 홈 화면 앱에서 한 번 따로 로그인해야 한다.

## 검증

- 단위 테스트: `homeScreenApp.test.ts`는 구현 전에 1/3(AC-4만 통과)이었고, 구현 후 3/3이다. 0.10.34 위로 리베이스한 뒤에도 3/3이다.
- 2222, 로그인하지 않은 상태: `manifest.webmanifest` 200(`application/manifest+json`), 아이콘 세 개 모두 200(`image/png`).
- 아이폰 실기기: 사용자가 Safari에서 홈 화면에 추가하고 아이콘으로 열어 확인했다.
