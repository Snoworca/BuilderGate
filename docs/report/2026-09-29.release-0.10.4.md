## 검증

- **데몬 테스트**: `tools/daemon/*.test.js` 253/256. 실패 3건(`node-pty-windows-hide` 2건, `terminal-snapshot-quota` 1건)은 WSL 과 Windows `node_modules` 차이로 인한 실패이며, 이번 변경과 무관하다.
- **릴리즈 가드**: `test:release-pipeline` exit 0. 소비자 매니페스트는 `McpToolService.ts` 버전 문자열만 바뀌어 재봉인했고, tuples/classifications 는 변하지 않았다.
- **2222 exe 실측**: MSI 설치 이미지를 쓰는 LocalAppData 레이아웃, 첫 실행 포트 이동(2221→2222)과 저장, 점유 포트 거부(exit 2), 포터블 폴더의 기존 동작 유지.

## 알려진 한계

- 관리자 권한이 필요한 실제 MSI 설치·업그레이드·제거는 로컬에서 돌리지 않았다.
- 코드 서명이 없어 MSI 실행 시 SmartScreen 경고가 뜬다.
- 기존 포터블판 설정을 설치판으로 자동으로 가져오지 않는다.
