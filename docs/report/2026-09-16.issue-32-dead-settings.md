  표시를 함께 허용한다(`logging?:`). 콜론이 이름 바로 뒤에 붙을 것을 요구하던 최초 형태는
  `config.types.ts` 의 지배적 관용구인 `logging?: { ... }` 를 통째로 놓쳤다. 문자열 *값* 으로
  쓰인 `'logging'`(시나리오 이름)은 의도적으로 무시한다 — 허용 목록을 넓히는 대신 패턴을

  필드(`sampleIntervalMs: countLimit(...)`)로 되살아나면 두 형태 어느 쪽에도 맞지 않아
