# 터미널 메뉴 아이콘 · Workspace 활동 점 · Workspace 영어 표기

- 날짜: 2026-09-26
- 요구사항: FR-UIDS-005(신규), FR-UIDS-003 AC-1(Workspace 표기 규칙 추가)
- 커밋: `5d1c4214`

## 이슈
1. 세션 터미널 우클릭 메뉴에서 "파일 탐색기 열기"만 아이콘이 없었다.
2. 시안처럼 워크스페이스 항목 왼쪽에 회색·초록 원을 붙인다. 실행 중인 세션이 있으면 초록이다.
3. 한글 음역 "워크스페이스"가 어색하다. 영어로 바꾼다.

## 원인
- 메뉴 항목의 아이콘은 글자(`+ ✕ ⇄ ⎘ ⎗`)였고, 파일 탐색기 항목에는 아이콘 값이 없었다.
- 워크스페이스 행은 실행 중인 탭 수만 호박색 배지로 보여 주고, 상태 점은 없었다.

## 해결
- 메뉴의 모든 항목을 공용 아이콘 이름으로 바꿨다. 이동에 쓸 `swap`, 붙여넣기에 쓸 `clipboard`를 아이콘 세트에 추가했다.
- `workspaceActivity(runningCount)`가 행의 상태를 정하고, 행 이름 왼쪽에 8px 원을 그린다.
  - 탭 중 하나라도 상태가 `running`이면 초록(`--ok`), 아니면 회색이다.
  - 상태 이름(실행 중, 대기)을 aria-label과 title로도 준다.
- "워크스페이스"를 "Workspace"로 바꿨다(화면 문구 12곳). 목록 제목은 "Workspaces"이다. 가드 테스트가 음역이 다시 들어오지 못하게 막는다.
- `session-restore.spec.ts`를 고쳤다.
  - 이전 방식은 두 번의 실행에 걸쳐 워크스페이스를 넘겼는데, 이것이 B2 소유권 규칙을 어겼다.
  - 이제 한 번의 실행 안에서 `/health`의 pid가 바뀔 때까지 기다린다. 워크스페이스는 소유권 헬퍼로 만들고 지운다.
