# 0.10.1 — exe 입력 유실·세션 종료와 Codex 작업 중 입력 미전달

## 증상
1. exe 릴리즈판에서 첫 세션에 입력하면 "입력이 전달되지 않았습니다" 후 세션이 끊김(개발 모드는 정상)
