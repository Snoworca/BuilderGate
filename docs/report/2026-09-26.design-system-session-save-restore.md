# 디자인 시스템 전면 적용 · 세션 저장과 재시작 후 이어하기

- 날짜: 2026-09-26
- 요구사항: CON-UIDS-001, FR-UIDS-001..004, NFR-UIDS-001 (`docs/spec/44.ui-design-system.srs.md`), FR-AITUI-006..009 (`docs/spec/20.ai-tui-recovery.srs.md`)
- 커밋: `1332fbc3` (서버), `98ba1f0c` (프런트·E2E·SRS). 기반은 `87e026b8` (토큰·아이콘·공용 부품)

## 이슈

1. 견본(`docs/research/2026-09-26.ui-design-system.html`)의 디자인 시스템(아이콘, 크기, 문구)을 앱 전체에 적용하고, 문구를 한국어로 통일한다. 세션 터미널 영역(가는 구분선, 하단 상태 표시줄)의 레이아웃은 바꾸지 않는다.
2. 실행 중인 AI 에이전트(Claude, Codex, Hermes, OpenCode)의 세션 ID를 버튼으로 저장하고, BuilderGate 재시작 뒤 그 세션을 이어할 수 있게 한다. 훅은 쓰지 않는다. 저장은 에이전트를 종료하지 않는다.

## 원인과 설계

- 기존 화면은 hex 색, 제각각인 글자 크기, 유니코드·이모지 아이콘, 영어 문구가 섞여 있었다. 토큰·공용 부품·선 아이콘 세트는 `87e026b8`에서 마련했고, 이번에 각 화면을 거기로 옮겼다.
- 재시작하면 탭은 셸로 복구되지만, 복구 옵션의 `--continue`가 어느 세션으로 붙을지는 에이전트가 정한다. 탭마다 정확한 세션 ID가 필요하고, 그 값은 실행 중인 에이전트의 기록에서만 얻을 수 있다(연구: `docs/research/2026-09-26.agent-session-id-discovery.md`).

## 해결

### 서버 (`1332fbc3`)
- `server/src/services/agentSession/`는 에이전트별로 세션 ID를 해석하고, 확실도를 exact 또는 estimated로 붙인다.

  | 에이전트 | 해석 방법 |
  |---|---|
  | Claude | PTY 프로세스 트리에 속한 PID의 `sessions/<pid>.json` |
  | Codex | 잠겨 있는 `thread-writer-locks`와 rollout의 cwd 대조 |
  | OpenCode | 프로세스 시작 시각에 가장 가까운 로그의 마지막 `session.id` |
  | Hermes | 출력 표시, 또는 state.db |

  에이전트별 ID 형식을 검사한다. 기록 위치는 `BUILDERGATE_AGENT_*`로 바꿀 수 있다.
- `SessionSnapshotService`와 `/api/session-snapshot`은 후보 조회, 저장(원자적 쓰기, 권한 0600), 상태, 이어하기, 버리기를 제공한다.
- 고아 탭 복구: 저장본에 pending 항목이 있는 탭은 자동 복구 명령을 건너뛴다. 이어하기는 복구 옵션의 명령과 인자를 유지한 채 세션 선택자만 바꾸고, 셸에 맞게 인용해 보낸다.

### 프런트 (`98ba1f0c`)
- 디자인 시스템을 76개 파일에 적용했다.
  - 대상 화면: 헤더, 사이드바, 탭 막대, 대화상자, 설정·인증 화면, 도구 창, 편집기, 파일 탐색기
  - 가드 테스트(`frontend/tests/unit/uiDesignSystem.test.ts`)가 hex 색, 토큰 밖 크기, 글자 아이콘, 영어 문구가 다시 들어오지 못하게 막는다.
  - 가드 예외는 이유와 함께 3건만 둔다:
    - 복구 옵션 이모지: 사용자 데이터
    - `✓ 복사됨`: 텍스트 표식
    - 벤더링 편집기의 팔레트
- 세션 터미널 영역(`MosaicTile`, `MosaicOverrides.css`, `MetadataRow`, `Terminal/`)은 문구와 같은 값의 토큰만 바꿨다. 가드 목록에서 빠져 있다는 것도 테스트한다.
- 세션 화면 (`frontend/src/components/SessionSave/`)
  - 헤더 책갈피 버튼은 상태에 따라 세 가지로 보인다: 저장(배지), 저장됨·시각, 이어하기·개수.
  - 저장 창, 재시작 배너, 이어하기 창을 추가했다. 이어하기 창은 보낼 명령을 미리 보여 주고, exact 항목만 기본으로 선택한다.
- E2E
  - 바뀐 문구에 맞춰 선택자 27개 파일을 갱신했다.
  - `session-save.spec.ts`를 새로 만들었다.
  - `session-restore.spec.ts`도 새로 만들었다. 준비, 재시작, 이어하기의 두 단계로 돌며, `BUILDERGATE_E2E_RESTORE_PHASE`가 없으면 건너뛴다.

## 남은 것과 한계

- **E2E 실패 4건**: 선택자 변경 때문에 난 실패는 없다.
  - 1건(명령줄 실행): 활성 탭이 사용자 Workspace-1의 Claude 신뢰 확인 화면이라 입력을 가져갔다. 재시작 때마다 자동 복구가 이 탭에서 `claudep --continue`를 실행한다.
  - 2건(터미널 키보드): 워크스페이스 한도 때문에 409가 났다. 이전 편집기 테스트가 남긴 `e2e-mde-*` 워크스페이스 5개가 한도를 차지하고 있다. 그 ID는 이 작업이 만든 것이 아니어서 지우지 않았다.
  - 1건(명령줄 삭제 실패 안내): `apiError.ts`가 `{error: "문자열"}` 형태의 본문을 읽지 못해 "HTTP 500"이 나온다. 관련 파일은 HEAD와 같다.
- **모놀리식 러너 1건**: `authRoutes twoFactor.externalOnly`. 바로 앞 TCP 테스트가 `server.close()`를 기다리지 않은 채 같은 2222를 다시 연다. 단독으로 돌리면 통과한다. 이 러너는 2222가 비어 있어야 끝까지 돈다.
- 영향받는 E2E 전량은 다시 돌리지 않았다(FR-UIDS-004 AC-4, AC-5는 체크하지 않음).
- 자동 검사가 없는 AC는 체크하지 않았다: FR-UIDS-001 AC-4(아이콘 크기 규칙), FR-UIDS-003 AC-2·AC-3(문구 규칙), NFR-UIDS-001 AC-1·AC-3·AC-4.
- 서버가 보내는 셸 선택 메뉴 아이콘은 아직 이모지다. 컨텍스트 메뉴는 아이콘 이름을 받을 수 있으므로, 바꾸려면 `SessionManager`의 데이터만 고치면 된다.
