# Windows Chrome 한글 조합 중 Backspace가 앞 글자를 지우는 문제 수정

## 개요

이 보고서는 Windows Chrome에서 한글을 조합하는 중 Backspace를 누르면 앞 글자까지 지워지던 문제를 고친 결과를 기록한다.

- 요구사항: FR-BGSTAB-038(신설), `docs/spec/30.buildergate-stability.srs.md`
- 이슈: #220
- 브랜치: `fix/windows-hangul-backspace`(main `8b3dff87`, 0.10.34 기준)
- 작업일: 2026-11-02

## 증상

- **아니**를 입력하고 Backspace를 두 번 누르면, 첫 번째에서 니가 ㄴ이 되고 두 번째에서 **아**까지 지워져 줄이 비었다.
- 기대한 결과는 ㄴ만 지워지고 **아**가 남는 것이다.
- 영문 입력과, 조합이 끝난 뒤(스페이스로 완료)의 Backspace는 정상이었다.
- 사용자는 Windows PC에서 확인했고, 아이폰에서는 생기지 않는다.

## 측정

사용자가 2222의 터미널 화면에서 이벤트 기록 스크립트를 실행하고 같은 입력을 반복했다. 두 번째 Backspace의 이벤트 순서는 다음과 같았다.

```
keydown Process keyCode=229 isComposing=true
compositionupdate ""
beforeinput insertCompositionText ""
input deleteContentBackward isComposing=false   (입력창 "아ㄴ" -> "아")
SEND DEL
compositionend ""
```

xterm 6.0.0은 `deleteContentBackward` input 이벤트를 처리하지 않는다. 그러므로 이 DEL은 BuilderGate 코드가 보낸 것이다.

## 문제 원인

- FR-BGSTAB-036(맥 Safari 한글 입력, v0.10.30)은 맥 Safari의 한글 IME가 조합 이벤트를 보내지 않는 문제를 다룬다. 그래서 "조합 밖에서 입력창이 바뀌었는데 xterm이 보내지 않은 변화"를 터미널로 보낸다(`iosHangulInput.ts`의 `handleInput`).
- Windows Chrome은 조합의 마지막 자모를 지울 때, `compositionend`보다 먼저 `isComposing=false`인 `deleteContentBackward`를 보낸다.
- `handleInput`은 이벤트의 `isComposing`만 보고 이것을 조합 밖의 변화로 판단했고, 줄어든 한 글자만큼 DEL을 보냈다.
- 터미널은 ㄴ을 받은 적이 없다. 조합 중인 글자는 xterm이 `compositionend`에서 보내기 때문이다. 그래서 그 DEL은 앞 글자 **아**를 지웠다.

## 해결 방법

- `iosHangulInput.ts`에 `handleComposition(active)`를 추가했다. `compositionstart`부터 `compositionend`까지를 조합 중으로 기억한다.
- 조합 중에는 `handleInput`과 `interceptInput`이 이벤트의 `isComposing` 값과 관계없이 입력창 변화를 보내지 않는다.
- `TerminalView.tsx`의 `compositionstart`·`compositionend` 리스너가 이 함수를 부른다.
- 조합된 글자는 전처럼 xterm이 `compositionend`에서 보낸다.
- 맥 Safari와 아이폰 한글 키보드, 받아쓰기는 조합 이벤트를 보내지 않으므로 동작이 바뀌지 않는다.

## 검증

- `windowsHangulBackspace.test.ts`: 구현 전 1/3(`handleComposition` 없음), 구현 후 3/3.
- 변이 확인: 고친 조건(`compositionActive`)을 빼면 `['아', DEL]`이 나가며 실패한다. 이것은 보고된 증상과 같다.
- 회귀: mobile-keyboard 98/98(아이폰 한글, 맥 Safari 한글, 받아쓰기 포함), terminal-view-behavior 93/93, 앱 타입 검사 오류 0.
- Windows Chrome 실기기: 수정을 2222에 반영한 뒤(번들 `index-Zum-xF2D.js`) 사용자가 **아니** + Backspace 두 번을 입력했고, **아**가 남았다.
