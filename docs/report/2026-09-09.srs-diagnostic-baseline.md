## 재검증

MCP `get_work_mode({})`, `get_active_target({})`, `validate_spec({})`, `summarize_target({target:"wave-5"})`를 재조회한다. 링크 검사는 지원 MCP가 없으면 `speckiwi links check --json`을 사용한다. MCP 부재 시 validate는 `speckiwi validate --fail-on-warning --json`, summary는 `speckiwi summary --target wave-5 --json`으로 대체할 수 있다. 이 대체 명령을 이번 실행에서 모두 실행했다고 주장하지 않는다.

새 진단 발생 시 진행 전 원인을 확인하고, 요구사항 수정이 필요하면 지원 MCP로 처리한다. 현재는 진단 0이므로 repair, 새 Requirement 생성, 상태 변경을 수행하지 않았다. 기존 모니터가 문서상의 수동 절차라는 검색 결과를 넘어 저장소 전체 자동화 부재를 단정하지 않는다.
