# i18n 구현 (영어·한국어, 설정 언어 선택)

## 요청
연구 결과(docs/research/2026-09-27.i18n.md)에 따라 SRS 를 작성하고 i18n 구현을 완료한다. 도중 추가: 설정에 언어 선택 셀렉터(사용자 편의 + 한국어 브라우저에서 영어 화면 확인).

## SRS
- 새 scope `docs/spec/45.i18n.srs.md`, target `i18n`: FR-I18N-001~006, NFR-I18N-001, CON-I18N-001 — 전부 `implemented`, 검증 증거 등록
- 승계: FR-UIDS-003 → FR-I18N-005(ko 사전 문구 규칙), FR-UIDS-004 → FR-UIDS-007(AC-6 에 사전 키 이전·영어 로캘 허용 추가)
- draft→evolving 은 사용자 지시(/goal: 구현 완료)를 승인으로 보고 진행

## 구현
- 런타임 `frontend/src/i18n/`: `negotiate.ts`(navigator.language 가 한국어면 ko, 아니면 en), `catalog.ts`, `i18n.ts`(`Map<언어, Map<키, 문구>>`, `t`/`tn`, 렌더 전 `initI18n`, 설정 선택 localStorage), `keys.ts`(en JSON 에서 키 타입), `editorPhrases.ts`
- 사전 `frontend/public/locales/`: `languages.json`, `messages.ko.json`, `messages.en.json` — 서버 웹 루트에서 정적으로 받는다(서버 코드 변경 없음)
- 문구 추출: 84개 파일 958곳 → 키. ko 값은 원문 그대로, en 은 새 번역. 모듈 로드 중 `t()` 금지(표는 키를 담고 사용 시 번역)
- 편집기: 벤더 검색 패널·표 메뉴 16곳을 `view.state.phrase()` 로(단독 커밋 ea1a91ba, UPSTREAM.md 1행), CodeMirror 내장 문구와 함께 `EditorState.phrases` 로 번역
- 설정 화면 "언어" 카드: 자동 / English / 한국어. 바꾸면 새로고침해 적용
- E2E: `playwright.config.ts` 에 `locale: 'ko-KR'`(파생 설정 6개 포함 7개)
