# i18n 연구 (영어·한국어)

- **요청**: 영어·한국어를 지원하는 i18n 을 연구한다. 연구 도중 방향이 바뀌었다 — 프런트엔드에서 구현하고, 언어는 브라우저로 정하며(`navigator.language` 가 한국어면 한국어, 아니면 영어), 사전은 서버의 JSON 에서 받는다.
- **산출물**: [docs/research/2026-09-27.i18n.md](../research/2026-09-27.i18n.md), 추출 스크립트와 문구 목록 `docs/research/2026-09-27.i18n/`
- **핵심 사실**:
  - 옮길 한국어 문구는 958개(중복 제외 744개, 84개 파일)다. 그중 165개는 모듈 최상위에서 평가돼 `t()` 로 바로 바꿀 수 없다. 서버에는 한국어 문구가 없다.
  - 정적 JSON 을 쓰면 서버 코드 변경이 필요 없다.
  - 한국어 셀렉터를 쓰는 E2E 38개 파일이 로캘 `ko-KR` 고정을 필요로 한다.
  - FR-UIDS-003 전체와 FR-UIDS-004 를 승계해야 한다.
- **코드 변경**: 없음(연구만). SRS 는 초안만 있고 등록하지 않았다.
- **커밋**: 없음
