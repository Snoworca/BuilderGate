# iPad 에서 터미널 스크롤과 모바일 키보드가 동작하지 않음 (FR-ARCH-008 AC-4, FR-MKB-013 AC-5)

## 이슈

- 2026-11-14 사용자 보고: iPad 로 접속하면 Claude Code 세션과 일반 cmd 창 모두 터미널 안의 문자열이 스크롤되지 않는다.
- 손가락으로 끌면 터미널 대신 앱 화면 전체가 내려갔다가 올라온다.
- 모바일 키보드(방향키 · Esc · Ctrl 키 줄과 특수 키보드)가 나타나지 않는다.

## 원인

- `useResponsive` 의 `isMobile` 은 레이아웃 판정이다(`MOBILE_LAYOUT_QUERY`, FR-UIDS-015). iPad 는 화면이 넓고 높아서 의도대로 데스크톱 레이아웃을 받는다.
- 그런데 터치 입력 처리도 같은 `isMobile` 에 묶여 있었다.
  - `TerminalView.tsx` 의 한 손가락 스크롤 · 핀치 처리기는 `if (!isMobile) return;` 으로 휴대폰 레이아웃에서만 붙었다.
  - `.terminal-view` 의 `touch-action: none` 도 `isMobile` 일 때만 적용됐다.
  - 키 줄 표시 판정(`decideMobileKeyBar`), 입력 포커스 감시(`useTerminalInputFocus`), 시스템 키보드 판정(`useSystemKeyboardUp`)도 모두 `isMobile` 을 받았다.
- 그래서 iPad 에서는 터미널 위의 터치 이동을 아무도 소비하지 않았다(코드로 확인). iOS Safari 는 `html, body` 가 `overflow: hidden` 이어도 처리되지 않은 드래그를 문서 전체의 탄성 스크롤(바운스)로 처리하므로, 앱 화면 전체가 움직인 것으로 추정한다. 바운스 자체는 실기기에서 관찰하지 않았다(남은 일 참조).
- 탭으로 터미널에 포커스를 주는 경로(`TerminalRuntimeLayer.tsx`, FR-ARCH-010)는 `isMobile` 과 무관하다. 따라서 하드웨어 키보드가 없다면 탭했을 때 iOS 시스템 키보드는 원래도 떴을 것으로 본다. 이 부분은 실기기에서 확인하지 않았다.

## 해결

- **터치 입력 판정을 레이아웃과 분리했다.** `utils/touchInput.ts` 에 `TOUCH_INPUT_QUERY = '(pointer: coarse)'` 와 `usesTouchInput({ mobileLayout, coarsePointer })` 를 두고, `useResponsive` 가 `isTouchInput`(휴대폰 레이아웃 또는 주 포인터가 손가락)을 함께 돌려준다. 레이아웃 판정(`isMobile`)은 바꾸지 않았다.
  - 터치스크린 노트북은 주 포인터가 마우스(`pointer: fine`)이므로 지금과 같이 데스크톱으로 동작한다.
- **터미널:** 한 손가락 스크롤 · 핀치 처리기와 `touch-action: none` 을 `isTouchInput` 으로 붙인다.
- **모바일 키보드:** 키 줄 판정, 포커스 감시, 시스템 키보드 판정, 특수 키보드 닫기, 수식키 래치 초기화를 `isTouchInput` 으로 판정한다. 하드웨어 키보드를 붙인 iPad 는 시스템 키보드가 올라오지 않으므로 FR-MKB-013 AC-1 에 따라 키 줄이 숨은 채로 남는다.
- **문서 바운스 차단:** `globals.css` 의 `html, body, #root` 에 `overscroll-behavior: none` 을 더했다.

## 요구사항

- FR-ARCH-008 AC-4 추가: 데스크톱 레이아웃을 유지하는 터치 기기(iPad)에서도 한 손가락 스크롤 · 핀치가 동작하고 문서가 바운스하지 않는다.
- FR-MKB-013 AC-5 추가: 키 줄 판정의 `isMobile` 은 터치가 주 입력인 기기를 뜻한다.
- 두 AC 는 실제 iPad 확인 전이라 체크하지 않았다. 검증 증거(VE)와 변경 노트를 남겼다.

## 남은 일

- 실제 iPad 확인: iOS 바운스와 시스템 키보드는 Chromium 터치 에뮬레이션으로 재현되지 않는다. 2222 브라우저 확인도 하지 않았다(이 셸에 `BUILDERGATE_PASSWORD` 가 없어 로그인할 수 없었다).
- iPad 에 매직 키보드 트랙패드를 붙였을 때 Safari 가 `pointer` 를 `fine` 으로 바꾸는지 확인하지 않았다. 바꾼다면 그때는 데스크톱 동작(트랙패드 휠 스크롤)을 받는다.
