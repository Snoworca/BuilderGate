# E2E 실패 2건 해결 · Workspace 수/총 세션 수 제한 해제

## 요청
1. i18n 이전부터 실패하던 E2E 2건을 해결한다(테스트가 잘못됐으면 고치거나 지운다).
2. Workspace 수 제한과 전체 세션 수 제한을 해제한다. Workspace 당 세션(탭) 제한은 그대로 둔다.

## E2E 2건
| 스펙 | 원인 | 조치 |
|---|---|---|
| settings-password-policy TC-2401 | 테스트 결함. 가짜 토큰으로 로그인하는 완전 목 앱인데 `runtime-config`·`session-snapshot`·`session-snapshot/candidates`·`terminal-shortcuts` 요청에 목이 없어 실제 서버로 가서 401 → 로그아웃 | 목 앱에 catch-all(404) 을 먼저 등록해 목 없는 요청이 실제 서버에 닿지 않게 함 |

## 제한 해제 (FR-BGSTAB-026 → FR-BGSTAB-031 승계)
- 서버: `maxWorkspaces`·`maxTotalSessions` 스키마·템플릿·예시·설정 인벤토리에서 제거, `WORKSPACE_LIMIT_EXCEEDED`·`SESSION_LIMIT_EXCEEDED` 제거, `GET /api/workspaces` 의 `limits` 는 `{ maxTabsPerWorkspace }` 하나
- 옛 설정 파일의 두 키는 `RETIRED_CONFIG_KEYS` 로 경고 없이 무시(기존 배포가 그대로 기동). 잔존 가드(`retiredSettingsResidue`)에 등록
- 프런트: 사이드바 Workspace 추가 버튼은 개수로 막히지 않고, 탭 막대는 Workspace 당 탭 한도만 봄. 관련 사전 키 삭제
- 테스트: 제거된 동작만 검사하던 테스트는 삭제, 탭 한도 테스트는 유지·조정(단위 7개 파일, E2E 4개 파일)
