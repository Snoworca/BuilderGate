## 5. 계측기 사고 둘 — 둘 다 "red 를 봤다" 는 오판

**(가) WSL 의 `npx tsx` 가 죽었다.** `@esbuild/win32-x64` 만 있고 `@esbuild/linux-x64` 가 없어 프로세스가 시작조차 못 했다. exit 1 과 `'test failed'` 가 단언 실패와 구별되지 않아 **T-PH002-01 의 red 를 한 번 오판했다.** 러너가 죽으면 실패 출력에 **테스트 이름이 없고 파일 이름만** 나온다 — 그것이 구별 신호다. 계획에 R-05 로 남겼다.

**(나) `git diff` 가 CRLF 를 색상 변경으로 셌다.** AC-8 을 순진하게 세면 기존 CSS 5개가 변경으로, hex 줄 230개가 바뀐 것으로 잡힌다. `--ignore-cr-at-eol` 를 주면 전부 0줄이다. 이 워크트리는 세션 이전부터 CRLF 차이를 갖고 있었다. 계획의 `verification_cmd` 를 고치고 R-04 로 남겼다.

두 사고의 모양이 같다 — **값싸게 얻은 판독이 실제 판독처럼 보였다.**
