대분류 강조 · 트리 점선 · 상태 아이콘

바뀌는 점

  • 대분류 제목은 본문보다 4px 큽니다(직전 시안 6px, 지금 제품 3px).
  • 대분류 → 항목 → 세부항목이 왼쪽의 점선으로 이어집니다. 부모 아이콘에서 아래로 내려가 각 하위 줄로 꺾여 들어가고, 마지막 하위 줄에서 끝납니다. 상세 설명 상자 옆으로도 선이 이어집니다.
  • 대분류의 체크박스는 상태 아이콘으로 바뀝니다. 아이콘을 누르면 완료와 진행 중이 바뀝니다.
  • 대분류 오른쪽에 하위 완료 수(예: 1/3)를 작게 붙였습니다. 필요 없으면 뺍니다.
  • 항목·세부항목은 지금처럼 체크박스를 씁니다.

진행 중 아이콘: D (확정)

  • 대분류의 하위 항목 완료 비율만큼 원이 찹니다. 하위 항목이 없거나 아무것도 완료되지 않았어도 조금은 차 있어 「진행 중」으로 읽힙니다.
  • 모두 완료하고 대분류 아이콘을 누르면 초록 원 안의 V(완료)로 바뀝니다.

체크 색 고르기

체크박스

  • 브라우저 기본 체크박스 대신 빌더게이트 색(tokens.css)으로 그린 체크박스입니다. 어두운 바탕, 둥근 모서리이고, 체크했을 때 색은 위에서 고릅니다. 키보드 포커스 시 강조색 테두리가 생깁니다.
