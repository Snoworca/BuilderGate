파일 탐색기 — 끌어서 복사·이동, 새 파일

탐색기 안에서 항목을 끌어 다른 폴더에 놓으면 이동하고, Ctrl(macOS는 ⌥ Option)을 누른 채 놓으면 복사합니다. 여러 항목을 선택한 상태에서 그중 하나를 끌면 선택 전체가 함께 갑니다. 끌어 놓기는 데스크톱 전용이며 모바일(터치)에서는 켜지지 않습니다. 오른쪽 버튼 메뉴의 새 파일은 창을 띄워 이름을 받고, 같은 이름이 이미 있으면 만들지 않습니다.

동작 규칙

A. 끌어서 이동·복사 (데스크톱)

  1. 목록 보기·트리 보기의 행을 끌 수 있습니다. 선택된 행을 끌면 선택 전체, 선택되지 않은 행을 끌면 그 행만 선택한 뒤 끕니다.
  2. 기본은 이동입니다. 끄는 동안 Ctrl(macOS ⌥)을 누르고 있으면 복사입니다. 놓는 순간의 키 상태로 정하며, 배지가 실시간으로 바뀝니다.
  3. 놓을 수 있는 곳
    • 폴더 행(목록·트리)
    • 경로 막대의 폴더 이름(상위 폴더)
    • 목록의 빈 곳 = 지금 보고 있는 폴더
    • 다른 탭 — 0.8초 머무르면 그 탭으로 바뀌고, 그 탭의 폴더에 놓을 수 있습니다
  4. 놓을 수 없는 곳: 파일 행, 끌고 있는 항목 자신, 끌고 있는 폴더의 하위, 항목이 이미 있는 폴더. 커서가 🚫 로 바뀌고 배지에 이유가 나옵니다.
  5. 폴더 행 위에 0.8초 머무르면 그 폴더로 들어갑니다(트리는 펼침). 목록 위·아래 끝 32px 에 있으면 자동으로 스크롤합니다.
  6. Esc 또는 창 밖에 놓으면 아무 일도 없습니다.
  7. 놓으면 기존 붙여넣기와 같은 작업으로 서버에 보냅니다(복사 = copy, 이동 = cut). 진행은 작업 표시줄, 이름 충돌은 기존 충돌 창(건너뛰기·둘 다 유지·덮어쓰기)을 그대로 씁니다. 클립보드는 바꾸지 않습니다.
  8. 끝나면 원본·대상 폴더를 새로 고치고, 옮긴 항목을 대상 폴더에서 선택해 둡니다.
  9. OS 에서 파일을 끌어 오는 기존 업로드는 그대로입니다. 탐색기 안의 끌기와 OS 끌기는 데이터 형식으로 구별합니다.
  10. 같은 브라우저의 다른 워크스페이스 탐색기 창으로 끌어도 같은 규칙입니다(세션이 다르면 세션 간 붙여넣기와 같은 경로).

B. 모바일

  • pointer: coarse 이면 행에 draggable 을 주지 않습니다. 터치 길게 누르기·스크롤 동작은 바뀌지 않습니다.
  • 새 파일은 더보기 시트에 있습니다(새 폴더 바로 위).

C. 새 파일

  1. 오른쪽 버튼 메뉴(빈 곳·항목 모두)와 모바일 더보기 시트에 새 파일을 둡니다. 위치 규칙은 새 폴더와 같습니다.
  2. 모달 창이 뜨고 이름 칸에 바로 포커스가 갑니다. 기본 이름은 비어 있습니다.
  3. 입력할 때마다 확인합니다
    • 비었거나 공백뿐 → [만들기] 비활성(오류 문구 없음)
    • / \ 포함, . .. → 오류
    • 그 폴더 목록에 같은 이름(파일이든 폴더든) → 오류, [만들기] 비활성
  4. Enter = 만들기, Esc = 취소. 만드는 동안 버튼은 진행 표시로 바뀝니다.
  5. 서버는 이미 있으면 만들지 않습니다(덮어쓰기 없음, 배타적 생성). 그 사이 생긴 경우 창을 닫지 않고 오류를 보여 줍니다.
  6. 성공하면 창을 닫고, 목록을 새로 고친 뒤 새 파일을 선택하고 화면에 보이게 합니다. 내용은 0바이트입니다.

확인이 필요한 점

  • Windows 탐색기처럼 Shift+끌기를 "강제 이동"으로 둘지 (지금은 기본이 이동이라 불필요).
  • 대소문자만 다른 이름(readme.md vs README.md): 화면 확인은 정확히 같은 이름만 막고, 최종 판정은 서버 파일 시스템에 맡깁니다(Windows 는 거부, Linux 는 허용).
  • 새 파일을 만든 뒤 편집기에서 바로 열지 여부 — 이번 디자인에는 넣지 않았습니다.
